Enunciado

Vamos construir uma aplicação funcional que coloca em prática os conceitos da aula: Set, Map, equals()/hashCode() e a iteração com Java 8. O resultado final é um sistema de controle de estoque de um mini mercado, operado pelo console, com cadastro, consulta e venda de produtos.

Todo o código foi escrito para ser copiado e colado: basta seguir a ordem dos passos, criando um arquivo por vez no VS Code. Ao final, o projeto executa com um único comando.

Arquitetura das Coleções

O coração do sistema são duas estruturas: um Map que associa cada Produto (chave única) à sua quantidade, e um Set que mantém as categorias únicas cadastradas.

Pré-requisitos (VS Code + Java)

  1. VS Code com o pacote de extensões "Extension Pack for Java" (Microsoft).
  2. JDK 8 ou superior instalado e configurado no VS Code. Todo o código usa apenas recursos do Java 8 (lambdas, forEach e método de referência), funcionando igualmente nas versões LTS atuais (11, 17 e 21).
  3. Nenhuma biblioteca externa: tudo usa apenas a java.util padrão do Java.

Passo 2: Classe Produto (com equals e hashCode)

A classe que representa um item do estoque. Repare no ponto-chave da aula: o método equals() e o hashCode() consideram apenas o nome. Assim, dois produtos com o mesmo nome são "iguais" — é isso que torna o nome uma chave única no Map. A Regra de Ouro é respeitada: se são iguais pelo equals(), retornam o mesmo hashCode(). 

import java.util.Objects;

public class Produto {

    private final String nome;
    private final String categoria;
    private final double preco;

    public Produto(String nome) {
        this(nome, "Geral", 0.0);
    }

    public Produto(String nome, String categoria, double preco) {
        this.nome = nome;
        this.categoria = categoria;
        this.preco = preco;
    }

    public String getNome() {
        return nome;
    }

    public String getCategoria() {
        return categoria;
    }

    public double getPreco() {
        return preco;
    }

    // A identidade do produto é o NOME: dois produtos com o mesmo nome
    // são considerados "iguais" (Regra de Ouro).
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Produto produto = (Produto) o;
        return Objects.equals(nome, produto.nome);
    }

    @Override
    public int hashCode() {
        return Objects.hash(nome);
    }

    @Override
    public String toString() {
        return String.format("%s (%s) - R$ %.2f", nome, categoria, preco);
    }
}

Passo 3: Classe Estoque (Set e Map)

A lógica de negócio do sistema. Ela declara as variáveis com o tipo da interface (Map e Set) e instancia com as classes concretas — exatamente a dica de "programação para interface" da aula. Observe também o Autoboxing: o int vira Integer automaticamente. 

import java.util.Comparator;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;
import java.util.TreeMap;

public class Estoque {

    // MAP: associa cada produto (chave única) à quantidade em estoque.
    // O Produto é a CHAVE, por isso precisa de equals() e hashCode() corretos.
    private final Map<Produto, Integer> produtos = new HashMap<>();

    // SET: categorias únicas do mercado, sem duplicatas.
    private final Set<String> categorias = new HashSet<>();

    public boolean cadastrar(String nome, String categoria, double preco, int quantidade) {
        Produto produto = new Produto(nome, categoria, preco);

        // containsKey verifica se já existe produto com este nome (unicidade)
        if (produtos.containsKey(produto)) {
            return false;
        }

        produtos.put(produto, quantidade); // Autoboxing: int -> Integer
        categorias.add(categoria);
        return true;
    }

    public Integer consultar(String nome) {
        // get() usa hashCode() para achar o "balde" e equals() para confirmar
        return produtos.get(new Produto(nome));
    }

    public boolean vender(String nome, int quantidade) {
        Produto chave = new Produto(nome);

        if (!produtos.containsKey(chave)) {
            return false; // produto não cadastrado
        }

        int atual = produtos.get(chave);
        if (atual < quantidade) {
            return false; // estoque insuficiente
        }

        // put() com chave já existente SOBRESCREVE o valor antigo
        produtos.put(chave, atual - quantidade);
        return true;
    }

    public void listarOrdenado() {
        // TreeMap mantém as chaves ordenadas pelo Comparator fornecido
        Map<Produto, Integer> ordenado = new TreeMap<>(Comparator.comparing(Produto::getNome));
        ordenado.putAll(produtos);

        // forEach + Lambda percorre cada par chave-valor (Java 8)
        ordenado.forEach((produto, quantidade) ->
                System.out.println(produto + " | Quantidade: " + quantidade));
    }

    public void listarCategorias() {
        System.out.println("Categorias cadastradas:");
        for (String categoria : categorias) { // Enhanced-For sobre o Set
            System.out.println(" - " + categoria);
        }
    }

    public void listarEmFalta() {
        System.out.println("Produtos com estoque zerado:");
        produtos.forEach((produto, quantidade) -> {
            if (quantidade == 0) {
                System.out.println(" - " + produto.getNome());
            }
        });
    }
}

Passo 4: Classe Main (menu interativo)

A classe que conversa com o usuário pelo console. O menu chama os métodos da classe Estoque, que já encapsula toda a lógica das coleções. 

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Estoque estoque = new Estoque();
        Scanner scanner = new Scanner(System.in);
        // Ponto decimal (29.90) em vez de vírgula, em qualquer sistema
        scanner.useLocale(java.util.Locale.US);

        int opcao;
        do {
            System.out.println();
            System.out.println("=== CONTROLE DE ESTOQUE ===");
            System.out.println("1 - Cadastrar produto");
            System.out.println("2 - Consultar estoque");
            System.out.println("3 - Vender produto");
            System.out.println("4 - Listar estoque (ordem alfabética)");
            System.out.println("5 - Listar categorias");
            System.out.println("6 - Produtos em falta");
            System.out.println("0 - Sair");
            System.out.print("Opção: ");

            opcao = scanner.nextInt();
            scanner.nextLine(); // consome o Enter deixado pelo nextInt

            switch (opcao) {
                case 1: cadastrarProduto(estoque, scanner); break;
                case 2: consultarProduto(estoque, scanner); break;
                case 3: venderProduto(estoque, scanner); break;
                case 4: estoque.listarOrdenado(); break;
                case 5: estoque.listarCategorias(); break;
                case 6: estoque.listarEmFalta(); break;
                case 0: System.out.println("Encerrando o sistema..."); break;
                default: System.out.println("Opção inválida!"); break;
            }
        } while (opcao != 0);

        scanner.close();
    }

    private static void cadastrarProduto(Estoque estoque, Scanner scanner) {
        System.out.print("Nome do produto: ");
        String nome = scanner.nextLine();
        System.out.print("Categoria: ");
        String categoria = scanner.nextLine();
        System.out.print("Preço: ");
        double preco = scanner.nextDouble();
        scanner.nextLine();
        System.out.print("Quantidade inicial: ");
        int quantidade = scanner.nextInt();
        scanner.nextLine();

        if (estoque.cadastrar(nome, categoria, preco, quantidade)) {
            System.out.println("Produto cadastrado com sucesso!");
        } else {
            System.out.println("ERRO: já existe um produto com este nome.");
        }
    }

    private static void consultarProduto(Estoque estoque, Scanner scanner) {
        System.out.print("Nome do produto: ");
        String nome = scanner.nextLine();

        Integer quantidade = estoque.consultar(nome); // Autoboxing no retorno
        if (quantidade == null) {
            System.out.println("Produto não encontrado.");
        } else {
            System.out.println("Quantidade em estoque: " + quantidade);
        }
    }

    private static void venderProduto(Estoque estoque, Scanner scanner) {
        System.out.print("Nome do produto: ");
        String nome = scanner.nextLine();
        System.out.print("Quantidade vendida: ");
        int quantidade = scanner.nextInt();
        scanner.nextLine();

        if (estoque.vender(nome, quantidade)) {
            System.out.println("Venda realizada com sucesso!");
        } else {
            System.out.println("ERRO: produto não cadastrado ou estoque insuficiente.");
        }
    }
}

Como Executar

  1. Estrutura: crie a pasta controle-estoque com a subpasta src e copie os três arquivos (Produto.java, Estoque.java, Main.java) para dentro de src.
  2. Executar: abra o arquivo Main.java no VS Code e clique no botão "Run" (ou pressione F5).
  3. Testar o fluxo:
    • Cadastrar o produto "Arroz" e depois tentar cadastrar novamente o mesmo nome — o sistema recusa, provando a unicidade do Map.
    • Consultar o "Arroz" e ver a quantidade em estoque.
    • Listar estoque após cadastrar vários produtos — perceba que a saída sai em ordem alfabética, graças ao TreeMap.
    • Listar categorias e cadastrar duas vezes a mesma categoria — ela só aparece uma vez, provando a unicidade do Set.
    • Vender até zerar um produto e verificar o item na opção "Produtos em falta".

Dica de demonstração em sala

  • Antes de rodar, pergunte aos alunos: "quantas vezes um produto pode aparecer no estoque?" e "o que acontece se cadastrarmos o mesmo nome duas vezes?" — a resposta é o coração da aula.

  • Para reforçar a iteração Java 8, peça para substituírem o for da opção 5 por um categorias.forEach(System.out::println).

Dicas & Lembretes

  • Regra de Ouro: se dois objetos são iguais pelo equals(), eles devem ter o mesmo hashCode(). Aqui, ambos usam apenas o nome.
  • Chaves do Map: para localizar um valor, criamos new Produto(nome). O hashCode() acha o balde e o equals() confirma a igualdade.
  • Sobrescrita de valores: put() em uma chave existente substitui o valor antigo — por isso o método vender() atualiza a quantidade.
  • Autoboxing: int e double são convertidos automaticamente em Integer e Double ao entrarem em coleções.
  • Programação para interface: as variáveis são declaradas como Map e Set, e a instância concreta (ex: HashMap) pode ser trocada sem afetar o restante do código.
  • Scanner e ponto decimal: o useLocale(Locale.US) garante que o preço seja digitado com ponto (29.90), independentemente do idioma do sistema.
