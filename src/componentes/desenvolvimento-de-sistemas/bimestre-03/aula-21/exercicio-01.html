1. Enunciado

Nesta atividade você construirá um sistema de notas para uma turma da ETEC, aplicando na prática as estruturas da aula: um Set para garantir que cada aluno seja matriculado uma única vez e um Map para associar cada aluno à sua nota final. Ao final, o sistema deve listar os aprovados, exibir o boletim em ordem alfabética e calcular a média da turma.

3. Passo a Passo

Passo 1: A Classe Aluno (Aluno.java)

A identidade do aluno será o email: dois alunos com o mesmo email são considerados "iguais". Por isso, equals() e hashCode() usam apenas o email — respeitando a Regra de Ouro da aula. 

import java.util.Objects;

public class Aluno {

    private final String nome;
    private final String email;

    public Aluno(String nome, String email) {
        this.nome = nome;
        this.email = email;
    }

    public String getNome() {
        return nome;
    }

    public String getEmail() {
        return email;
    }

    // A identidade do aluno é o EMAIL: dois alunos com o mesmo email
    // são considerados "iguais" (Regra de Ouro).
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Aluno aluno = (Aluno) o;
        return Objects.equals(email, aluno.email);
    }

    @Override
    public int hashCode() {
        return Objects.hash(email);
    }

    @Override
    public String toString() {
        return nome + " (" + email + ")";
    }
}

Passo 2: A Classe Turma (Turma.java)

Repare em três pontos da aula: as variáveis são declaradas com o tipo da interface (Set e Map), o Set descarta matrículas duplicadas e o Map usa o Aluno como chave (é por isso que equals()/hashCode() são indispensáveis). 

import java.util.Comparator;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;
import java.util.TreeMap;

public class Turma {

    // SET: cada aluno aparece uma única vez (unicidade por email)
    private final Set<Aluno> alunos = new HashSet<>();

    // MAP: aluno -> nota final (Aluno é a CHAVE, por isso equals/hashCode)
    private final Map<Aluno, Double> notas = new HashMap<>();

    public boolean matricular(Aluno aluno) {
        return alunos.add(aluno); // retorna false se o email já existe
    }

    // Set não tem índice: buscamos o aluno real percorrendo o conjunto
    public Aluno buscarPorEmail(String email) {
        Aluno chave = new Aluno("", email); // so o email importa (equals)
        for (Aluno aluno : alunos) {
            if (aluno.equals(chave)) {
                return aluno;
            }
        }
        return null;
    }

    public void lancarNota(String email, double nota) {
        Aluno aluno = buscarPorEmail(email);
        if (aluno == null) {
            System.out.println("ERRO: aluno não matriculado.");
            return;
        }
        notas.put(aluno, nota); // chave existente: sobrescreve a nota
    }

    public int totalDeAlunos() {
        return alunos.size();
    }

    public void listarAprovados() {
        System.out.println("Aprovados (nota >= 6.0):");
        notas.forEach((aluno, nota) -> {
            if (nota >= 6.0) {
                System.out.println(" - " + aluno.getNome() + ": " + nota);
            }
        });
    }

    public void exibirBoletim() {
        // TreeMap ordena as chaves usando o Comparator fornecido
        Map<Aluno, Double> boletim = new TreeMap<>(Comparator.comparing(Aluno::getNome));
        boletim.putAll(notas);

        boletim.forEach((aluno, nota) ->
                System.out.println(aluno.getNome() + " -> " + nota));
    }

    public double calcularMedia() {
        double soma = 0;
        for (Double nota : notas.values()) { // Enhanced-For sobre os valores
            soma += nota;
        }
        return notas.isEmpty() ? 0 : soma / notas.size();
    }
}

Passo 3: O Menu (Main.java)

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Turma turma = new Turma();
        Scanner scanner = new Scanner(System.in);
        // Ponto decimal (8.5) em vez de vírgula, em qualquer sistema
        scanner.useLocale(java.util.Locale.US);

        int opcao;
        do {
            System.out.println();
            System.out.println("=== SISTEMA DE NOTAS ===");
            System.out.println("1 - Matricular aluno");
            System.out.println("2 - Lançar nota");
            System.out.println("3 - Listar aprovados");
            System.out.println("4 - Exibir boletim (ordem alfabética)");
            System.out.println("5 - Média da turma");
            System.out.println("6 - Total de alunos");
            System.out.println("0 - Sair");
            System.out.print("Opção: ");

            opcao = scanner.nextInt();
            scanner.nextLine(); // consome o Enter deixado pelo nextInt

            switch (opcao) {
                case 1: matricular(turma, scanner); break;
                case 2: lancarNota(turma, scanner); break;
                case 3: turma.listarAprovados(); break;
                case 4: turma.exibirBoletim(); break;
                case 5: System.out.println("Média da turma: " + turma.calcularMedia()); break;
                case 6: System.out.println("Total de alunos: " + turma.totalDeAlunos()); break;
                case 0: System.out.println("Encerrando..."); break;
                default: System.out.println("Opção inválida!"); break;
            }
        } while (opcao != 0);

        scanner.close();
    }

    private static void matricular(Turma turma, Scanner scanner) {
        System.out.print("Nome do aluno: ");
        String nome = scanner.nextLine();
        System.out.print("Email: ");
        String email = scanner.nextLine();

        if (turma.matricular(new Aluno(nome, email))) {
            System.out.println("Aluno matriculado com sucesso!");
        } else {
            System.out.println("ERRO: já existe um aluno com este email.");
        }
    }

    private static void lancarNota(Turma turma, Scanner scanner) {
        System.out.print("Email do aluno: ");
        String email = scanner.nextLine();
        System.out.print("Nota final: ");
        double nota = scanner.nextDouble();
        scanner.nextLine();

        turma.lancarNota(email, nota);
    }
}

4. Desafios de Fixação

  • Unicidade: matricule Ana (ana@etec.com.br) e depois tente matricular novamente com o mesmo email. O que o método add retorna? Depois, matricule Ana Souza com um email diferente — o sistema deve aceitar, pois a identidade é o email.
  • Sobrescrita no Map: lance uma nota para um aluno que já tem nota. Verifique que o valor antigo é substituído, exatamente como o put() se comporta em chaves existentes.
  • Mude a Regra de Ouro: altere equals()/hashCode() da classe Aluno para usar o nome em vez do email. Repita o desafio 1 e explique o que mudou no comportamento.
  • Iteração Java 8: reescreva o método calcularMedia() usando notas.values().forEach(...) ou forEach sobre a entrada.
  • Explore o TreeSet: declare o conjunto de alunos como TreeSet<Aluno> (com um Comparator.comparing(Aluno::getNome)) e liste os alunos. Qual a diferença no comportamento?
  • Scanner e ponto decimal: o useLocale(Locale.US) faz o nextDouble() aceitar o ponto (ex: 8.5) em qualquer sistema, independentemente do idioma.
