Teoria & Conceitos

O Collections Framework é um conjunto de interfaces e implementações prontas do Java para armazenar e manipular grupos de objetos. Já conhecemos as listas (a interface List). Nesta aula exploramos duas famílias mais avançadas: os conjuntos (Set), que garantem unicidade de elementos, e os mapas (Map), que associam chaves a valores — como um dicionário.

1. A Interface java.util.Set

Um conjunto (Set) funciona de forma análoga aos conjuntos da matemática: ele é uma coleção que não permite elementos duplicados. Ao tentar adicionar um elemento que já existe, o método add retornará false e a operação será ignorada.

  • Ordenação: ao contrário das listas, a interface Set não garante uma ordem específica de armazenamento; os elementos podem não ser recuperados na mesma ordem em que foram inseridos.
  • Performance: a grande vantagem do Set é a velocidade. Implementações como o HashSet possuem performance incomparável com as listas para operações de pesquisa, como o método contains.

Exemplo de Código: HashSet e Unicidade

import java.util.HashSet;
import java.util.Set;

public class ExemploHashSet {
    public static void main(String[] args) {
        Set<String> cargos = new HashSet<>();
        cargos.add("Gerente");
        cargos.add("Diretor");
        cargos.add("Gerente"); // Elemento repetido: será ignorado

        System.out.println(cargos.size()); // Saída será 2
        System.out.println(cargos);        // Ordem de exibição NÃO é garantida
    }
}

O resultado 2 prova que o segundo "Gerente" foi descartado. Repare que a ordem de exibição pode variar entre execuções: o HashSet não se compromete com nenhuma ordenação.

2. Principais Implementações de Set

A interface Set possui três implementações clássicas, que diferem principalmente na ordem em que os elementos são armazenados:

  • HashSet: armazena os dados em uma tabela de hash. É a implementação mais rápida, mas não garante nenhuma ordem.
  • TreeSet: armazena os elementos em uma árvore. Os elementos são mantidos em sua ordem natural (ex: alfabética ou numérica) ou por um Comparator personalizado.
  • LinkedHashSet: uma variante do HashSet que mantém a ordem de inserção dos elementos.

Exemplo de Código: Comparando a Ordem das Implementações

import java.util.HashSet;
import java.util.LinkedHashSet;
import java.util.Set;
import java.util.TreeSet;

public class ComparandoSets {
    public static void main(String[] args) {
        Set<String> hashSet = new HashSet<>();
        Set<String> treeSet = new TreeSet<>();
        Set<String> linkedHashSet = new LinkedHashSet<>();

        String[] nomes = {"Ana", "Carlos", "Bruno"};

        for (String nome : nomes) {
            hashSet.add(nome);
            treeSet.add(nome);
            linkedHashSet.add(nome);
        }

        System.out.println("HashSet: " + hashSet);        // ordem imprevisivel
        System.out.println("TreeSet: " + treeSet);        // [Ana, Bruno, Carlos] (alfabetica)
        System.out.println("LinkedHashSet: " + linkedHashSet); // [Ana, Carlos, Bruno] (insercao)
    }
}
Implementação Estrutura Interna Ordenação Quando Usar
HashSet Tabela de hash Nenhuma (imprevisível) Busca rápida por contains
TreeSet Árvore (Red-Black) Ordem natural ou Comparator Elementos sempre ordenados
LinkedHashSet Tabela de hash + lista ligada Ordem de inserção Unicidade preservando a chegada

Map: Dicionários de Chave-Valor

1. A Interface java.util.Map

Um mapa (Map) é uma coleção que associa chaves únicas a valores, funcionando como um dicionário ou matriz associativa. Embora faça parte do framework de coleções, a interface Map não estende Collection, pois seu comportamento é fundamentalmente diferente.

  • Chaves: devem ser únicas. Se você inserir um valor com uma chave já existente, o valor antigo será sobrescrito pelo novo.
  • Valores: podem ser duplicados; várias chaves podem apontar para o mesmo valor.

Exemplo de Código: HashMap

import java.util.HashMap;
import java.util.Map;

public class ExemploHashMap {
    public static void main(String[] args) {
        Map<String, Double> contas = new HashMap<>();
        contas.put("diretor", 10000.0); // put para adicionar chave e valor
        contas.put("gerente", 5000.0);

        double saldo = contas.get("diretor"); // get para recuperar pela chave
        System.out.println(saldo); // 10000.0

        contas.put("diretor", 12000.0); // chave repetida: sobrescreve o valor
        System.out.println(contas.get("diretor")); // 12000.0
    }
}

2. Principais Implementações de Map

  • HashMap: implementação baseada em tabela de hash. É rápida, não sincronizada e permite chaves ou valores null.
  • TreeMap: mantém as chaves em ordem classificada (ordem natural ou Comparator).
  • Hashtable: implementação mais antiga, sincronizada (thread-safe) e que não permite elementos nulos.

HashMap Nenhuma (imprevisível) Não Sim
TreeMap Ordenada (natural ou Comparator) Não Só valores
Hashtable Nenhuma (imprevisível) Sim Não

hashCode() e equals(): O Segredo do Funcionamento

Para que as coleções baseadas em espalhamento (como HashSet e HashMap) funcionem corretamente, é essencial que os objetos usados como chaves ou elementos implementem corretamente os métodos hashCode() e equals().

Regra de Ouro: se dois objetos são considerados iguais pelo método equals(), eles devem retornar o mesmo valor no método hashCode(). Caso essa regra seja quebrada, a coleção não conseguirá localizar os objetos corretamente, mesmo que eles estejam lá.

Exemplo de Código: equals() e hashCode()

import java.util.Objects;

public class Conta {
    private String titular;
    private double saldo;

    public Conta(String titular, double saldo) {
        this.titular = titular;
        this.saldo = saldo;
    }

    public double getSaldo() {
        return saldo;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Conta conta = (Conta) o;
        return Double.compare(conta.saldo, saldo) == 0
                && Objects.equals(titular, conta.titular);
    }

    @Override
    public int hashCode() {
        return Objects.hash(titular, saldo);
    }
}

Observe que ambos os métodos utilizam os mesmos atributos (titular e saldo). Assim, duas contas iguais pelo equals() sempre produzirão o mesmo hashCode(). 

import java.util.HashSet;
import java.util.Set;

public class TesteUnicidade {
    public static void main(String[] args) {
        Set<Conta> contas = new HashSet<>();
        contas.add(new Conta("Maria", 2500.0));
        contas.add(new Conta("Maria", 2500.0)); // objeto "igual" ao anterior

        System.out.println(contas.size()); // Saída: 1 (unicidade funcionando)
    }
}

Iteração e Java 8

Embora conjuntos não possuam índices (como o get(i) das listas), eles podem ser percorridos facilmente usando o Enhanced-For ou a API de Streams do Java 8. Já para os mapas, o método forEach permite realizar operações em cada par chave-valor de forma concisa.

Exemplo de Código: Percorrendo Set e Map

import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

public class IterandoColecoes {
    public static void main(String[] args) {
        // Percorrendo um Set com Enhanced-For
        Set<String> cargos = new HashSet<>();
        cargos.add("Gerente");
        cargos.add("Diretor");

        for (String cargo : cargos) {
            System.out.println("Cargo: " + cargo);
        }

        // Percorrendo um Map com forEach + Lambda (Java 8)
        Map<String, Conta> mapaDeContas = new HashMap<>();
        mapaDeContas.put("diretor", new Conta("Diretor", 12000.0));
        mapaDeContas.put("gerente", new Conta("Gerente", 5000.0));

        mapaDeContas.forEach((cargo, conta) -> {
            System.out.println("Cargo: " + cargo + " | Saldo: " + conta.getSaldo());
        });
    }
}

No mapa, a sintaxe (cargo, conta) -> recebe cada par chave-valor e executa a operação desejada. Também é possível percorrer apenas as chaves com keySet() ou apenas os valores com values().

Dicas & Lembretes Técnicos

  • Escolha a Coleção Certa: use List quando a ordem e duplicatas importarem. Use Set para garantir unicidade e performance em buscas. Use Map para associações de chave-valor.
  • Tipos Primitivos: coleções não aceitam tipos primitivos (como int ou double). O Java utiliza o Autoboxing para converter esses valores em suas classes empacotadoras (ex: Integer, Double) automaticamente.
  • Programação para Interface: sempre declare suas variáveis usando o tipo da interface (ex: Set) e instancie com a classe concreta (ex: HashSet). Isso diminui o acoplamento e facilita a troca de implementação futura.
  • equals + hashCode: em classes usadas como chave de Map ou elemento de Set, implemente sempre equals() e hashCode() usando os mesmos atributos.
  • Map não é Collection: apesar de fazer parte do framework, Map não estende a interface Collection — ele tem métodos próprios como put e get.

Como aplicar na Prática

  • Cadastro de usuários: use um Set<String> de emails para impedir que o mesmo email seja cadastrado duas vezes.
  • Dicionário de configurações: armazene parâmetros do sistema em um Map<String, String> (ex: "url_banco" → valor).
  • Contador de ocorrências: percorra uma lista e conte cada elemento usando um Map<String, Integer>, incrementando o valor a cada repetição.
  • Menu ordenado: para exibir opções sempre em ordem alfabética, use TreeSet ou TreeMap.
  • Lista de presença: um LinkedHashSet registra cada aluno uma única vez, preservando a ordem em que chegou.
