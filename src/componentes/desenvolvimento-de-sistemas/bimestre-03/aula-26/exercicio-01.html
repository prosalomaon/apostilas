Enunciado

Você foi contratado para desenvolver a camada de persistência de um sistema de estoque. A tabela PRODUTO no banco de dados estoque_db possui a seguinte estrutura: 

CREATE TABLE produto (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    descricao VARCHAR(255),
    preco DECIMAL(10,2) NOT NULL,
    quantidade_estoque INT DEFAULT 0
);

Sua tarefa é implementar a camada de persistência completa, seguindo o padrão DAO.
