Teoria & Conceitos

1. O que é uma GUI e o Ecossistema Swing

Uma GUI (Graphical User Interface) oferece um mecanismo amigável para a interação entre o usuário e o aplicativo através de elementos visuais como botões, janelas e menus.

  • Swing vs. AWT: O Java possui dois conjuntos principais de componentes GUI. O AWT (Abstract Window Toolkit) é o mais antigo e depende de componentes nativos do sistema operacional ("componentes pesados"). O Swing (pacote javax.swing) é a biblioteca sucessora, cujos componentes são "leves", pois são escritos e processados inteiramente em Java, garantindo maior portabilidade e uma aparência uniforme entre diferentes plataformas.
  • Contrato vs. Interface Gráfica: É importante não confundir o conceito de Interface Java (um contrato de métodos) com uma Interface Gráfica de usuário.

2. Componentes Básicos do Swing

Os componentes Swing são as peças fundamentais ("widgets") para construir uma tela. Quase todos derivam da classe JComponent — a exceção são os contêineres de nível superior (top-level), como o JFrame.

  • JFrame: Representa a janela principal do aplicativo, contendo barra de título e botões de controle (minimizar, fechar).
  • JLabel: Utilizado para exibir texto ou imagens não editáveis (rótulos).
  • JButton: Um botão de comando que dispara uma ação quando clicado.
  • JTextField e JPasswordField: Campos para entrada de texto de uma única linha. O segundo oculta os caracteres digitados por segurança.
  • JPanel: Uma área genérica usada para organizar e agrupar outros componentes.

3. Gerenciadores de Layout (Layout Managers)

Em vez de posicionar componentes por coordenadas exatas (o que tornaria a GUI rígida), o Java usa gerenciadores de layout para organizar os componentes automaticamente conforme o tamanho da janela muda.

  • FlowLayout: Posiciona os componentes da esquerda para a direita, como palavras em uma página. É o padrão para JPanel.
  • BorderLayout: Divide o contêiner em cinco regiões: NORTH, SOUTH, EAST, WEST e CENTER. É o layout padrão para JFrame.
  • GridLayout: Organiza os componentes em uma grade retangular de linhas e colunas, onde todos os espaços têm o mesmo tamanho.

4. Tratamento de Eventos (Event Handling)

As GUIs são baseadas em eventos: quando o usuário interage com um componente (clica em um botão ou pressiona Enter), o sistema gera um sinal que o programa deve tratar.

  • Modelo de Delegação de Eventos: Envolve três partes: a origem do evento (o botão), o objeto de evento (contendo dados sobre o clique) e o ouvinte (listener) (o código que responde).
  • Interfaces Ouvintes: Para responder a cliques de botão, a classe deve implementar a interface ActionListener e definir o método actionPerformed.
  • Classes Internas e Anônimas: Frequentemente, os ouvintes são implementados como classes internas para que possam acessar facilmente os atributos da janela principal.

Exemplo de Código

1. Uma Janela Básica

O exemplo abaixo mostra como criar uma janela simples herdando de JFrame e configurando um rótulo: 

import java.awt.FlowLayout; // Gerenciador de layout
import javax.swing.JFrame;   // Base da janela
import javax.swing.JLabel;   // Rótulo de texto

public class MinhaJanela extends JFrame {
    private final JLabel label;

    public MinhaJanela() {
        super("Título da Janela");       // Título da barra superior
        setLayout(new FlowLayout());     // Define o layout

        label = new JLabel("Bem-vindo ao Swing!");
        label.setToolTipText("Dica de ferramenta ao passar o mouse");
        add(label);                      // Anexa o componente à janela
    }

    public static void main(String[] args) {
        MinhaJanela janela = new MinhaJanela();
        janela.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); // Encerra o app ao fechar
        janela.setSize(300, 150);        // Define largura e altura em pixels
        janela.setVisible(true);         // Exibe a janela na tela
    }
}

2. Janela com Botão e Tratamento de Evento

Para que um botão responda ao clique, registramos um ouvinte com addActionListener e implementamos actionPerformed — aqui com uma classe anônima: 

import java.awt.FlowLayout;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import javax.swing.JButton;
import javax.swing.JFrame;
import javax.swing.JLabel;

public class JanelaComBotao extends JFrame {
    private final JLabel status;

    public JanelaComBotao() {
        super("Janela com Evento");
        setLayout(new FlowLayout());

        status = new JLabel("Aguardando clique...");
        add(status);

        JButton botao = new JButton("Clique aqui");
        botao.addActionListener(new ActionListener() {
            @Override
            public void actionPerformed(ActionEvent e) {
                status.setText("Botão clicado!");
            }
        });
        add(botao);
    }

    public static void main(String[] args) {
        JanelaComBotao janela = new JanelaComBotao();
        janela.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        janela.setSize(320, 150);
        janela.setVisible(true);
    }
}

Note que a classe anônima do ouvinte acessa diretamente o atributo status da janela, sem a necessidade de parâmetros extras — essa é a grande vantagem das classes internas.

Modelo de Delegação de Eventos

Quando o usuário clica no botão, a origem gera um objeto de evento que é entregue ao ouvinte registrado:

Dicas & Lembretes de Herói

  • Encerramento do Programa: Sempre chame setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE), caso contrário, a janela sumirá ao fechar, mas o processo Java continuará rodando em segundo plano.
  • Thread de Despacho de Eventos (EDT): Toda a manipulação de componentes GUI deve ocorrer na thread correta para garantir a segurança e estabilidade da interface.
  • Nimbus Look-and-Feel: O Java moderno oferece o tema Nimbus, que é elegante e multiplataforma. Ele pode ser configurado no arquivo swing.properties ou via código.
  • Desenho Personalizado: Para desenhar formas (linhas, círculos), você deve sobrescrever o método paintComponent de um JPanel. A primeira instrução deve ser sempre super.paintComponent(g) para limpar a área antes de desenhar.

Como aplicar na Prática

  • Sempre pense em "janela + layout + componentes": ao iniciar uma tela, defina o JFrame (com título e tamanho), escolha o layout adequado e só então adicione os componentes com add().
  • Agrupe com JPanel: para organizar formulários complexos, combine vários JPanel (cada um com seu próprio layout) dentro da janela.
  • Não esqueça o evento: um botão sem addActionListener é um botão decorativo. Sempre registre o ouvinte e implemente actionPerformed.
  • Proteja campos de senha: utilize JPasswordField sempre que o dado digitado não puder ser exibido em texto claro.
  • Teste a aparência: prefira layouts automáticos (Flow, Border, Grid) em vez de coordenadas fixas — assim a tela se adapta ao redimensionamento da janela.
