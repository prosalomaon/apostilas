Enunciado

Vamos construir uma aplicação funcional e completa que coloca em prática todos os conceitos da aula: persistência via JDBC, conexão com o MySQL e o padrão DAO. O resultado final é um sistema de cadastro de produtos com interface gráfica Swing e um CRUD completo (Cadastrar, Listar, Atualizar e Excluir).

Todo o código foi escrito para ser copiado e colado: basta seguir a ordem dos passos, criando um arquivo por vez no VS Code. Ao final, o projeto executa com um único comando.

Pré-requisitos (VS Code + Java)

  1. VS Code com o pacote de extensões "Extension Pack for Java" (Microsoft), que já inclui Maven, depurador e suporte a Swing.
  2. JDK 17 ou superior instalado e configurado no VS Code.
  3. MySQL Server em execução local (ou via XAMPP).
  4. Nada de drivers para baixar manualmente: o driver do MySQL entra pelo Maven (pom.xml).

Passo 1: Preparando o Banco de Dados

Execute o script abaixo no MySQL (via MySQL Workbench, terminal ou painel do XAMPP). Ele cria o banco cadastro_produtos e a tabela produtos com os campos usados pela aplicação. 

-- 1. Cria o banco de dados
CREATE DATABASE IF NOT EXISTS cadastro_produtos;
USE cadastro_produtos;

-- 2. Cria a tabela de produtos
CREATE TABLE IF NOT EXISTS produtos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    preco DECIMAL(10,2) NOT NULL,
    quantidade INT NOT NULL DEFAULT 0,
    categoria VARCHAR(50)
);

-- 3. (Opcional) Registros iniciais para testar o Listar
INSERT INTO produtos (nome, preco, quantidade, categoria) VALUES

('Mouse', 49.90, 20, 'Informática'),
('Cadeira Gamer', 899.90, 3, 'Móveis');

Passo 3: Classe de Conexão (Conexao.java)

Centraliza a abertura da conexão. Ajuste o usuário e a senha para os do seu MySQL. A URL segue o formato visto na aula: jdbc:mysql://endereco:porta/nome_do_banco. 

package com.exemplo.produtos;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class Conexao {

    private static final String URL = "jdbc:mysql://localhost:3306/cadastro_produtos";
    private static final String USUARIO = "root";
    private static final String SENHA = "sua_senha";

    public static Connection abrir() {
        try {
            return DriverManager.getConnection(URL, USUARIO, SENHA);
        } catch (SQLException e) {
            // Relança como unchecked para não acoplar as demais camadas ao JDBC
            throw new RuntimeException("Erro ao conectar no banco de dados.", e);
        }
    }
}

Repare que a SQLException (checked) é capturada e relançada como RuntimeException (unchecked) — exatamente a boa prática apresentada na aula.

Passo 4: Modelo Produto (Java Bean)

Classe que representa a tabela produtos no código Java, seguindo o padrão Java Beans (construtor vazio e getters/setters). Ela fica no pacote model. 

package com.exemplo.produtos.model;

public class Produto {

    private int id;
    private String nome;
    private double preco;
    private int quantidade;
    private String categoria;

    public Produto() {
    }

    public Produto(int id, String nome, double preco, int quantidade, String categoria) {
        this.id = id;
        this.nome = nome;
        this.preco = preco;
        this.quantidade = quantidade;
        this.categoria = categoria;
    }

    public int getId() { return id; }
    public void setId(int id) { this.id = id; }

    public String getNome() { return nome; }
    public void setNome(String nome) { this.nome = nome; }

    public double getPreco() { return preco; }
    public void setPreco(double preco) { this.preco = preco; }

    public int getQuantidade() { return quantidade; }
    public void setQuantidade(int quantidade) { this.quantidade = quantidade; }

    public String getCategoria() { return categoria; }
    public void setCategoria(String categoria) { this.categoria = categoria; }

    @Override
    public String toString() {
        return nome;
    }
}

Passo 5: Camada DAO

O padrão DAO isola todo o SQL. A interface define o contrato; a implementação usa o JDBC. O restante da aplicação nunca toca em SQL diretamente.

Interface ProdutoDAO

package com.exemplo.produtos.dao;

import com.exemplo.produtos.model.Produto;
import java.util.List;

public interface ProdutoDAO {

    void salvar(Produto produto);
    void atualizar(Produto produto);
    void excluir(int id);
    List<Produto> listar();
    Produto buscarPorId(int id);
}

Implementação ProdutoDAOImpl

Toda instrução usa PreparedStatement (proteção contra SQL Injection), com os valores passados por posição (começando em 1) e recursos fechados via try-with-resources. 

package com.exemplo.produtos.dao;

import com.exemplo.produtos.Conexao;
import com.exemplo.produtos.model.Produto;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.ArrayList;
import java.util.List;

public class ProdutoDAOImpl implements ProdutoDAO {

    @Override
    public void salvar(Produto produto) {
        String sql = "INSERT INTO produtos (nome, preco, quantidade, categoria) VALUES (?, ?, ?, ?)";
        try (Connection conexao = Conexao.abrir();
             PreparedStatement stmt = conexao.prepareStatement(sql)) {

            stmt.setString(1, produto.getNome());
            stmt.setDouble(2, produto.getPreco());
            stmt.setInt(3, produto.getQuantidade());
            stmt.setString(4, produto.getCategoria());
            stmt.executeUpdate();

        } catch (SQLException e) {
            throw new RuntimeException("Erro ao salvar produto.", e);
        }
    }

    @Override
    public void atualizar(Produto produto) {
        String sql = "UPDATE produtos SET nome = ?, preco = ?, quantidade = ?, categoria = ? WHERE id = ?";
        try (Connection conexao = Conexao.abrir();
             PreparedStatement stmt = conexao.prepareStatement(sql)) {

            stmt.setString(1, produto.getNome());
            stmt.setDouble(2, produto.getPreco());
            stmt.setInt(3, produto.getQuantidade());
            stmt.setString(4, produto.getCategoria());
            stmt.setInt(5, produto.getId());
            stmt.executeUpdate();

        } catch (SQLException e) {
            throw new RuntimeException("Erro ao atualizar produto.", e);
        }
    }

    @Override
    public void excluir(int id) {
        String sql = "DELETE FROM produtos WHERE id = ?";
        try (Connection conexao = Conexao.abrir();
             PreparedStatement stmt = conexao.prepareStatement(sql)) {

            stmt.setInt(1, id);
            stmt.executeUpdate();

        } catch (SQLException e) {
            throw new RuntimeException("Erro ao excluir produto.", e);
        }
    }

    @Override
    public List<Produto> listar() {
        List<Produto> produtos = new ArrayList<>();
        String sql = "SELECT id, nome, preco, quantidade, categoria FROM produtos ORDER BY nome";

        try (Connection conexao = Conexao.abrir();
             PreparedStatement stmt = conexao.prepareStatement(sql);
             ResultSet rs = stmt.executeQuery()) {

            while (rs.next()) {
                Produto p = new Produto(
                        rs.getInt("id"),
                        rs.getString("nome"),
                        rs.getDouble("preco"),
                        rs.getInt("quantidade"),
                        rs.getString("categoria"));
                produtos.add(p);
            }
        } catch (SQLException e) {
            throw new RuntimeException("Erro ao listar produtos.", e);
        }
        return produtos;
    }

    @Override
    public Produto buscarPorId(int id) {
        String sql = "SELECT id, nome, preco, quantidade, categoria FROM produtos WHERE id = ?";
        try (Connection conexao = Conexao.abrir();
             PreparedStatement stmt = conexao.prepareStatement(sql)) {

            stmt.setInt(1, id);
            try (ResultSet rs = stmt.executeQuery()) {
                if (rs.next()) {
                    return new Produto(
                            rs.getInt("id"),
                            rs.getString("nome"),
                            rs.getDouble("preco"),
                            rs.getInt("quantidade"),
                            rs.getString("categoria"));
                }
            }
        } catch (SQLException e) {
            throw new RuntimeException("Erro ao buscar produto.", e);
        }
        return null;
    }
}

Passo 6: Interface Gráfica Swing (ProdutoForm.java)

A janela principal reúne o formulário (campos), a tabela de produtos e os botões do CRUD. O código usa JTable com um DefaultTableModel para exibir a listagem. 

package com.exemplo.produtos.ui;

import com.exemplo.produtos.dao.ProdutoDAO;
import com.exemplo.produtos.dao.ProdutoDAOImpl;
import com.exemplo.produtos.model.Produto;

import javax.swing.*;
import javax.swing.table.DefaultTableModel;
import java.awt.*;

public class ProdutoForm extends JFrame {

    private final ProdutoDAO produtoDAO = new ProdutoDAOImpl();

    private final JTextField campoId = new JTextField(6);
    private final JTextField campoNome = new JTextField(20);
    private final JTextField campoPreco = new JTextField(10);
    private final JTextField campoQuantidade = new JTextField(6);
    private final JTextField campoCategoria = new JTextField(12);

    private final DefaultTableModel modeloTabela = new DefaultTableModel(
            new String[]{"ID", "Nome", "Preço", "Qtd.", "Categoria"}, 0);

    private final JTable tabela = new JTable(modeloTabela);

    public ProdutoForm() {
        setTitle("Cadastro de Produtos - JDBC + Swing");
        setSize(720, 480);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setLocationRelativeTo(null);

        setLayout(new BorderLayout());
        add(criarCampos(), BorderLayout.NORTH);
        add(criarTabela(), BorderLayout.CENTER);
        add(criarBotoes(), BorderLayout.SOUTH);

        listar();
    }

    private JPanel criarCampos() {
        JPanel painel = new JPanel(new GridLayout(3, 4, 8, 8));
        painel.setBorder(BorderFactory.createEmptyBorder(10, 10, 10, 10));

        painel.add(new JLabel("ID:"));
        painel.add(campoId);
        painel.add(new JLabel("Nome:"));
        painel.add(campoNome);
        painel.add(new JLabel("Preço:"));
        painel.add(campoPreco);
        painel.add(new JLabel("Quantidade:"));
        painel.add(campoQuantidade);
        painel.add(new JLabel("Categoria:"));
        painel.add(campoCategoria);
        painel.add(new JLabel());
        painel.add(new JLabel());

        return painel;
    }

    private JScrollPane criarTabela() {
        tabela.setSelectionMode(ListSelectionModel.SINGLE_SELECTION);
        tabela.getSelectionModel().addListSelectionListener(e -> preencherCamposDaLinhaSelecionada());
        return new JScrollPane(tabela);
    }

    private JPanel criarBotoes() {
        JButton salvar = new JButton("Salvar (Novo)");
        JButton atualizar = new JButton("Atualizar");
        JButton excluir = new JButton("Excluir");
        JButton limpar = new JButton("Limpar");
        JButton listar = new JButton("Listar");

        salvar.addActionListener(e -> salvar());
        atualizar.addActionListener(e -> atualizar());
        excluir.addActionListener(e -> excluir());
        limpar.addActionListener(e -> limparCampos());
        listar.addActionListener(e -> listar());

        JPanel painel = new JPanel();
        painel.add(salvar);
        painel.add(atualizar);
        painel.add(excluir);
        painel.add(limpar);
        painel.add(listar);
        return painel;
    }

    private void salvar() {
        try {
            Produto p = new Produto();
            p.setNome(campoNome.getText().trim());
            p.setPreco(Double.parseDouble(campoPreco.getText().trim()));
            p.setQuantidade(Integer.parseInt(campoQuantidade.getText().trim()));
            p.setCategoria(campoCategoria.getText().trim());

            produtoDAO.salvar(p);
            JOptionPane.showMessageDialog(this, "Produto cadastrado com sucesso!");
            limparCampos();
            listar();
        } catch (Exception ex) {
            JOptionPane.showMessageDialog(this, "Erro ao salvar: " + ex.getMessage());
        }
    }

    private void atualizar() {
        if (campoId.getText().trim().isEmpty()) {
            JOptionPane.showMessageDialog(this, "Selecione um produto na tabela.");
            return;
        }
        try {
            Produto p = new Produto();
            p.setId(Integer.parseInt(campoId.getText().trim()));
            p.setNome(campoNome.getText().trim());
            p.setPreco(Double.parseDouble(campoPreco.getText().trim()));
            p.setQuantidade(Integer.parseInt(campoQuantidade.getText().trim()));
            p.setCategoria(campoCategoria.getText().trim());

            produtoDAO.atualizar(p);
            JOptionPane.showMessageDialog(this, "Produto atualizado com sucesso!");
            limparCampos();
            listar();
        } catch (Exception ex) {
            JOptionPane.showMessageDialog(this, "Erro ao atualizar: " + ex.getMessage());
        }
    }

    private void excluir() {
        if (campoId.getText().trim().isEmpty()) {
            JOptionPane.showMessageDialog(this, "Selecione um produto na tabela.");
            return;
        }
        int id = Integer.parseInt(campoId.getText().trim());
        int confirmacao = JOptionPane.showConfirmDialog(
                this, "Excluir o produto selecionado?", "Confirmar", JOptionPane.YES_NO_OPTION);

        if (confirmacao == JOptionPane.YES_OPTION) {
            produtoDAO.excluir(id);
            limparCampos();
            listar();
        }
    }

    private void listar() {
        modeloTabela.setRowCount(0);
        for (Produto p : produtoDAO.listar()) {
            modeloTabela.addRow(new Object[]{
                    p.getId(), p.getNome(), p.getPreco(), p.getQuantidade(), p.getCategoria()
            });
        }
    }

    private void preencherCamposDaLinhaSelecionada() {
        int linha = tabela.getSelectedRow();
        if (linha >= 0) {
            campoId.setText(String.valueOf(modeloTabela.getValueAt(linha, 0)));
            campoNome.setText(String.valueOf(modeloTabela.getValueAt(linha, 1)));
            campoPreco.setText(String.valueOf(modeloTabela.getValueAt(linha, 2)));
            campoQuantidade.setText(String.valueOf(modeloTabela.getValueAt(linha, 3)));
            campoCategoria.setText(String.valueOf(modeloTabela.getValueAt(linha, 4)));
        }
    }

    private void limparCampos() {
        campoId.setText("");
        campoNome.setText("");
        campoPreco.setText("");
        campoQuantidade.setText("");
        campoCategoria.setText("");
    }
}

Passo 7: Classe Principal (Main.java)

A classe com o método main apenas abre a janela Swing. O SwingUtilities.invokeLater garante que a interface seja criada na Event Dispatch Thread (EDT), prática obrigatória em qualquer aplicação gráfica Java. 

package com.exemplo.produtos;

import com.exemplo.produtos.ui.ProdutoForm;
import javax.swing.SwingUtilities;

public class Main {

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new ProdutoForm().setVisible(true);
        });
    }
}

Como Executar

  1. Banco: execute o script do Passo 1 no seu MySQL (confira se o serviço está rodando).
  2. Conexão: em Conexao.java, ajuste USUARIO e SENHA para as credenciais do seu MySQL.
  3. Compilar: no VS Code, abra o arquivo Main.java e clique no botão "Run" (ou pressione F5). O Maven resolve a dependência do driver automaticamente.
  4. Testar o CRUD:
    • Salvar: preencha os campos e clique em "Salvar (Novo)".
    • Atualizar: selecione uma linha da tabela, altere os campos e clique em "Atualizar".
    • Excluir: selecione a linha e clique em "Excluir" (o sistema pede confirmação).
    • Listar: o botão "Listar" recarrega a tabela com os dados do banco.

Dica de demonstração em sala

  • Rode a aplicação e cadastre alguns produtos. Em seguida, abra o MySQL Workbench e execute SELECT * FROM cadastro_produtos.produtos; para mostrar aos alunos que os dados realmente foram persistidos no banco — não apenas na memória do programa.
  • Para demonstrar a proteção contra SQL Injection, troque momentaneamente o PreparedStatement por concatenação de strings e digite ' OR '1'='1 em um campo de busca.

Dicas & Lembretes

  • Driver automático: com o Maven, o arquivo .jar do driver é baixado e colocado no classpath automaticamente — você não precisa fazer nada manual.
  • URL de conexão: se o MySQL usar outra porta (ex.: 3307 no XAMPP), ajuste a URL em Conexao.java.
  • Nunca concatene SQL: todos os comandos usam PreparedStatement com parâmetros começando em 1 — jamais monte o SQL com valores do usuário.
  • Recursos: todas as conexões e statements usam try-with-resources, garantindo o fechamento mesmo em caso de erro.
  • Interface gráfica: crie a janela na EDT com SwingUtilities.invokeLater.
