1. Enunciado

Nesta atividade você construirá um sistema bancário que protege sua regra de negócio com o tratamento de exceções visto na aula. Uma conta só pode sacar ou transferir valores que estejam disponíveis — e, se a regra for violada, o sistema deve falhar de forma explicita lançando uma exceção personalizada, em vez de simplesmente imprimir um texto solto ou retornar um código de erro.

2. Preparação

  • Localização: crie os arquivos dentro da sua pasta de projetos Java (ex: src/aula22/).
  • Arquivos Necessários:
    • SaldoInsuficienteException.java: a exceção personalizada de negócio.
    • ContaBancaria.java: a regra de negócio com throw/throws.
    • Main.java: o menu interativo que captura as exceções.
  • Versão do Java: o código usa apenas recursos do Java 8, sendo compatível com os LTS atuais (11, 17 e 21).

3. Passo a Passo

Passo 1: A Exceção Personalizada (SaldoInsuficienteException.java)

Como a regra de negócio "não pode sacar mais do que tem" não existe na API Java, criamos nossa própria exceção. Ela herda de RuntimeException (unchecked), então os métodos que a lançam não são obrigados a capturá-la — mas declarar throws documenta a intenção. 

public class SaldoInsuficienteException extends RuntimeException {

    public SaldoInsuficienteException(String mensagem) {
        super(mensagem);
    }
}

Passo 2: A Regra de Negócio (ContaBancaria.java)

Repare nos três pontos da aula: throw é usado no imperativo para lançar a exceção quando a regra é violada, throws é usado na assinatura para delegar a responsabilidade, e o IllegalArgumentException (unchecked padrão) rejeita valores inválidos. 

import java.util.ArrayList;
import java.util.List;

public class ContaBancaria {

    private final String titular;
    private double saldo;
    private final List<String> extrato = new ArrayList<>();

    public ContaBancaria(String titular, double saldoInicial) {
        this.titular = titular;
        if (saldoInicial < 0) {
            throw new IllegalArgumentException("Saldo inicial não pode ser negativo.");
        }
        this.saldo = saldoInicial;
    }

    public void depositar(double valor) {
        if (valor <= 0) {
            throw new IllegalArgumentException("Valor de depósito deve ser positivo.");
        }
        this.saldo += valor;
        extrato.add("Depósito de R$ " + valor);
    }

    public void sacar(double valor) throws SaldoInsuficienteException {
        if (valor <= 0) {
            throw new IllegalArgumentException("Valor de saque deve ser positivo.");
        }
        if (valor > this.saldo) {
            // LANÇA a exceção quando a regra de negócio é violada
            throw new SaldoInsuficienteException(
                "Saldo insuficiente! Disponível: R$ " + this.saldo);
        }
        this.saldo -= valor;
        extrato.add("Saque de R$ " + valor);
    }

    public void transferir(double valor, ContaBancaria destino)
            throws SaldoInsuficienteException {
        if (destino == null) {
            throw new NullPointerException("Conta de destino não pode ser nula.");
        }
        this.sacar(valor);   // valida e debita desta conta
        destino.depositar(valor); // credita na conta de destino
        extrato.add("Transferência de R$ " + valor + " para " + destino.getTitular());
    }

    public double getSaldo() {
        return saldo;
    }

    public String getTitular() {
        return titular;
    }

    public void exibirExtrato() {
        System.out.println("=== EXTRATO DE " + titular + " ===");
        for (String operacao : extrato) {
            System.out.println(" - " + operacao);
        }
    }
}

Passo 3: O Menu com try, catch e finally (Main.java)

O menu captura exceções específicas em vez do genérico Exception: cada catch sabe exatamente como recuperar o sistema. 

import java.util.InputMismatchException;
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        ContaBancaria conta = new ContaBancaria("João", 1000.0);
        ContaBancaria destino = new ContaBancaria("Maria", 0.0);
        Scanner scanner = new Scanner(System.in);
        scanner.useLocale(java.util.Locale.US); // ponto decimal (8.5)

        int opcao;
        do {
            System.out.println();
            System.out.println("=== SISTEMA BANCÁRIO ===");
            System.out.println("1 - Depositar");
            System.out.println("2 - Sacar");
            System.out.println("3 - Transferir para " + destino.getTitular());
            System.out.println("4 - Consultar saldo");
            System.out.println("5 - Exibir extrato");
            System.out.println("0 - Sair");
            System.out.print("Opção: ");

            try {
                opcao = scanner.nextInt();
                scanner.nextLine(); // consome o Enter deixado pelo nextInt

                switch (opcao) {
                    case 1: depositar(conta, scanner); break;
                    case 2: sacar(conta, scanner); break;
                    case 3: transferir(conta, destino, scanner); break;
                    case 4: System.out.println("Saldo de " + conta.getTitular()
                            + ": R$ " + conta.getSaldo()); break;
                    case 5: conta.exibirExtrato(); break;
                    case 0: System.out.println("Encerrando..."); break;
                    default: System.out.println("Opção inválida!"); break;
                }
            } catch (InputMismatchException e) {
                // catch específico: o usuário digitou algo que não é número
                System.out.println("ERRO: digite um número de opção válido.");
                scanner.nextLine(); // descarta a entrada inválida
                opcao = -1; // impede o laço de encerrar
            }
        } while (opcao != 0);

        scanner.close();
        System.out.println("Programa finalizado.");
    }

    private static void depositar(ContaBancaria conta, Scanner scanner) {
        try {
            System.out.print("Valor do depósito: ");
            double valor = scanner.nextDouble();
            scanner.nextLine();
            conta.depositar(valor);
            System.out.println("Depósito realizado! Saldo: R$ " + conta.getSaldo());
        } catch (IllegalArgumentException e) {
            System.out.println("ERRO: " + e.getMessage());
        }
    }

    private static void sacar(ContaBancaria conta, Scanner scanner) {
        try {
            System.out.print("Valor do saque: ");
            double valor = scanner.nextDouble();
            scanner.nextLine();
            conta.sacar(valor);
            System.out.println("Saque realizado! Saldo: R$ " + conta.getSaldo());
        } catch (IllegalArgumentException e) {
            System.out.println("ERRO: " + e.getMessage());
        } catch (SaldoInsuficienteException e) {
            System.out.println("ERRO: " + e.getMessage());
        }
    }

    private static void transferir(ContaBancaria origem, ContaBancaria destino,
                                   Scanner scanner) {
        try {
            System.out.print("Valor da transferência: ");
            double valor = scanner.nextDouble();
            scanner.nextLine();
            origem.transferir(valor, destino);
            System.out.println("Transferência realizada!");
            System.out.println("Saldo de " + origem.getTitular() + ": R$ "
                    + origem.getSaldo());
            System.out.println("Saldo de " + destino.getTitular() + ": R$ "
                    + destino.getSaldo());
        } catch (SaldoInsuficienteException e) {
            System.out.println("ERRO: " + e.getMessage());
        } finally {
            System.out.println("Operação de transferência concluída.");
        }
    }
}

Teste sugerido: João inicia com R$ 1000. Tente sacar R$ 1500 (deve lançar SaldoInsuficienteException), depois transfira R$ 300 para Maria (deve funcionar) e confira os saldos no menu.

4. Desafios de Fixação

  • Veja a stacktrace: comente o catch (SaldoInsuficienteException e) do método sacar() e execute o saque inválido. Observe a exceção não tratada aparecer no console e a pilha de chamadas exibida pela JVM.
  • Checked vs. Unchecked: mude SaldoInsuficienteException para herdar de Exception em vez de RuntimeException. O que o compilador passa a exigir? Compile e explique a diferença.
  • Nova exceção de domínio: crie uma ValorInvalidoException e substitua o IllegalArgumentException nos métodos de depósito e saque. Mantenha o menu capturando apenas as exceções de negócio.
  • try-with-resources: substitua o scanner.close() do final pelo uso de try (Scanner scanner = new Scanner(System.in)). Como o Scanner implementa AutoCloseable, ele será fechado automaticamente.
  • Preserve a causa: crie um construtor em SaldoInsuficienteException que receba (String mensagem, Throwable causa) e chame super(mensagem, causa). Relance uma exceção dentro do try e confirme que getCause() retorna o erro original.
  • Multicatch: no método sacar() do menu, troque os dois catch por um único catch (IllegalArgumentException | SaldoInsuficienteException e). As duas classes são "irmãs" (nenhuma herda da outra), então o agrupamento é permitido.
