1. Enunciado

Uma empresa de e-commerce precisa de um aplicativo que exiba um catálogo de produtos. O app deve permitir que o usuário selecione um produto da lista e navegue para uma tela de detalhes, exibindo todas as informações do item escolhido. Implemente o fluxo completo de navegação utilizando Jetpack Compose Navigation.

2. Preparação do Ambiente

Antes de iniciar o desenvolvimento, certifique-se de que:

  • Android Studio: Versão Ladybug (2024.2.1) ou superior instalada.
  • Kotlin: Versão 1.9.0 ou superior configurada no build.gradle.kts.
  • Dependências: Adicione as dependências de Navigation Compose no arquivo build.gradle.kts (app): 
    dependencies {
    implementation("androidx.navigation:navigation-compose:2.8.3")
    implementation("androidx.compose.material3:material3:1.3.0")
}
  • Conhecimento Prévio: Compreender o básico de Compose (estados, composições) e o conceito de rotas e parâmetros.

3. Código Base (Estrutura de Dados)

Comece criando a classe de dados e a lista de produtos que serão exibidos no catálogo:

// data/Product.kt
data class Product(

4. O Desafio

Com a estrutura de dados definida, implemente as seguintes funcionalidades:

Desafio 1: Tela de Catálogo (Mestre)

Crie uma tela que exibe uma lista scrollável (LazyColumn) com todos os produtos. Cada item da lista deve exibir o nome, o preço formatado em Real (R$) e um indicador visual de disponibilidade (em estoque / esgotado). Ao clicar em um item, o app deve navegar para a tela de detalhes.

Desafio 2: Tela de Detalhes (Detalhe)

Crie uma tela que receba o ID do produto como argumento de rota e exiba todas as informações: nome, preço, descrição e status de estoque. Inclua um botão de "Voltar" que retorne ao catálogo.

Desafio 3: Rota e Navegação

Configure o NavHost com as rotas necessárias. Utilize um objeto Routes para centralizar as strings de rota e evite duplicação de código.

Desafio 4 (Bônus): Tratamento de Erro

Se o produto não for encontrado (ID inválido), exiba uma mensagem amigável ao invés de travar o app. Utilize o operador Elvis (?:) para tratar o caso nulo.

5. Estrutura Esperada

Seu projeto deve conter a seguinte organização de arquivos:

app/src/main/java/com/example/loja/
├── data/
│   └── Product.kt          (modelo de dados e lista)
├── navigation/
│   └── AppNavigation.kt    (NavHost e configuração de rotas)
└── ui/
    ├── CatalogScreen.kt    (tela de lista - Mestre)
    └── DetailScreen.kt     (tela de detalhes - Detalhe)

Orientações Finais

  • Utilize MaterialTheme para manter a consistência visual do app.
  • Lembre-se de formatar o preço com String.format("R$ %.2f", price).
  • Ao passar o nome do produto como parâmetro na rota, trate caracteres especiais (espaços, acentos) utilizando Uri.encode().
  • Certifique-se de que a navegação funciona corretamente ao pressionar o botão "Voltar" do dispositivo.
  • Valide os argumentos recebidos na tela de detalhes antes de utilizá-los.
