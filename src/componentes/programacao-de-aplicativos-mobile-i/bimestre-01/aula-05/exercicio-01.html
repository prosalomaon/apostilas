1. Enunciado

Você deve criar um aplicativo que funcione como um monitor visual do ciclo de vida. O app deve exibir na tela a lista de callbacks que estão sendo executados em tempo real, permitindo que o aluno observe o comportamento do sistema ao interagir com o dispositivo (girar a tela, enviar para segundo plano, etc.).

2. Preparação do Ambiente

  • Android Studio: Versão Ladybug (2024.2.1) ou superior.
  • Projeto: Crie um novo projeto Empty Activity (Compose) com as configurações:
    • Name: LifecycleMonitor
    • Packagename: com.exercicio.lifecycle
    • Linguagem: Kotlin
    • Build configuration: Kotlin DSL (.kts)
    • Minimum SDK: API 24 (Android 7.0)
  • Conhecimento Prévio: Ter concluído a Aula 05 sobre Ciclo de Vida de um App.

3. O Desafio

Desafio 1: Implementar os Callbacks

Sobrescreva todos os métodos de ciclo de vida (onCreate, onStart, onResume, onPause, onStop, onRestart, onDestroy) na sua MainActivity. Em cada um, adicione uma mensagem à lista de logs que será exibida na tela. Use a palavra-chave override e chame super em cada um.

Desafio 2: Criar a Tela de Logs

Utilize Compose para criar uma interface que exiba a lista de logs em tempo real. Cada mensagem deve mostrar o nome do callback e uma breve descrição do que está acontecendo. Utilize LazyColumn para renderizar a lista de forma performática.

Desafio 3: Persistência com Bundle

Implemente o onSaveInstanceState() para salvar a quantidade total de callbacks registrados. Ao recriar a Activity (girando a tela), recupere esse valor dentro do onCreate() e exiba uma mensagem indicando que os dados foram restaurados.

Desafio 4 (Bônus): Contador de Rotações

Implemente um contador que registra quantas vezes a tela foi rotacionada (Activity destruída e recriada). Salve o valor no Bundle e exiba-o no topo da tela junto com o título.

4. Testes a Realizar

Após implementar o app, execute os seguintes testes e observe o comportamento:

  • Teste 1: Abra o app pela primeira vez. Qual é a sequência de callbacks exibida?
  • Teste 2: Gire o dispositivo 90 graus. Quantos callbacks são disparados? O contador de rotações é incrementado?
  • Teste 3: Pressione o botão Home e volte ao app. Observe a sequência onPause → onStop → onRestart → onStart → onResume.
  • Teste 4: Abra uma notificação e volte ao app. O comportamento é igual ao Teste 3?
  • Teste 5: Feche o app pelo menu de tarefas e reabra. Observe que onCreate é chamado novamente sem savedInstanceState.

Orientações Finais

  • Lembre-se de que onCreate() só recebe savedInstanceState não-nulo quando a Activity está sendo recriada, não na primeira execução.
  • Não coloque código pesado dentro de onPause() — ele bloqueia a transição para a próxima tela.
  • Para visualizar melhor os logs, utilize Log.d() no Logcat do Android Studio em paralelo à exibição na tela.
  • Certifique-se de que cada callback chama super.onXxx() para não comprometer o funcionamento do sistema.
