1. Enunciado

Você recebeu a tarefa de auditar a estrutura de um projeto Android recém-criado. A empresa precisa que você identifique os principais arquivos e pastas, compreenda suas funções e documente possíveis configurações incorretas que devem ser ajustadas antes do desenvolvimento.

2. Preparação do Ambiente

Para realizar esta atividade, você precisará:

  • Android Studio: Versão Ladybug (2024.2.1) ou superior instalada.
  • Projeto Base: Crie um novo projeto Empty Activity (Compose) com as seguintes configurações:
    • Name: AuditoriaProjeto
    • Packagename: com.exercicio.auditoria
    • Linguagem: Kotlin
    • Build configuration: Kotlin DSL (.kts)
    • Minimum SDK: API 24 (Android 7.0)
  • Conhecimento Prévio: Ter concluído a Aula 04 sobre Estrutura de um Projeto Android.

3. O Desafio

Com o projeto criado, responda as questões abaixo e execute as tarefas solicitadas:

Tarefa 1: Mapeamento da Hierarquia (Teórica)

Liste e descreva brevemente a função de cada pasta principal visível na aba "Android" do Android Studio. Identifique em qual pasta estão localizados:

  • O arquivo AndroidManifest.xml.
  • O arquivo MainActivity.kt.
  • O arquivo build.gradle.kts do módulo.
  • O arquivo strings.xml.

Tarefa 2: Análise do Manifesto

Abra o arquivo AndroidManifest.xml e responda:

  • Qual Activity está configurada como LAUNCHER?
  • O manifesto declara alguma permissão? Se sim, qual?
  • Qual é o applicationId definido para o app?
  • Adicione uma nova permissão de Internet (android.permission.INTERNET) ao manifesto.

Tarefa 3: Configuração do Gradle

Abra o arquivo build.gradle.kts (Module: app) e responda:

  • Qual é a versão do compileSdk?
  • Qual é a versão do minSdk?
  • Quantas dependências o projeto possui? Liste pelo menos 3 delas.
  • Adicione a dependência implementation("com.google.code.gson:gson:2.10.1") e execute o Sync.

Tarefa 4: Explorando a Pasta res

Navegue pela pasta res e:

  • Altere o valor de <string name="app_name"> no strings.xml para "Minha Auditoria".
  • Verifique se o nome do app mudou no emulador ou dispositivo de teste após a alteração.
  • Identifique quantos arquivos existem na pasta mipmap e qual sua função.

Orientações Finais

  • Documente suas respostas em um arquivo de texto ou no próprio Android Studio usando comments.
  • Cuidado ao editar o AndroidManifest.xml: erros de sintaxe podem impedir que o app abra.
  • Sempre execute o "Sync Now" após alterar arquivos Gradle.
  • Se encontrar alguma configuração inesperada, compare com o que foi estudado na aula e tente explicar o motivo.
