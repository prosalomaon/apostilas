1. Exercício: Identificação de MVDs

Analise a tabela abaixo, utilizada por uma empresa de consultoria para registrar os idiomas e as certificações de cada funcionário: 

FUNCIONARIO_IDIOMA(
    CodFuncionario,
    Idioma,
    Certificacao
)

Regras de Negócio:

  • Um funcionário pode falar múltiplos idiomas.
  • Um funcionário pode possuir múltiplas certificações.
  • Os idiomas falados por um funcionário são independentes das certificações que ele possui.

Atividades:

  • Identifique a(s) Dependência(s) Multivalorada(s) existente(s) na tabela.
  • Justifique por que essa tabela viola a 4FN.
  • Escreva o esquema relacional resultante após a decomposição para 4FN.
  • Escreva os comandos CREATE TABLE para as tabelas resultantes.

2. Exercício: Aplicação da 4FN

Uma rede de hotéis mantém uma tabela para registrar quais serviços são oferecidos em cada quarto e quais funcionários estão designados para cada quarto: 

QUARTO_SERVICO_FUNCIONARIO(
    NumQuarto,
    Servico,
    CodFuncionario
)

Regras de Negócio:

  • Um quarto pode ter múltiplos serviços (limpeza, room service, lavanderia).
  • Um quarto pode ter múltiplos funcionários designados.
  • Os serviços oferecidos em um quarto são independentes dos funcionários designados.

Atividades:

  • Identifique as MVDs na tabela.
  • Decomponha a tabela para 4FN, justificando cada criação.
  • Escreva os comandos SQL (CREATE TABLE e INSERT INTO) para implementar as tabelas normalizadas com pelo menos 3 registros cada.

Orientações de Entrega

  • Preencha cada seção com sua análise e código SQL.
  • Utilize notação textual para os esquemas relacionais: NOME_TABELA(atributo1, atributo2, ...).
  • Justifique sempre por que a decomposição é necessária.
