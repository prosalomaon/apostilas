Enunciado

Uma livraria possui a seguinte tabela referente às vendas realizadas. A tabela encontra-se na Segunda Forma Normal (2FN), pois a chave primária é simples e não há dependências parciais. Porém, apresenta um problema de dependência transitiva: 

VENDA(
    Cod_Venda       INT,
    Data_Venda      DATE,
    Cod_Livro       INT,
    Titulo_Livro    VARCHAR(150),
    Genero_Livro    VARCHAR(50),
    Preco_Livro     DECIMAL(10,2),
    Quantidade      INT
)

Chave Primária: Cod_Venda

Dados de Exemplo

Cod_Venda Data_Venda Cod_Livro Titulo_Livro Genero_Livro Preco_Livro Quantidade

2 2026-08-11 102 O Cortiço Romance 28,00 1
