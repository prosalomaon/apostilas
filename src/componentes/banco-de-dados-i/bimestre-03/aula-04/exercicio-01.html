Enunciado

Uma universidade possui a seguinte tabela referente à alocação de professores em turmas de disciplinas. A tabela encontra-se na Primeira Forma Normal (1FN), mas apresenta problemas de projeto: 

ALOCACAO(
    ID_Professor      INT,
    Codigo_Disciplina INT,
    Nome_Professor    VARCHAR(100),
    Nome_Disciplina   VARCHAR(100),
    Carga_Horaria     INT,
    Semestre_Ano      VARCHAR(10)
)

Chave Primária Composta: (ID_Professor, Codigo_Disciplina)

Questão 5: Verificação

Após criar as tabelas, insira os dados de exemplo fornecidos no enunciado e execute a consulta abaixo para reconstruir a visão original. Confirme que o resultado é idêntico à tabela original: 

SELECT P.ID_Professor, D.Codigo_Disciplina,
       P.Nome_Professor, D.Nome_Disciplina,
       D.Carga_Horaria, T.Semestre_Ano
FROM TURMA_ALOCACAO T
JOIN PROFESSOR P ON P.ID_Professor = T.ID_Professor
JOIN DISCIPLINA D ON D.Codigo_Disciplina = T.Codigo_Disciplina;
