Enunciado

Uma academia deseja controlar as matrículas de seus alunos junto aos personais responsáveis. A tabela abaixo já está na Terceira Forma Normal (3FN), porém apresenta chaves candidatas sobrepostas: 

TREINO(
    Aluno        VARCHAR(100),
    Modalidade   VARCHAR(100),
    Personal     VARCHAR(100)
)

Regras de Negócio (Dependências Funcionais)

  • DF1: (Aluno, Modalidade) → Personal — para cada modalidade, o aluno tem apenas um personal específico.
  • DF2: Personal → Modalidade — cada personal trabalha com apenas uma modalidade específica.

Dados de Exemplo

Aluno Modalidade Personal
Carla Musculação Rafael
Diego Musculação Rafael
Carla Natação Beatriz
