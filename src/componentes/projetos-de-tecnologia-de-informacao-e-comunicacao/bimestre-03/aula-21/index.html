Teoria & Conceitos: A Lógica por Trás das Células

1. O que é um Algoritmo e o Pensamento Computacional?

Um algoritmo é um conjunto de instruções que o computador interpreta e executa para realizar tarefas. No contexto contábil, um algoritmo pode ser o passo a passo para calcular um imposto ou classificar um risco de crédito. Para criar soluções eficientes, aplicamos os pilares do Pensamento Computacional:

  • Decomposição: Dividir um problema contábil complexo em partes menores (ex: separar receita, custo e despesa).
  • Reconhecimento de Padrões: Identificar regularidades (ex: todo vencimento após o dia 10 gera multa).
  • Abstração: Filtrar detalhes irrelevantes e focar no que é essencial para o cálculo.
  • Algoritmo: Criar a sequência lógica de passos e fórmulas para resolver o problema.

2. A Célula como "Variável"

Na programação, uma variável armazena um dado que pode mudar. No Google Sheets, cada célula funciona como uma variável.

  • Nome da Variável: É o endereço da célula (ex: A1, B5).
  • Conteúdo/Tipo de Dado: Pode ser Texto (String), Número (Integer/Float), Valor Lógico ou uma Fórmula.

3. Estrutura Sequencial e Operadores

O processamento segue uma ordem lógica (geralmente de cima para baixo ou conforme as referências das fórmulas). Para processar esses dados, utilizamos:

  • Operadores Aritméticos: +, -, *, /, % e ^.
  • Operadores Relacionais (Comparação): = (Igual), > (Maior), < (Menor), >= (Maior ou igual), <= (Menor ou igual) e <> (Diferente).

4. Estrutura de Decisão: A Função SE (IF)

A base da inteligência de um algoritmo é a capacidade de tomar decisões. A função SE verifica uma condição e retorna um resultado se for VERDADEIRO e outro se for FALSO.

  • Sintaxe: =SE(teste_logico; valor_se_verdadeiro; valor_se_falso).
  • Exemplo: =SE(B2>1000; "Alto Risco"; "Baixo Risco").

Exemplo de Código

Compare as duas formas abaixo. A primeira calcula um valor com operadores aritméticos e a segunda toma uma decisão com a função SE: 

=B2 - C2 + D2 * 0.05

=SE(B2>1000; "Alto Risco"; "Baixo Risco")
Parte da Fórmula Significado no Algoritmo
SE( Início da estrutura de decisão (if)
B2>1000 Teste lógico que retorna VERDADEIRO ou FALSO
"Alto Risco" Valor retornado se o teste for VERDADEIRO
"Baixo Risco" Valor retornado se o teste for FALSO

Aplicação Prática: Criando um "Script" de Validação

Para exercitar a lógica, vamos construir um algoritmo que decide automaticamente se uma empresa pode receber um empréstimo.

1. Preparação

  1. Abra o Google Planilhas.
  2. Renomeie a aba para Algoritmo_Credito.
  3. Monte o cabeçalho na linha 1: Empresa | Faturamento | Dívidas | Anos de Mercado | Status da Aprovação.

2. O Desafio (O Algoritmo)

Você deve programar a coluna Status da Aprovação (Coluna E) para que ela siga a seguinte lógica de negócio:

  • Entrada de Dados: Preencha os dados de 3 empresas fictícias nas colunas A, B, C e D.
  • Processamento Lógico: Na célula E2, insira uma função SE que avalie:
    • Teste Lógico: O Faturamento (B2) deve ser maior que as Dívidas (C2).
    • Se Verdadeiro: Escreva "PRÉ-APROVADO".
    • Se Falso: Escreva "NEGADO".
  • Automação: Utilize a alça de preenchimento (clique no quadradinho no canto inferior direito da célula E2 e arraste para baixo) para replicar a lógica para as outras empresas. 
=SE(B2>C2; "PRÉ-APROVADO"; "NEGADO")

Exemplo de resultado esperado:

Empresa Faturamento (B) Dívidas (C) Anos de Mercado (D) Status (E)
TechNova 500.000 120.000 5 PRÉ-APROVADO
Comercial Silva 80.000 95.000 2 NEGADO
AgroVerde 200.000 200.000 8 NEGADO

Diagramação

Representação gráfica do algoritmo de validação de crédito construído na aula:

flowchart TD A([Início]) --> B[Ler Empresa, Faturamento,\nDívidas e Anos de Mercado] B --> C{SE Faturamento > Dívidas?} C -->|Verdadeiro| D["Escrever PRÉ-APROVADO"] C -->|Falso| E["Escrever NEGADO"] D --> F([Fim]) E --> F

Note que o nó de decisão SE(B2>C2) funciona exatamente como um if de programação: duas saídas possíveis, uma para cada resposta do teste lógico.

Dicas & Lembretes Profissionais

  • Toda fórmula deve começar com "=": Sem isso, o Sheets entende como um texto comum.
  • Aspas para Textos: Ao programar mensagens como "APROVADO", elas devem estar sempre entre aspas duplas.
  • Erro de Referência Circular: Evite criar uma fórmula em uma célula que aponte para ela mesma; isso gera erro de processamento.
  • Limpeza de Código: Use a tecla Delete para apagar o conteúdo de uma célula sem perder a formatação/estrutura configurada.
