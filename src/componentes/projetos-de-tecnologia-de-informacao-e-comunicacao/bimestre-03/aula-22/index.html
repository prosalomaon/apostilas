Teoria & Conceitos: A Ponte de Ouro – Traduzindo Planilhas para JavaScript

Nas aulas anteriores de processamento de dados e algoritmos, você utilizou a grade de células e fórmulas do Google Planilhas para automatizar cálculos e tomar decisões. Agora, daremos um passo fundamental: aprender a pensar como um programador profissional, utilizando o JavaScript — a linguagem de programação mais popular do mundo para desenvolvimento web e automação de chatbots.

Nesta aula, você verá que uma planilha eletrônica e um código JavaScript compartilham exatamente a mesma lógica. Vamos aprender a converter tabelas e fórmulas do Sheets diretamente em códigos de programação estruturados.

A Tabela de Tradução

Para programar em JavaScript, você não precisa esquecer o que aprendeu em planilhas; basta "traduzir" os conceitos. Veja como os elementos das planilhas são mapeados na programação:

Conceito em Planilhas (Google Sheets) Conceito em Programação (JavaScript) O que significa?
Célula Ativa (ex: B2) let ou const (Variável) Um espaço na memória para guardar dados que podem ou não mudar.
Texto Tipo de Dado: String Texto puro, delimitado por aspas (ex: "Tomate").
Número (Numeric) Tipo de Dado: Number Números inteiros ou decimais (ex: 12 ou 2.80).
Sinal de igual (=) no início Operador de Atribuição (=) Em JS, o = serve para guardar um valor dentro de uma variável (da direita para a esquerda).
Fórmula de Multiplicação (=B2*C2) Operador Aritmético (*) Realização de cálculos aritméticos diretos sobre as variáveis.
Fórmula Lógica SE() Estrutura de Decisão if / else Se uma condição for verdadeira, faça algo; senão, faça outra coisa.
Operador Lógico E() Operador Lógico && (AND) Combina condições. Exige que todas sejam verdadeiras simultaneamente.
Exibir valor na célula Saída de Dados (console.log()) Exibe o resultado do processamento na tela ou terminal do programador.

Duas formas de criar uma variável: let e const

  • let: cria uma variável cujo valor pode mudar durante a execução do programa — como uma célula que você edita livremente (ex: quantidade em estoque).
  • const: cria uma constante cujo valor não pode ser alterado depois da atribuição — como um dado fixo de cadastro (ex: nome do produto, taxa de imposto).

Exemplo de Código: A Conversão Prática (Passo a Passo)

Vamos analisar uma planilha muito simples de controle de compras (comum em quitandas ou pequenos comércios) e ver como ela é convertida linha por linha em um código JavaScript.

A Planilha de Origem (A1:E2)

Célula Campo Conteúdo / Fórmula Tipo
A2 Produto Tomate Texto (String)
B2 Quantidade 2 Número (Number)
C2 Preço Unitário 2.80 Número (Number)
D2 Preço Total =B2*C2 Fórmula de Multiplicação
E2 Status do Pedido =SE(B2>10; "Atacado"; "Varejo") Fórmula de Decisão

O Código JavaScript Correspondente

Copie o código estruturado abaixo. Você pode executá-lo no Terminal do Visual Studio Code ou diretamente no console do seu navegador de internet: 

// 1. Declarando as "Células" como Variáveis (Entrada de Dados)
let produto = "Tomate";       // Célula A2 (String)
let quantidade = 2;           // Célula B2 (Number)
let precoUnitario = 2.80;     // Célula C2 (Number)

// 2. Criando as Fórmulas de Processamento
// Célula D2: Preço Total (=B2*C2)
let precoTotal = quantidade * precoUnitario;

// Célula E2: Status do Pedido usando a estrutura SE (=SE(B2>10; "Atacado"; "Varejo"))
let statusPedido;
if (quantidade > 10) {
    statusPedido = "Atacado";
} else {
    statusPedido = "Varejo";
}

// 3. Exibindo os Resultados (Saída de Dados)
console.log("--- CUPOM FISCAL SIMULADO ---");
console.log("Produto adquirido: " + produto);
console.log("Quantidade: " + quantidade);
console.log("Preço Total calculado: R$ " + precoTotal.toFixed(2));
console.log("Classificação de Venda: " + statusPedido);

Anatomia do Código

Parte do Código Equivalente na Planilha Significado
let produto = "Tomate"; Célula A2 preenchida com Tomate Cria a variável e guarda o texto nela.
quantidade * precoUnitario =B2*C2 Multiplica os valores guardados nas variáveis.
if (quantidade > 10) { ... } else { ... } =SE(B2>10; "Atacado"; "Varejo") Teste lógico com dois caminhos possíveis.
console.log(...) Valor exibido na célula Mostra o resultado do processamento na tela.
"R$ " + precoTotal.toFixed(2) Formatação de número/currency da célula Concatena texto com número formatado com 2 casas decimais.

Resultado esperado ao executar:

--- CUPOM FISCAL SIMULADO ---
Produto adquirido: Tomate
Quantidade: 2
Preço Total calculado: R$ 5.60
Classificação de Venda: Varejo

O Desafio: Transforme a Lógica Contábil em Código JS

Para consolidar essa transição de pensamento lógico, realize a atividade a seguir.

A Planilha Proposta (Entrada de Dados)

Imagine que você tem uma tabela de análise financeira para decidir se um cliente receberá um determinado limite de crédito com base na renda e no tempo de trabalho:

Célula Nome do Campo Conteúdo / Fórmula
A2 Nome do Cliente "Carlos"
B2 Renda Mensal 5500
C2 Tempo de Trabalho (Anos) 4
D2 Limite Concedido =SE(B2>5000; 10000; 3000)

O que você deve fazer

  1. Abra o seu editor de código (como o VS Code) ou o console do navegador.
  2. Declare as variáveis de entrada de dados para o Nome do Cliente, Renda Mensal e Tempo de Trabalho.
  3. Escreva a estrutura condicional if / else para avaliar a renda (se for maior que 5000, a variável limiteConcedido recebe 10000; caso contrário, recebe 3000).
  4. Utilize o console.log() para imprimir na tela uma mensagem clara, por exemplo: "O cliente Carlos tem direito a R$ 10000 de limite de crédito". 
// Estrutura esperada (rascunho):
let nomeCliente = ...;
let rendaMensal = ...;
let limiteConcedido;

if (rendaMensal > 5000) {
    // verdadeiro
} else {
    // falso
}

console.log(...);

Dicas & Lembretes de Programação

  • Case Sensitivity (Diferenciação de Maiúsculas): diferente das funções do Sheets (onde =se() e =SE() funcionam igual), o JavaScript é extremamente rígido. Escrever IF em maiúsculo gerará um erro. Use sempre letras minúsculas para estruturas de controle: if e else.
  • As Aspas Importam: textos (Strings) devem ser declarados obrigatoriamente entre aspas simples ou duplas. Números não utilizam aspas, caso contrário, o JavaScript os tratará como texto e impedirá a realização de operações matemáticas.
  • A importância do Ponto e Vírgula (;): em JavaScript, utilizamos o ponto e vírgula ao final de cada linha de instrução para indicar ao interpretador que aquele comando foi concluído com sucesso, evitando falhas de leitura no script.
  • O Erro #NOME? vs. Erros de JS: nas planilhas, errar o nome de uma fórmula gera o erro #NOME?. No JavaScript, o terminal exibirá um erro de referência (ReferenceError), indicando que você tentou chamar algo que o sistema não reconhece.

Como aplicar na Prática

Essa mesma lógica de tradução está presente no dia a dia de quem trabalha com tecnologia:

  • Automação de chatbots: bots de WhatsApp e atendimento usam exatamente estruturas if / else para decidir qual mensagem enviar conforme a resposta do cliente.
  • Sistemas comerciais: o cálculo do preço total de um pedido (quantidade × preço unitário) é o mesmo que fizemos no cupom fiscal simulado.
  • Análise de crédito e financeira: regras como "renda maior que X aprova limite Y" rodam em servidores escritos em JavaScript (Node.js), substituindo planilhas manuais.
  • Migração de sistemas: muitas empresas começaram com controles em planilhas e depois os "converteram" em programas — o processo que você aprendeu hoje é a base dessa migração.
