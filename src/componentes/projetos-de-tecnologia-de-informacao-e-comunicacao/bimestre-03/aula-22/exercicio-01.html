Enunciado

Você é analista financeiro da empresa CrediTech. A equipe ainda decide os limites de crédito dos clientes em uma planilha, mas a diretoria quer migrar esse controle para um programa automatizado. Sua missão é traduzir a planilha em um código JavaScript que aplique a seguinte regra:

Se a Renda Mensal do cliente for maior que 5000, o limite concedido é R$ 10000. Caso contrário, o limite concedido é R$ 3000.

A planilha de origem que você deve "traduzir" é:

Célula Nome do Campo Conteúdo / Fórmula
A2 Nome do Cliente "Carlos"
B2 Renda Mensal 5500
C2 Tempo de Trabalho (Anos) 4
D2 Limite Concedido =SE(B2>5000; 10000; 3000)

Execute os passos abaixo e, em seguida, responda às questões.

Passos da Construção

  1. Abra o Visual Studio Code (ou o console do navegador, tecla F12).
  2. Crie um arquivo chamado analise-credito.js.
  3. Declare as variáveis de entrada com let: Nome do Cliente (String), Renda Mensal (Number) e Tempo de Trabalho (Number).
  4. Declare a variável limiteConcedido e escreva a estrutura if / else que avalia a renda conforme a regra do enunciado.
  5. Utilize o console.log() para exibir a mensagem final, por exemplo: "O cliente Carlos tem direito a R$ 10000 de limite de crédito".
  6. Execute o código no terminal (comando node analise-credito.js) ou no console do navegador e confira o resultado.
  7. Altere os valores das variáveis pelo menos 3 vezes para testar cenários diferentes e anote os resultados na Questão 2.

Orientações

  • Revise o conteúdo da aula antes de começar: variáveis (let/const), tipos de dados, operadores e a estrutura if / else.
  • Lembre-se: textos entre aspas, números sem aspas e instruções terminadas com ponto e vírgula.
  • O JavaScript diferencia maiúsculas de minúsculas: use sempre if e else em minúsculo.
  • Na Questão 2, teste também o caso-limite (renda igual a 5000) para refletir sobre a escolha do operador.
