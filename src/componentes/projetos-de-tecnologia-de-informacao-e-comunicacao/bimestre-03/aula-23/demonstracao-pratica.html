Contexto

Você foi contratado como auditor financeiro da empresa AuditPro Consultoria. A equipe recebeu o relatório de margens de lucro líquido (%) de quatro projetos contábeis auditados e precisa classificar cada um automaticamente. A regra de negócio é:

  • Margem < 0: "[ALERTA] O Projeto [Nome] está dando prejuízo!"
  • Margem entre 0 e 10 (inclusive): "[ATENÇÃO] O Projeto [Nome] está com baixa lucratividade."
  • Margem > 10: "[OK] O Projeto [Nome] é altamente rentável."

Esta página reúne a solução completa do desafio e dois exemplos que fazem o caminho de ida e volta entre a planilha e o código: primeiro transformamos um código em planilha e depois transformamos essa planilha em código.

Exemplo A: Transformando Código em Planilha

Tudo começa no código: os quatro projetos e suas margens foram declarados em duas matrizes (Arrays) — os dados que o programa mantém em memória: 

// Dados de entrada declarados em JavaScript (matrizes)
const projetos = ["Alfa", "Beta", "Gama", "Delta"];
const margens  = [15, 8, -3, 22];

Esse mesmo conjunto de dados pode ser materializado como uma planilha: cada posição da matriz vira uma linha e cada valor vira uma célula. A cadeia if / else if / else do código passa a ser uma fórmula SE(...) aninhada na coluna de diagnóstico:

A B C
1 Projeto Margem de lucro (%) Diagnóstico
2 Alfa 15 [OK] O Projeto Alfa é altamente rentável.
3 Beta 8 [ATENÇÃO] O Projeto Beta está com baixa lucratividade.
4 Gama -3 [ALERTA] O Projeto Gama está dando prejuízo!
5 Delta 22 [OK] O Projeto Delta é altamente rentável.

Fórmula da coluna C (C2 arrastada até C5): =SE(B2<0; "[ALERTA] O Projeto "&A2&" está dando prejuízo!"; SE(B2<=10; "[ATENÇÃO] O Projeto "&A2&" está com baixa lucratividade."; "[OK] O Projeto "&A2&" é altamente rentável."))

Repare na correspondência: projetos[0] (Alfa) é a célula A2, margens[0] (15) é a célula B2, e o encadeamento de if / else if / else é exatamente a estrutura do SE(...) aninhado.

Exemplo B: Transformando Planilha em Código

Agora o caminho inverso. Partimos da planilha — lendo a fórmula da coluna C — e escrevemos o código JavaScript que reproduz o mesmo resultado:

A B C
1 Projeto Margem de lucro (%) Fórmula do diagnóstico
2 Alfa 15 =SE(B2<0; "[ALERTA] O Projeto "&A2&" está dando prejuízo!"; SE(B2<=10; "[ATENÇÃO] O Projeto "&A2&" está com baixa lucratividade."; "[OK] O Projeto "&A2&" é altamente rentável."))
3 Beta 8 Mesma fórmula da célula C2 (arrastada para baixo)
4 Gama -3 Mesma fórmula da célula C2 (arrastada para baixo)
5 Delta 22 Mesma fórmula da célula C2 (arrastada para baixo)

Traduzindo, a função SE do Sheets vira o bloco if / else if / else, o & de concatenação vira a Template String com ${}, e o ato de arrastar a fórmula vira o loop for: 

// 1. Entrada de dados: matrizes (colunas A e B da planilha)
const projetos = ["Alfa", "Beta", "Gama", "Delta"];
const margens  = [15, 8, -3, 22];

console.log("--- AUDITORIA DE RENTABILIDADE ---");

// 2. "Arrastar a fórmula": percorrer cada linha com o loop for
for (let i = 0; i < margens.length; i++) {
    const nome   = projetos[i];   // célula da coluna A na linha atual
    const margem = margens[i];    // célula da coluna B na linha atual

    // 3. Decisão encadeada: equivalente ao SE(...) aninhado
    if (margem < 0) {
        console.log(`[ALERTA] O Projeto ${nome} está dando prejuízo!`);
    } else if (margem <= 10) {
        console.log(`[ATENÇÃO] O Projeto ${nome} está com baixa lucratividade.`);
    } else {
        console.log(`[OK] O Projeto ${nome} é altamente rentável.`);
    }
}

console.log("--------------------------------");
console.log("Fim da auditoria.");

Resultado esperado ao executar (node ou Console do Navegador):

[OK] O Projeto Alfa é altamente rentável.
[ATENÇÃO] O Projeto Beta está com baixa lucratividade.
[ALERTA] O Projeto Gama está dando prejuízo!
[OK] O Projeto Delta é altamente rentável.

Código Completo para a Demonstração em Sala

Versão comentada e pronta para ser demonstrada. Copie o bloco abaixo em um arquivo auditoria-projetos.js e execute com o comando node auditoria-projetos.js, ou cole no console do navegador (tecla F12): 

// ============================================================
// AUDITORIA DE RENTABILIDADE DE PROJETOS - Aula 23 (PTIC)
// Execute no VS Code (node) ou no Console do Navegador (F12)
// ============================================================

// 1. Entrada de dados: as matrizes (colunas A e B da planilha)
const projetos = ["Alfa", "Beta", "Gama", "Delta"];
const margens  = [15, 8, -3, 22];

console.log("--- AUDITORIA DE RENTABILIDADE ---");

// 2. Loop for: percorre a matriz do primeiro ao último item
for (let i = 0; i < margens.length; i++) {
    const nome   = projetos[i];  // célula da coluna A da linha atual
    const margem = margens[i];   // célula da coluna B da linha atual

    // 3. Classificação: equivalente ao SE(SE(...)) aninhado
    if (margem < 0) {                              // margem menor que 0
        console.log(`[ALERTA] O Projeto ${nome} está dando prejuízo!`);
    } else if (margem <= 10) {                     // margem entre 0 e 10
        console.log(`[ATENÇÃO] O Projeto ${nome} está com baixa lucratividade.`);
    } else {                                        // margem maior que 10
        console.log(`[OK] O Projeto ${nome} é altamente rentável.`);
    }
}

console.log("--------------------------------");
console.log("Fim da auditoria.");

Anatomia do Código

Parte do Código Equivalente na Planilha Significado
const projetos = ["Alfa", ...] Intervalo A2:A5 Matriz com os nomes; cada posição corresponde a uma célula da coluna A.
const margens = [15, 8, -3, 22] Intervalo B2:B5 Matriz com os valores numéricos; cada posição corresponde a uma célula da coluna B.
margens.length Contagem de células preenchidas (CONT.NÚM) Informa quantos itens existem na matriz, definindo o limite do loop.
projetos[i] / margens[i] Células A{linha} e B{linha} da linha atual Acessa o item da posição i (o índice começa em 0).
for (let i = 0; i < margens.length; i++) Arrastar a fórmula até a última linha Inicializa o contador, testa a condição e incrementa a cada volta.
if / else if / else =SE(...; SE(...; ...; ...)) aninhado Decisão encadeada: testa cada faixa de margem até achar a correta.
`[OK] ... ${nome} ...` Valor exibido na célula Template String: interpola variáveis dentro do texto usando crases e ${}.

Desafios para a Turma

  1. Reescreva a auditoria usando um loop while em vez do for. Que cuidados extras foram necessários?
  2. A diretoria quer saber quantos projetos estão dando prejuízo. Crie uma variável acumuladora let projetosEmPrejuizo = 0;, incremente-a dentro do loop quando a margem for negativa e exiba o total ao final.
  3. Adicione à matriz um Projeto Ômega com margem exatamente igual a 10. Qual mensagem ele recebe? E se a condição do segundo bloco fosse margem >= 0 && margem < 10, o diagnóstico mudaria? Justifique.

Dicas para Rodar a Demonstração em Sala

  • Índice começa em 0: margens[0] é o primeiro item. Acessar margens[4] nessa lista geraria undefined, pois só existem índices 0 a 3.
  • Identação: mantenha os blocos do for e do if recuados com TAB — a clareza visual evita "chaves perdidas".
  • Case Sensitive: escreva For com F maiúsculo e o terminal acusará erro SyntaxError. Em JavaScript, estruturas são sempre minúsculas.
  • Loop infinito: se alterar para while, não se esqueça de mudar a variável de controle (i++) dentro do bloco.
