Enunciado

Você foi contratado como auditor financeiro da empresa AuditPro Consultoria. A equipe recebeu o relatório de margens de lucro líquido (%) de quatro projetos contábeis auditados e precisa classificar cada um automaticamente. Sua missão é montar um algoritmo em JavaScript que percorra a lista de projetos e exiba um diagnóstico para cada margem, conforme as regras de negócio:

Margem menor que 0: "[ALERTA] O Projeto [Nome] está dando prejuízo!"
Margem entre 0 e 10 (inclusive): "[ATENÇÃO] O Projeto [Nome] está com baixa lucratividade."
Margem maior que 10: "[OK] O Projeto [Nome] é altamente rentável."

O relatório de origem (que você deve converter em matrizes) contém os seguintes dados:

Projeto Margem de Lucro Líquido (%)
Alfa 15
Beta 8
Gama -3 (Prejuízo)
Delta 22

Execute os passos abaixo e, em seguida, responda às questões.

Passos da Construção

  1. Abra o Visual Studio Code (ou o console do navegador, tecla F12).
  2. Crie um arquivo chamado auditoria-projetos.js.
  3. Declare a matriz das margens: const margens = [15, 8, -3, 22]; e a matriz dos nomes: const projetos = ["Alfa", "Beta", "Gama", "Delta"];
  4. Escreva um loop for que percorra as matrizes do índice 0 até margens.length, guardando a margem e o nome do projeto corrente em variáveis.
  5. Dentro do loop, monte a estrutura condicional encadeada (if / else if / else) aplicando as três regras do enunciado com console.log().
  6. Execute o código no terminal (comando node auditoria-projetos.js) ou no console do navegador e confira se os quatro diagnósticos aparecem corretamente.
  7. Adicione novos projetos às matrizes para testar cenários diferentes e anote os resultados na Questão 2.
