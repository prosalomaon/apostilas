1. Enunciado

Você foi contratado para desenvolver um sistema que gerencia o desempenho de alunos em uma disciplina. O sistema deve ser modular: cada tarefa (cálculos, exibição de resultados e formatação) deve ser feita em uma função ou procedimento separado, evitando a repetição de código.

O programa deverá calcular a média de um aluno a partir de três notas, determinar o conceito (A, B, C, D ou E), verificar se o número é par ou ímpar e exibir um relatório final formatado.

2. Preparação

  • Ambiente: utilize o VS Code (com extensão Java) ou um compilador Java online (ex: OnlineGDB).
  • Conhecimento Prévio: requer domínio de declaração de variáveis, operadores relacionais e lógicos, e a estrutura de métodos (modificadores, tipo de retorno, parâmetros e return).
  • Documentação: consulte o conteúdo da aula 25 sobre Modularização, Funções e Procedimentos.
  • Crie a classe SistemaDesempenho.

4. O Desafio

Implemente o corpo de cada método seguindo as especificações abaixo:

  • imprimirDivisoria: use o laço for para imprimir o caractere recebido o número de vezes indicado em tamanho e finalize com System.out.println().
  • calcularMedia: some as três notas e retorne o resultado da divisão por 3 (utilize divisão por 3.0 ou conte com o fato de as notas serem double).
  • ehPar: retorne true se o resto da divisão de numero por 2 for igual a 0; caso contrário, retorne false.
  • obterConceito: utilize condicionais encadeadas (if/else if) para retornar a letra correspondente à faixa da média, conforme comentários no código.

5. Orientações Finais

  • Função não imprime: as funções calcularMedia, ehPar e obterConceito devem apenas retornar valores. Quem imprime é o main.
  • Retorno correto: o tipo de retorno da função deve casar com o valor devolvido (ex: double para média, boolean para par, e char para conceito).
