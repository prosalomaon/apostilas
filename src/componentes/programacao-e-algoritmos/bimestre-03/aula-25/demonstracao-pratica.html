Enunciado

Esta demonstração coloca em prática o conceito de modularização: observe o mesmo programa escrito de duas formas. O primeiro exemplo concentra todo o processamento em um único bloco gigante dentro do main. O segundo exemplo refatora esse mesmo código, quebrando-o em funções e procedimentos menores, cada um com um nome descritivo e uma única responsabilidade.

O programa gera o relatório de desempenho de uma turma: calcula a média de cada aluno, determina o conceito (A–E), identifica os aprovados e exibe a média geral.

A. Versão Gigante (Sem Modularização)

Tudo em um único método: cálculos, lógica de conceito, contagem e impressão misturados em um só bloco extenso.

public class RelatorioGigante {

    public static void main(String[] args) {
        // TODO: todos os passos amontoados em um único método

        String[] nomes = {"Aline", "Bruno", "Carla", "Diego", "Elias"};
        double[][] notas = {
            {9.5, 8.0, 10.0},
            {5.0, 6.5, 7.0},
            {7.0, 7.5, 6.0},
            {4.0, 5.0, 3.5},
            {10.0, 9.5, 9.0}
        };

        System.out.println("=====================================");
        System.out.println("RELATÓRIO DA TURMA");
        System.out.println("=====================================");

        double[] medias = new double[nomes.length];
        double somaTurma = 0.0;
        int aprovados = 0;

        for (int i = 0; i < nomes.length; i++) {
            double media = (notas[i][0] + notas[i][1] + notas[i][2]) / 3.0;
            medias[i] = media;
            somaTurma = somaTurma + media;

            char conceito;
            if (media >= 9.0) {
                conceito = 'A';
            } else if (media >= 8.0) {
                conceito = 'B';
            } else if (media >= 7.0) {
                conceito = 'C';
            } else if (media >= 6.0) {
                conceito = 'D';
            } else {
                conceito = 'E';
            }

            boolean aprovado = media >= 6.0;
            if (aprovado) {
                aprovados++;
            }

            System.out.println(nomes[i] + ": média " + media
                    + " - Conceito " + conceito
                    + (aprovado ? " - APROVADO" : " - REPROVADO"));
        }

        double mediaTurma = somaTurma / nomes.length;
        System.out.println("-------------------------------------");
        System.out.println("Média da turma: " + mediaTurma);
        System.out.println("Aprovados: " + aprovados + " de " + nomes.length);
    }
}

B. Versão Modular (Funções e Procedimentos)

O mesmo relatório, agora organizado em unidades pequenas e reutilizáveis. Cada sub-rotina tem uma única responsabilidade e o main se torna apenas um "roteiro" que orquestra as chamadas. 

public class RelatorioModular {

    // Procedimento: desenha uma linha divisória
    public static void imprimirLinha(String simbolo, int tamanho) {
        for (int i = 0; i < tamanho; i++) {
            System.out.print(simbolo);
        }
        System.out.println();
    }

    // Função: retorna a média de três notas
    public static double calcularMedia(double n1, double n2, double n3) {
        return (n1 + n2 + n3) / 3.0;
    }

    // Função: retorna o conceito a partir da média
    public static char obterConceito(double media) {
        if (media >= 9.0) return 'A';
        else if (media >= 8.0) return 'B';
        else if (media >= 7.0) return 'C';
        else if (media >= 6.0) return 'D';
        else return 'E';
    }

    // Função: retorna se o aluno foi aprovado
    public static boolean foiAprovado(double media) {
        return media >= 6.0;
    }

    // Função: retorna a média geral da turma
    public static double calcularMediaTurma(double[] medias) {
        double soma = 0.0;
        for (int i = 0; i < medias.length; i++) {
            soma = soma + medias[i];
        }
        return soma / medias.length;
    }

    public static void main(String[] args) {
        String[] nomes = {"Aline", "Bruno", "Carla", "Diego", "Elias"};
        double[][] notas = {
            {9.5, 8.0, 10.0},
            {5.0, 6.5, 7.0},
            {7.0, 7.5, 6.0},
            {4.0, 5.0, 3.5},
            {10.0, 9.5, 9.0}
        };

        imprimirLinha("=", 40);
        System.out.println("RELATÓRIO DA TURMA");
        imprimirLinha("=", 40);

        double[] medias = new double[nomes.length];
        int aprovados = 0;

        for (int i = 0; i < nomes.length; i++) {
            double media = calcularMedia(notas[i][0], notas[i][1], notas[i][2]);
            medias[i] = media;

            if (foiAprovado(media)) {
                aprovados++;
            }

            System.out.println(nomes[i] + ": média " + media
                    + " - Conceito " + obterConceito(media)
                    + (foiAprovado(media) ? " - APROVADO" : " - REPROVADO"));
        }

        System.out.println("-------------------------------------------");
        System.out.println("Média da turma: " + calcularMediaTurma(medias));
        System.out.println("Aprovados: " + aprovados + " de " + nomes.length);
    }
}

O que mudou?

  • Legibilidade: O main agora é curto e descreve, de cima para baixo, os passos do relatório.
  • Reutilização: calcularMedia, obterConceito e imprimirLinha podem ser usadas em qualquer outro trecho do sistema.
  • Manutenção: Para mudar a regra de conceito, basta alterar apenas obterConceito. Para trocar o traço da divisória, altere apenas a chamada de imprimirLinha.
  • Teste isolado: Cada função pode ser testada independentemente (ex: calcularMedia(10, 9, 8) deve retornar 9.0).

Dica de demonstração em sala

  1. Compile e execute primeiro o RelatorioGigante.
  2. Depois compile e execute o RelatorioModular.
  3. Observe que a saída é idêntica, mas a versão modular é mais fácil de ler, manter e testar.
  4. Pergunte aos alunos: para adicionar um novo tipo de cálculo (ex: desvio padrão), em qual das versões seria mais fácil?
