1. Visão Geral do Projeto

Este projeto integra todos os conteúdos estudados no terceiro bimestre: vetores, matrizes, Strings e modularização (funções com parâmetros e retorno). Você irá construir um sistema completo de gerenciamento de estoque para uma loja de materiais escolares.

Objetivos de Aprendizagem

  • Aplicar vetores para armazenar listas de produtos e preços.
  • Utilizar matrizes para controlar entradas e saídas ao longo do tempo.
  • Manipular Strings para cadastro e exibição de informações.
  • Estruturar o programa com funções modulares reutilizáveis.
  • Praticar a comunicação entre módulos via parâmetros e retorno.
  • Compreender o escopo de variáveis locais e globais.

2. Preparação

  • Ambiente: utilize o VS Code (com extensão Java) ou um compilador Java online (ex: OnlineGDB).
  • Conhecimento Prévio: vetores, matrizes, Strings, funções com parâmetros e retorno, escopo de variáveis.
  • Crie a classe SistemaEstoque.

3. Estrutura do Sistema

O sistema será composto por módulos (funções) que realizam tarefas específicas:

Módulo Responsabilidade Conteúdo Utilizado
cadastrarProdutos() Preencher vetores de nomes, preços e quantidades Vetores, Strings, Entrada de dados
exibirEstoque() Listar todos os produtos com suas informações Vetores, Laços, Strings
registrarEntrada() Adicionar quantidade a um produto existente Vetores, Busca sequencial
registrarSaida() Remover quantidade de um produto (com validação) Vetores, Condicionais
buscarProduto() Encontrar um produto pelo nome Vetores, Strings (.equals, .toLowerCase)
calcularValorTotal() Retornar o valor total do estoque Vetores, Função com retorno
relatorioMensal() Exibir movimentação do mês usando matriz Matrizes, Laços aninhados

4. Estrutura de Dados

Os dados do sistema serão armazenados em vetores paralelos e uma matriz:

// Vetores paralelos (cada índice representa um produto)
String[] nomes = new String[5];      // Nomes dos produtos
double[] precos = new double[5];     // Preços unitários
int[] quantidades = new int[5];      // Quantidade em estoque

// Matriz de movimentação (produto x mês)
// movimentacao[produto][mes] = quantidade movimentada no mês
int[][] movimentacao = new int[5][12]; // 5 produtos, 12 meses

6. O Desafio

Implemente cada função seguindo as especificações:

  • cadastrarProdutos(): peça ao usuário o nome, preço e quantidade de cada produto. Preencha os 3 vetores.
  • exibirEstoque(): exiba uma tabela formatada com todos os produtos, mostrando nome, preço e quantidade.
  • registrarEntrada(): peça o nome do produto e a quantidade a adicionar. Use busca sequencial para encontrar o índice. Atualize a matriz de movimentação no mês atual (use 0 como mês fixo para simplificar).
  • registrarSaida(): peça o nome do produto e a quantidade a remover. Valide se há estoque suficiente. Atualize a matriz.
  • buscarProduto(): peça o nome e use .toLowerCase() e .equals() para busca case-insensitive.
  • calcularValorTotal(): retorne a soma de (preço × quantidade) de todos os produtos.
  • relatorioMensal(): exiba a matriz de movimentação formatada com nomes nas linhas e meses nas colunas.

7. Orientações Finais

8. Requisitos Funcionais

  1. Cadastro de até 5 produtos (nome, preço e quantidade).
  2. Exibição formatada de todos os produtos em estoque.
  3. Registro de entradas e saídas com atualização de quantidade.
  4. Busca de produto por nome (case-insensitive).
  5. Cálculo do valor total do estoque.
  6. Relatório mensal de movimentação usando matriz.
  7. Menu interativo com loop até o usuário escolher sair.
