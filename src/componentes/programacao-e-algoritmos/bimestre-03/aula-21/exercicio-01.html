1. Enunciado

Você está desenvolvendo um módulo para um jogo de RPG que gerencia os pontos de vida (HP) de uma equipe de 4 aventureiros. O sistema deve permitir a entrada do HP de cada herói e, ao final, informar o HP total da equipe e identificar qual o herói com a maior saúde atual.

2. Preparação

  • Ambiente: Utilize o VS Code (com extensão Java) ou um compilador Java online (ex: OnlineGDB).
  • Conhecimento Prévio: Requer domínio de laços for e da entrada de dados com Scanner.
  • Documentação: Consulte o conteúdo da aula 21 sobre vetores para relembrar o uso de .length e da busca de máximo.
  • Certifique-se de importar java.util.Scanner para entrada de dados e declare um vetor de inteiros com tamanho 4.

3. Código Base (Exemplo de Demonstração)

Este código já captura o HP de cada aventureiro e o armazena nas posições do vetor. Sua missão é completar a parte comentada. 

import java.util.Scanner;

public class GestaoEquipe {
    public static void main(String[] args) {
        Scanner leitor = new Scanner(System.in);
        int[] aventureirosHP = new int[4];

        // Entrada de dados
        for (int i = 0; i < aventureirosHP.length; i++) {
            System.out.print("Digite o HP do aventureiro " + (i + 1) + ": ");
            aventureirosHP[i] = leitor.nextInt();
        }

        // Espaço para a lógica do desafio

        leitor.close();
    }
}

4. O Desafio

Implemente as seguintes funcionalidades após a entrada de dados:

  • Cálculo do Total: Utilize um laço para somar o HP de todos os aventureiros e exiba o resultado.
  • Busca de Máximo: Encontre e exiba o maior valor de HP presente no vetor aventureiros.
  • Status de Alerta: Verifique se algum aventureiro está com HP menor que 10. Se sim, imprima "Alerta: Herói em perigo!".

Requisitos técnicos:

  • Utilize a propriedade .length em seus laços para garantir que o código funcione mesmo se o tamanho da equipe mudar.
  • Para encontrar o máximo, assuma que o primeiro elemento é o maior e compare-o com os demais dentro do laço.
  • Faça o commit do seu código caso esteja utilizando Git, documentando a criação do módulo de vetores.

5. Orientações Finais

  • Teste de Mesa: antes de rodar, simule a entrada HP = 25, 8, 40, 12 e verifique se o total (85), o máximo (40) e o alerta são exibidos corretamente.
  • Formatação da saída: exiba mensagens claras, como "HP total da equipe: 85" e "Aventureiro com maior HP: 40".
  • Indentação: mantenha o código organizado para facilitar a leitura e a correção.
