Teoria & Conceitos

Esta aula apresenta os Vetores (também chamados de arrays unidimensionais), a primeira estrutura de dados que vamos estudar em Java. Com eles, deixamos de armazenar um único valor por variável e passamos a guardar dezenas, centenas ou até milhares de valores relacionados em um único bloco de memória.

1. O que é um Vetor?

Um vetor é uma estrutura de dados que consiste em uma sequência numerada de itens, onde todos os itens são do mesmo tipo (homogêneos). Enquanto uma variável comum (escalar) armazena apenas um valor por vez, um vetor permite armazenar um conjunto de valores sob um único nome, diferenciando-os por um índice.

Veja a diferença na prática:

// Variável escalar: apenas um valor por vez
double nota1 = 7.5;
double nota2 = 8.0;
double nota3 = 9.2;

// Vetor: vários valores do mesmo tipo sob um único nome
double[] notas = {7.5, 8.0, 9.2};

System.out.println(notas[0]); // 7.5
System.out.println(notas[1]); // 8.0
System.out.println(notas[2]); // 9.2

Note que, sem vetores, escreveríamos uma variável para cada nota. Com um vetor, uma única estrutura consegue guardar todas elas, e ainda podemos percorrer os elementos com laços de repetição, como veremos adiante.

2. Componentes Fundamentais

Todo vetor possui três componentes essenciais:

  • Tipo Base: é o tipo de dado comum a todos os elementos do vetor (ex: int, double, String).
  • Comprimento (Length): é o número total de elementos que o vetor pode conter, definido no momento da sua criação. Uma vez criado, seu tamanho não pode ser alterado.
  • Índice (Index): é a posição numérica de um item no vetor. Em Java (e na maioria das linguagens modernas), a contagem começa sempre em 0. Se um vetor tem comprimento N, seus índices válidos vão de 0 até N−1.

Pense em um prédio de 5 andares onde o térreo é o andar 0: o "último" andar é o 4, não o 5. Com vetores funciona igual. Observe o mapeamento de um vetor de 5 elementos:

Índice 0 1 2 3 4
Valor armazenado 10 20 30 40 50 
int[] numeros = new int[5]; // comprimento 5: índices de 0 a 4

System.out.println(numeros.length); // Imprime: 5
System.out.println(numeros[4]);     // Último elemento
// System.out.println(numeros[5]);  // ERRO! Índice 5 não existe

3. Vetores em Java: Objetos e Valores Padrão

Em Java, vetores são tratados como objetos. Isso significa que eles precisam ser instanciados com o operador new, o que reserva um bloco contíguo de memória para os dados. Quando um vetor é criado, o Java preenche automaticamente seus elementos com valores padrão:

Tipo do vetor Valor padrão de cada elemento
int, double, long... 0 (ou 0.0)
boolean false
String, objetos em geral null 
int[] inteiros = new int[3];
double[] reais = new double[2];
boolean[] logicos = new boolean[2];
String[] textos = new String[2];

System.out.println(inteiros[0]); // 0.0? Não: 0 (inteiro)
System.out.println(reais[0]);    // 0.0
System.out.println(logicos[0]);  // false
System.out.println(textos[0]);   // null

4. Declaração e Criação

Existem diferentes formas de criar um vetor em Java:

4.1. Declaração seguida de criação com new

Aqui definimos o tipo, o nome e, com new, o tamanho. O vetor nasce preenchido com os valores padrão do tipo (todos os elementos valem 0). 

// Declaração seguida de criação (tamanho 5, preenchido com zeros)
int[] notas = new int[5];

// Também é possível separar declaração e criação
double[] precos;
precos = new double[10]; // cria um vetor de 10 posições, tudo 0.0

4.2. Criação com inicialização direta

Quando já sabemos os valores, usamos as chaves { }. O tamanho é determinado automaticamente pela quantidade de valores informados. 

// Criação com inicialização direta (tamanho determinado pelos valores)
double[] precos = {19.90, 25.00, 10.50, 4.99}; // 4 elementos

String[] diasSemana = {"Segunda", "Terça", "Quarta", "Quinta", "Sexta"};
char[] vogais = {'a', 'e', 'i', 'o', 'u'};

4.3. Atribuição após a criação

É possível criar o vetor "vazio" e preencher cada posição depois:

int[] idades = new int[3];
idades[0] = 18;
idades[1] = 21;
idades[2] = 35;

System.out.println("Idades: " + idades[0] + ", " + idades[1] + ", " + idades[2]);

5. Acesso e Modificação

Utilizamos colchetes [ ] para acessar uma "gaveta" específica da memória. O valor entre colchetes é o índice da posição que queremos ler ou alterar. 

notas[0] = 85; // Atribui valor à primeira posição
System.out.println("Segunda nota: " + notas[1]); // Acessa a segunda posição

Um cuidado importante: o índice pode ser qualquer expressão que resulte em um número inteiro, inclusive o resultado de uma operação ou uma variável controlada por um laço: 

int[] numeros = {10, 20, 30, 40};

int posicao = 2;
System.out.println(numeros[posicao]);       // 30 (valor na posição 2)

int soma = numeros[0] + numeros[3];         // 10 + 40
System.out.println("Soma: " + soma);        // 50

numeros[1] = numeros[1] + 5;                // agora a posição 1 vale 25
System.out.println(numeros[1]);             // 25

6. Processamento com Laços (Acesso Sequencial)

A forma mais eficiente de percorrer um vetor é utilizando o laço for, usando a propriedade .length para controlar o limite. Assim o código continua correto mesmo que o tamanho do vetor mude.

Exemplo: Somar todos os elementos de um vetor

double[] valores = {10.5, 20.0, 30.5};
double soma = 0;

for (int i = 0; i < valores.length; i++) {
    soma += valores[i];
}

System.out.println("Soma total: " + soma); // 61.0

Exemplo: Calcular a média dos elementos

double[] notas = {8.0, 7.5, 9.0, 6.5};
double soma = 0;

for (int i = 0; i < notas.length; i++) {
    soma += notas[i];
}

double media = soma / notas.length;
System.out.println("Média: " + media); // 7.75

Exemplo: Encontrar o maior valor

int[] alturas = {165, 178, 150, 189, 172};
int maior = alturas[0]; // assume que o primeiro é o maior

for (int i = 1; i < alturas.length; i++) {
    if (alturas[i] > maior) {
        maior = alturas[i];
    }
}

System.out.println("Maior altura: " + maior); // 189

7. O Laço for-each (Enhanced for)

Quando precisamos apenas ler os valores do vetor, sem saber o índice, podemos usar a versão simplificada do laço, chamada de enhanced for ou for-each. Ela percorre cada elemento na ordem. 

String[] frutas = {"Maçã", "Banana", "Uva"};

// O laço for-each lê cada elemento, um por um
for (String fruta : frutas) {
    System.out.println("Fruta: " + fruta);
}

// Saída:
// Fruta: Maçã
// Fruta: Banana
// Fruta: Uva

8. Cópia de Vetores: Referência vs. Cópia Real

Atribuição de Referência: se você fizer vetorA = vetorB, você não está copiando os dados, mas sim fazendo as duas variáveis apontarem para o mesmo objeto na memória. 

int[] vetorA = {1, 2, 3};
int[] vetorB = vetorA; // as duas variáveis apontam para o MESMO vetor

vetorB[0] = 99;

System.out.println(vetorA[0]); // 99! vetorA também mudou

Para copiar os dados de verdade, usamos um laço ou o comando System.arraycopy(): 

int[] original = {1, 2, 3};
int[] copia = new int[original.length];

// Cópia manual com laço
for (int i = 0; i < original.length; i++) {
    copia[i] = original[i];
}

// OU com System.arraycopy:
// System.arraycopy(original, 0, copia, 0, original.length);

copia[0] = 99;
System.out.println(original[0]); // 1 (não mudou)
System.out.println(copia[0]);    // 99

9. Vetores de Strings

Vetores podem armazenar qualquer tipo de dado, inclusive objetos. Cada posição de um vetor de String guarda uma referência para uma cadeia de caracteres. 

String[] convidados = new String[3];
convidados[0] = "Ana";
convidados[1] = "Bruno";
convidados[2] = "Carla";

for (int i = 0; i < convidados.length; i++) {
    System.out.println("Convidado " + (i + 1) + ": " + convidados[i]);
}

Resumo

  • Vetor é uma sequência numerada de valores do mesmo tipo.
  • Índices começam em 0 e vão até o comprimento menos 1.
  • Vetores são objetos: usam new e têm a propriedade .length.
  • Use o laço for + .length para percorrer com segurança.
  • vetorA = vetorB copia a referência, não os dados.

Exemplo de Código

Exemplo 1: Somando Elementos de um Vetor

Programa completo que soma todos os valores armazenados no vetor.

public class SomaVetor {
    public static void main(String[] args) {
        int[] numeros = {10, 20, 30, 40};
        int soma = 0;

        for (int i = 0; i < numeros.length; i++) {
            soma += numeros[i];
        }

        System.out.println("Soma: " + soma); // 100
    }
}

Exemplo 2: Média de Notas de uma Turma

Calcula a média final considerando 4 notas armazenadas em um vetor.

public class MediaNotas {
    public static void main(String[] args) {
        double[] notas = {7.0, 8.5, 6.0, 9.5};
        double soma = 0;

        for (double nota : notas) {
            soma += nota;
        }

        double media = soma / notas.length;
        System.out.println("Média da turma: " + media); // 7.75
    }
}

Exemplo 3: Maior e Menor Valor

Percorre o vetor uma única vez encontrando o maior e o menor elemento.

public class MaiorMenor {
    public static void main(String[] args) {
        int[] valores = {45, 12, 78, 33, 90, 5};
        int maior = valores[0];
        int menor = valores[0];

        for (int i = 1; i < valores.length; i++) {
            if (valores[i] > maior) {
                maior = valores[i];
            }
            if (valores[i] < menor) {
                menor = valores[i];
            }
        }

        System.out.println("Maior: " + maior); // 90
        System.out.println("Menor: " + menor); // 5
    }
}

Exemplo 4: Contando Elementos que Satisfazem uma Condição

Conta quantos números do vetor são pares.

public class ContaPares {
    public static void main(String[] args) {
        int[] numeros = {2, 7, 10, 13, 22, 31};
        int quantidadePares = 0;

        for (int i = 0; i < numeros.length; i++) {
            if (numeros[i] % 2 == 0) {
                quantidadePares++;
            }
        }

        System.out.println("Pares: " + quantidadePares); // 3
    }
}

Exemplo 5: Vetor de Strings

Lista de convidados exibida com um laço for-each.

public class ListaConvidados {
    public static void main(String[] args) {
        String[] convidados = {"Ana", "Bruno", "Carla", "Diego"};

        System.out.println("Convidados:");
        for (String nome : convidados) {
            System.out.println("- " + nome);
        }
    }
}

Exemplo 6: Busca de um Valor no Vetor

Verifica se um determinado valor está presente no vetor.

public class BuscaValor {
    public static void main(String[] args) {
        int[] numeros = {15, 8, 42, 3, 27};
        int procurado = 42;
        boolean encontrado = false;

        for (int i = 0; i < numeros.length; i++) {
            if (numeros[i] == procurado) {
                encontrado = true;
                break; // não precisa continuar procurando
            }
        }

        System.out.println("Encontrado? " + encontrado); // true
    }
}

Exemplo 7: Invertendo a Ordem dos Elementos

Inverte o vetor "no lugar" (in-place), trocando os elementos das pontas.

public class InverteVetor {
    public static void main(String[] args) {
        int[] numeros = {1, 2, 3, 4, 5};

        for (int i = 0; i < numeros.length / 2; i++) {
            int temp = numeros[i];
            numeros[i] = numeros[numeros.length - 1 - i];
            numeros[numeros.length - 1 - i] = temp;
        }

        for (int n : numeros) {
            System.out.print(n + " "); // 5 4 3 2 1
        }
    }
}

Exemplo 8: Preenchendo um Vetor com Dados do Usuário

Lê 4 notas pelo teclado, armazena no vetor e exibe os valores lidos.

import java.util.Scanner;

public class LendoNotas {
    public static void main(String[] args) {
        Scanner leitor = new Scanner(System.in);
        double[] notas = new double[4];

        for (int i = 0; i < notas.length; i++) {
            System.out.print("Digite a nota " + (i + 1) + ": ");
            notas[i] = leitor.nextDouble();
        }

        System.out.println("Notas informadas:");
        for (double nota : notas) {
            System.out.println("- " + nota);
        }

        leitor.close();
    }
}

Exemplo 9: Copiando um Vetor com System.arraycopy

Usa o método pronto do Java para copiar todos os elementos.

public class CopiaVetor {
    public static void main(String[] args) {
        int[] original = {5, 10, 15};
        int[] destino = new int[original.length];

        // Copia: vetor origem, posição inicial, destino, posição inicial, quantidade
        System.arraycopy(original, 0, destino, 0, original.length);

        destino[1] = 99;

        System.out.println(original[1]); // 10 (origem intacta)
        System.out.println(destino[1]);  // 99 (cópia alterada)
    }
}

Dicas & Lembretes

  • Erro de Índice: o erro mais comum é o ArrayIndexOutOfBoundsException, que ocorre ao tentar acessar um índice negativo ou maior/igual ao comprimento do vetor.
  • O Índice "N": lembre-se que em um vetor de tamanho 10, o índice 10 não existe; o último é o 9.
  • Atribuição de Referência: se você fizer vetorA = vetorB, você não está copiando os dados, mas sim fazendo as duas variáveis apontarem para o mesmo objeto na memória. Para copiar, use um laço ou o comando System.arraycopy().
  • Sempre use .length: prefira for (int i = 0; i < vetor.length; i++) em vez de números fixos. Assim o código continua funcionando se o vetor mudar de tamanho.
  • Primeira posição é 0: ao exibir a posição "humana" de um elemento, lembre-se de somar 1 ao índice, como em (i + 1).
  • for-each é para leitura: o laço for (int n : numeros) não permite alterar o vetor; ele apenas entrega uma cópia do valor de cada posição.

Como aplicar na Prática

Em projetos reais, os vetores são utilizados em cenários como:

  • Sistemas Acadêmicos: armazenar uma lista de notas de uma turma para calcular a média e encontrar a maior nota.
  • Desenvolvimento de Jogos: gerenciar o inventário de um personagem ou as coordenadas X e Y de múltiplos inimigos na tela.
  • Finanças: registrar o histórico de lucros mensais de uma empresa ao longo de um ano.
  • Processamento de Texto: analisar frases como cadeias de caracteres (Strings), onde cada letra ocupa uma posição.
  • Controle de Estoque: guardar as quantidades de cada produto e verificar quais estão abaixo do mínimo (reposição automática).
  • Estatísticas Esportivas: acumular os pontos marcados por cada jogador ao longo de uma temporada.

Em todos esses casos, a lógica é a mesma: agrupar dados do mesmo tipo, acessar cada um pelo índice e processar o conjunto com laços.
