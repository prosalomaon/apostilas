1. Enunciado

Crie um sistema que armazene os nomes de 5 heróis da sua equipe. Após cadastrá-los, o usuário deve poder digitar o nome de um herói para verificar se ele faz parte da equipe e em qual posição ele está escalado.

2. Preparação

  • Ambiente: utilize o VS Code (com extensão Java) ou um compilador Java online (ex: OnlineGDB).
  • Conhecimento Prévio: requer domínio de vetores de String, laços for e entrada de dados com Scanner.
  • Documentação: consulte o conteúdo da aula 22 sobre preenchimento e busca em vetores.
  • Crie uma classe chamada LocalizadorEquipe.

3. Código Base

Este código já realiza o preenchimento do vetor com os nomes dos heróis. Sua missão é completar a parte da busca. 

import java.util.Scanner;

public class LocalizadorEquipe {
    public static void main(String[] args) {
        Scanner leitor = new Scanner(System.in);
        String[] herois = new String[5];

        // Preenchimento do vetor
        for (int i = 0; i < herois.length; i++) {
            System.out.print("Cadastre o herói " + (i + 1) + ": ");
            herois[i] = leitor.nextLine();
        }

        // O Desafio começa aqui...

        leitor.close();
    }
}

4. O Desafio

Implemente as seguintes funcionalidades após o preenchimento do vetor:

  • Entrada do Usuário: solicite ao usuário o nome de um herói para busca.
  • Busca Linear: implemente um laço for para percorrer o vetor e encontrar o nome digitado.
  • Comparação Flexível: use o método .equalsIgnoreCase() para comparar as Strings, permitindo que a busca funcione independentemente de letras maiúsculas ou minúsculas.
  • Saída: exiba "Herói [Nome] encontrado na posição [i]" ou "Herói não localizado".

Requisitos técnicos:

  • Utilize a propriedade .length no laço de busca.
  • Inicialize uma variável int posicao = -1 antes do laço para armazenar o resultado da busca.
  • Use break ao encontrar o herói para interromper a busca.

5. Orientações Finais

  • Teste de Mesa: se cadastrar "Artur" na posição 0, a busca deve retornar o índice 0.
  • Formatação da saída: exiba mensagens claras, como "Herói Artur encontrado na posição 0".
  • Desafio Extra: se sobrar tempo, tente exibir a lista completa de heróis em ordem inversa após a busca.
