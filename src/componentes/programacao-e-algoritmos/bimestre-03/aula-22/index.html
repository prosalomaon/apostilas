Teoria & Conceitos

Nesta aula vamos aprofundar o uso de vetores aprendendo três operações fundamentais: preenchimento, busca e localização de extremos. Essas técnicas são a base para resolver a maioria dos problemas que envolvem conjuntos de dados em Java.

1. Preenchimento de Vetores

Preencher um vetor consiste em atribuir valores a cada uma de suas posições (índices). Existem três formas principais de realizar essa tarefa em Java:

  • Inicialização Direta: ocorre no momento da declaração, quando os valores já são conhecidos.
  • Atribuição Manual: atribuir um valor a uma posição específica usando seu índice.
  • Preenchimento Dinâmico (Laços): é a forma mais eficiente, utilizando uma estrutura de repetição (geralmente o laço for) para percorrer o vetor do índice 0 até comprimento - 1. 
// 1. Inicialização Direta
int[] numeros = {10, 20, 30, 40, 50};

// 2. Atribuição Manual
String[] cores = new String[3];
cores[0] = "Azul";
cores[1] = "Vermelho";
cores[2] = "Verde";

// 3. Preenchimento Dinâmico (via Scanner)
import java.util.Scanner;

double[] temps = new double[7];
Scanner leitor = new Scanner(System.in);

for (int i = 0; i < temps.length; i++) {
    System.out.print("Digite a temperatura do dia " + (i + 1) + ": ");
    temps[i] = leitor.nextDouble();
}

Dica técnica: ao preencher vetores via teclado, é recomendável usar o atributo .length no controle do laço para garantir que o código seja flexível a mudanças no tamanho do array.

2. Busca em Vetores (Linear Search)

A operação de busca serve para verificar se um determinado valor (chamado de alvo ou chave) está presente no conjunto de dados. A técnica mais simples é a Busca Linear.

  • Funcionamento: o programa percorre o vetor item por item, comparando cada elemento com o valor procurado.
  • Resultados: se o valor for encontrado, o programa retorna o índice da posição; caso contrário, costuma-se retornar um valor sinalizador, como -1, para indicar que o item não existe no vetor. 
int[] ids = {101, 202, 305, 407, 500};
int alvo = 305;
int posicao = -1;

for (int i = 0; i < ids.length; i++) {
    if (ids[i] == alvo) {
        posicao = i; // Encontrou o alvo!
        break;       // Interrompe a busca após encontrar
    }
}

if (posicao != -1) {
    System.out.println("ID encontrado na posição: " + posicao);
} else {
    System.out.println("ID não encontrado.");
}

3. Localização de Extremos (Maior e Menor)

Uma variação da busca é a localização do maior ou menor valor. Para isso, utiliza-se a estratégia da hipótese inicial: assume-se que o primeiro elemento (vetor[0]) é o maior e, em seguida, percorre-se o restante do vetor comparando e atualizando essa variável sempre que um valor superior for encontrado. 

double[] notas = {7.5, 9.2, 6.8, 10.0, 8.5};
double maiorNota = notas[0]; // Hipótese inicial

for (int i = 1; i < notas.length; i++) {
    if (notas[i] > maiorNota) {
        maiorNota = notas[i]; // Atualização do maior valor
    }
}
System.out.println("A maior nota é: " + maiorNota);

Exemplo de Código

Exemplo 1: Preenchimento com Entrada do Usuário

Neste exemplo, preenchemos um vetor de temperaturas coletadas durante uma semana. 

import java.util.Scanner;

public class PreencherVetor {
    public static void main(String[] args) {
        Scanner leitor = new Scanner(System.in);
        double[] temps = new double[7]; // Vetor para 7 dias

        for (int i = 0; i < temps.length; i++) {
            System.out.print("Digite a temperatura do dia " + (i + 1) + ": ");
            temps[i] = leitor.nextDouble(); // Preenchimento dinâmico
        }

        System.out.println("\nTemperaturas registradas:");
        for (int i = 0; i < temps.length; i++) {
            System.out.println("Dia " + (i + 1) + ": " + temps[i] + "°C");
        }

        leitor.close();
    }
}

Exemplo 2: Busca Linear de um Valor

Verificando se um número específico está presente em uma lista de IDs. 

public class BuscaLinear {
    public static void main(String[] args) {
        int[] ids = {101, 202, 305, 407, 500};
        int alvo = 305;
        int posicao = -1;

        for (int i = 0; i < ids.length; i++) {
            if (ids[i] == alvo) {
                posicao = i; // Encontrou o alvo!
                break;       // Interrompe a busca após encontrar
            }
        }

        if (posicao != -1) {
            System.out.println("ID encontrado na posição: " + posicao);
        } else {
            System.out.println("ID não encontrado.");
        }
    }
}

Exemplo 3: Encontrando o Maior Valor

Localizando a nota mais alta em uma turma.

public class MaiorNota {
    public static void main(String[] args) {
        double[] notas = {7.5, 9.2, 6.8, 10.0, 8.5};
        double maiorNota = notas[0]; // Hipótese inicial

        for (int i = 1; i < notas.length; i++) {
            if (notas[i] > maiorNota) {
                maiorNota = notas[i]; // Atualização do maior valor
            }
        }
        System.out.println("A maior nota é: " + maiorNota);
    }
}

Dicas & Lembretes

  • Cuidado com os Limites: sempre use < ao comparar com .length (ex: i < lista.length). Usar <= causará um erro de "Índice fora dos limites" (ArrayIndexOutOfBoundsException), pois a última posição é sempre tamanho - 1.
  • Sentinelas em Busca: se o objetivo é apenas saber se o item existe, uma variável boolean pode bastar. Se precisar da posição, use um int iniciado em -1.
  • Eficiência: a busca linear é excelente para vetores pequenos ou desordenados. Para grandes volumes de dados ordenados, existem métodos mais rápidos (como a busca binária), que serão estudados futuramente.
  • Hipótese Inicial: ao buscar o maior ou menor valor, sempre inicie com o primeiro elemento do vetor e comece o laço pelo índice 1.
  • Comparação de Strings: ao buscar nomes em vetores de String, use .equalsIgnoreCase() para ignorar diferenças de maiúsculas e minúsculas.

Como aplicar na Prática

  • Controle de Estoque: buscar um produto pelo código de barras em um vetor de inventário.
  • Sistemas de RH: encontrar o funcionário com o maior tempo de casa para conceder um bônus.
  • Processamento de Sinais: filtrar ruídos em uma sequência de leituras de sensores, eliminando valores fora de uma faixa permitida.
