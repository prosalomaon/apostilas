1. Enunciado

Você é responsável por criar um sistema simples para gerenciar as notas de uma turma. Cada aluno possui 4 notas bimestrais. Seu programa deve armazenar as notas em uma matriz, calcular a média de cada aluno e identificar os alunos aprovados (média >= 7.0).

2. Preparação

  • Ambiente: utilize o VS Code (com extensão Java) ou um compilador Java online (ex: OnlineGDB).
  • Conhecimento Prévio: requer domínio de declaração de matrizes, laços aninhados e acesso a elementos por índice.
  • Documentação: consulte o conteúdo da aula 24 sobre Matrizes.
  • Crie a classe CalculadoraNotas.

3. Código Base

Este código já possui a matriz de notas preenchida. Sua missão é implementar todo o processamento solicitado. 

public class CalculadoraNotas {
    public static void main(String[] args) {
        // notas[aluno][bimestre] — 4 alunos, 4 bimestres
        double[][] notas = {
            { 8.0, 7.5, 9.0, 6.5 },   // Aluno 0
            { 5.0, 6.0, 4.5, 7.0 },   // Aluno 1
            { 9.5, 8.0, 10.0, 9.0 },  // Aluno 2
            { 6.0, 5.5, 7.0, 6.0 }    // Aluno 3
        };

        // Implemente o desafio abaixo

    }
}

4. O Desafio

Implemente as seguintes funcionalidades:

  • Exibição da Matriz: exiba todas as notas da turma em formato de tabela, mostrando o número do aluno e suas 4 notas.
  • Cálculo da Média: para cada aluno, calcule a média das 4 notas e exiba o resultado ao lado do nome/desenho do aluno.
  • Verificação de Aprovação: se a média for maior ou igual a 7.0, exiba "Aprovado"; caso contrário, exiba "Reprovado".
  • Soma Geral: ao final, calcule e exiba a soma de todas as notas da turma.
  • Maior Nota: encontre e exiba a maior nota de toda a matriz, indicando qual aluno e qual bimestre ela ocorreu.

5. Orientações Finais

  • Estrutura do Laço: utilize dois laços for aninhados — o externo para percorrer os alunos e o interno para percorrer as notas de cada aluno.
  • Cuidado com Índices: lembre-se de que os índices começam em 0. O aluno 0 é o primeiro, o aluno 3 é o último.
  • Saída Esperada: para os dados fornecidos, a saída deve ser semelhante a: 
=== Notas da Turma ===
Aluno 1: 8.0 | 7.5 | 9.0 | 6.5 → Média: 7.75 → Aprovado
Aluno 2: 5.0 | 6.0 | 4.5 | 7.0 → Média: 5.62 → Reprovado
Aluno 3: 9.5 | 8.0 | 10.0 | 9.0 → Média: 9.12 → Aprovado
Aluno 4: 6.0 | 5.5 | 7.0 | 6.0 → Média: 6.12 → Reprovado

Soma de todas as notas: 114.0
Maior nota: 10.0 (Aluno 3, Bimestre 3)
