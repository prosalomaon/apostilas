Teoria & Conceitos

Nesta aula vamos estudar as Matrizes (arrays multidimensionais), estruturas de dados que nos permitem trabalhar com tabelas, grades e dados bidimensionais organizados em linhas e colunas.

1. O que é uma Matriz?

Enquanto um vetor (array unidimensional) representa uma sequência linear de elementos, uma matriz é uma variável composta homogênea estruturada em múltiplas dimensões. A matriz mais comum é a bidimensional (2D), que pode ser visualizada como uma grade retangular ou planilha:

  • Linhas (Rows): Representam a primeira dimensão da matriz.
  • Colunas (Columns): Representam a segunda dimensão da matriz.

2. Matrizes na Memória

Embora visualizemos uma matriz como uma tabela física de duas dimensões, a memória principal do computador é essencialmente linear (um bloco sequencial de bytes). Em Java, uma matriz bidimensional é implementada como um array de arrays. Isso significa que a matriz é um objeto que contém referências para múltiplos vetores unidimensionais, cada um representando uma linha da tabela.

Por conta dessa arquitetura, Java nos dá extrema flexibilidade:

  • matriz.length nos dá o número de linhas da matriz.
  • matriz[i].length nos dá o número de colunas daquela linha específica.
  • As linhas não precisam necessariamente ter o mesmo tamanho (embora a criação padrão gere linhas uniformes).

2.1. Declaração e Instanciação em Java

Para criar uma matriz em Java, utilizamos dois pares de colchetes [][].

Criação Padrão (Sem valores iniciais):

Dizemos ao Java o tipo base, a quantidade de linhas e a quantidade de colunas. Ao serem criadas, as posições numéricas são automaticamente inicializadas com 0 (ou 0.0), booleanas com false e objetos com null. 

// Declara uma matriz de números decimais com 3 linhas e 4 colunas (tabela 3x4)
double[][] tabelaLucros = new double[3][4];

Inicialização Direta (Literal):

Se já conhecemos os dados antes de rodar o programa, podemos usar chaves aninhadas para definir as linhas e colunas diretamente: 

// Matriz de inteiros 3x4 inicializada manualmente
int[][] matrizNumeros = {
    { 1, 0, 12, -1 },  // Linha 0
    { 7, -3, 2, 5 },   // Linha 1
    { -5, -2, 2, -9 }  // Linha 2
};

3. Acesso e Modificação de Elementos

Para ler ou alterar um dado de uma matriz, precisamos informar a coordenada exata com base na indexação, que sempre inicia em 0 tanto para linhas quanto para colunas: 

// Modificando um valor na linha 1, coluna 3 (coordenadas baseadas em zero)
matrizNumeros[1][3] = 99;

// Acessando e exibindo o valor da linha 0, coluna 2
int valor = matrizNumeros[0][2];
System.out.println("O valor é: " + valor); // Exibe 12

4. Processando Matrizes com Laços Aninhados

A maneira padrão e mais eficiente de percorrer todos os elementos de uma grade é utilizando dois laços for aninhados. O laço externo controla as linhas, enquanto o interno percorre as colunas daquela linha.

Exemplo 1: Preenchendo uma Matriz com Zeros

int[][] grid = new int[3][4];

for (int row = 0; row < grid.length; row++) {
    for (int col = 0; col < grid[row].length; col++) {
        grid[row][col] = 0;
    }
}

Exemplo 2: Somando todos os elementos (for-each aninhado)

Java nos permite simplificar a leitura usando o laço aprimorado for-each. Lembre-se que cada elemento da matriz principal é, por si só, um array de inteiros (int[]): 

int sum = 0;
for (int[] row : grid) {      // Para cada linha da matriz...
    for (int item : row) {    // Para cada item dentro dessa linha...
        sum += item;          // Acumula na soma
    }
}
System.out.println("Soma total: " + sum);

Exemplo de Código

Exemplo 1: Preenchimento e Exibição de Matriz

Cria uma matriz 3x4, preenche com valores e exibe no formato de tabela.

public class ExibeMatriz {
    public static void main(String[] args) {
        int[][] numeros = {
            { 1, 0, 12, -1 },
            { 7, -3, 2, 5 },
            { -5, -2, 2, -9 }
        };

        for (int linha = 0; linha < numeros.length; linha++) {
            for (int coluna = 0; coluna < numeros[linha].length; coluna++) {
                System.out.printf("%4d", numeros[linha][coluna]);
            }
            System.out.println();
        }
    }
}

Exemplo 2: Soma de Todos os Elementos

Percorre a matriz inteira e acumula a soma de todos os valores.

public class SomaMatriz {
    public static void main(String[] args) {
        int[][] dados = {
            { 10, 20, 30 },
            { 40, 50, 60 }
        };

        int soma = 0;
        for (int[] linha : dados) {
            for (int valor : linha) {
                soma += valor;
            }
        }

        System.out.println("Soma total: " + soma); // 210
    }
}

Exemplo 3: Controle de Lucros por Loja e Mês

Calcula o lucro total da empresa e o lucro consolidado de dezembro usando matrizes. 

public class AnaliseFinanceira {
    public static void main(String[] args) {
        // profit[ID da Loja (0-2)][Mês do Ano (0-11)]
        double[][] profit = {
            { 1000.50, 1200.00, 800.75, 1500.25, 900.00, 1100.50,
              1300.75, 1600.00, 1400.25, 1050.00, 1250.50, 1800.75 },
            { 800.00, 950.25, 700.50, 1100.00, 850.75, 900.00,
              1050.25, 1200.50, 1000.00, 780.25, 920.00, 1400.75 },
            { 600.25, 750.00, 500.50, 900.75, 650.00, 700.25,
              850.00, 1000.50, 800.75, 600.00, 720.25, 1100.00 }
        };

        // 1. Calculando o Lucro Total da empresa no ano
        double totalCompanyProfit = 0;
        for (int store = 0; store < profit.length; store++) {
            for (int month = 0; month < profit[store].length; month++) {
                totalCompanyProfit += profit[store][month];
            }
        }
        System.out.printf("Lucro Total do Ano: R$ %.2f%n", totalCompanyProfit);

        // 2. Calculando o lucro consolidado de todas as lojas em Dezembro (mês 11)
        double decemberProfit = 0.0;
        for (int store = 0; store < profit.length; store++) {
            decemberProfit += profit[store][11];
        }
        System.out.printf("Lucro Total de Dezembro: R$ %.2f%n", decemberProfit);
    }
}

Exemplo 4: Tabuleiro de Damas

Representa um tabuleiro 8x8 usando constantes para identificar os estados de cada casa. 

public class TabuleiroDamas {
    static final int EMPTY = 0;
    static final int RED = 1;
    static final int BLACK = 2;

    public static void main(String[] args) {
        int[][] board = new int[8][8];

        // Inicializando o tabuleiro padrão
        for (int row = 0; row < 8; row++) {
            for (int col = 0; col < 8; col++) {
                if (row < 3 && (row + col) % 2 != 0) {
                    board[row][col] = RED;
                } else if (row > 4 && (row + col) % 2 != 0) {
                    board[row][col] = BLACK;
                } else {
                    board[row][col] = EMPTY;
                }
            }
        }

        // Exibindo o tabuleiro
        for (int row = 0; row < 8; row++) {
            for (int col = 0; col < 8; col++) {
                System.out.print(board[row][col] + " ");
            }
            System.out.println();
        }
    }
}

Dicas & Lembretes

  • ArrayIndexOutOfBoundsException: Este é o erro mais comum no trabalho com matrizes. Lembre-se de que se uma matriz foi declarada como new int[10][20], a última linha válida é a 9 e a última coluna é a 19. Usar índices maiores que o limite causará o travamento do programa.
  • Array de Arrays: Por se tratar de um array de arrays, você pode criar sub-arrays de comprimentos variados de forma manual (Ragged Arrays). Se fizer isso, evite fixar o limite do laço com números mágicos; use sempre matriz[row].length para ler o tamanho dinâmico de cada linha individual.
  • Inicialização Automática: Matrizes numéricas são inicializadas com 0, booleanas com false e objetos com null.
  • .length vs .length(): Para matrizes e vetores use .length (sem parênteses); para Strings use .length() (com parênteses).
  • Laços Aninhados: O laço externo sempre percorre as linhas e o interno as colunas. Inverter essa ordem pode causar erros lógicos difíceis de detectar.
  • Array of Arrays: Em Java, cada linha de uma matriz é realmente um vetor separado. Isso permite flexibilidade, mas requer atenção ao acessar matriz[i].length para cada linha.

Como aplicar na Prática

  • Controle Financeiro: Armazenar lucros, despesas ou receitas organizados por categoria (linhas) e período (colunas).
  • Jogos de Tabuleiro: Representar grades de xadrez, damas ou jogos da velha usando matrizes para armazenar o estado de cada casa.
  • Processamento de Imagens: Imagens digitais são matrizes de pixels, onde cada linha e coluna representa um ponto com cor (RGB).
  • Mapas e Navegação: Labirintos, mapas de jogos e rotas podem ser representados como grades bidimensionais.
  • Dados Científicos: Tabelas de resultados de experimentos, dados meteorológicos ou estatísticas organizados por variáveis.
