Teoria & Conceitos

Nesta aula vamos estudar as Strings, uma das estruturas de dados mais utilizadas em qualquer linguagem de programação. Com elas, conseguimos trabalhar com textos — de simples palavras a parágrafos inteiros de um sistema completo.

1. O que é uma String?

Tecnicamente, uma cadeia de caracteres é um vetor de caracteres. Enquanto um dado do tipo char armazena apenas uma letra ou símbolo, uma String permite agrupar esses caracteres para formar palavras, frases ou textos completos. 

// char: apenas UM caractere
char letra = 'A';

// String: vários caracteres agrupados
String palavra = "Algoritmo";

System.out.println(letra);   // A
System.out.println(palavra); // Algoritmo

Observe que char usa aspas simples ('A'), já a String usa aspas duplas ("Algoritmo").

2. Representação na Memória

Internamente, o computador armazena cada caractere utilizando códigos numéricos, como o padrão ASCII ou Unicode. Cada letra, número ou símbolo corresponde a um número inteiro que o processador utiliza para exibir o caractere correto na tela.

Caractere Código ASCII Código Unicode
'A' 65 U+0041
'a' 97 U+0061
'0' 48 U+0030
' ' (espaço) 32 U+0020

Em muitas linguagens, como o Portugol, o fim de uma string é marcado por um caractere nulo ('\0'), que indica ao sistema onde o texto termina dentro do espaço reservado no vetor. Em Java, a classe String gerencia isso automaticamente.

3. Strings em Java: Objetos vs. Primitivos

Diferente de tipos como int ou double, em Java, a String é um objeto e não um tipo primitivo. Isso significa que, além de armazenar dados, ela possui "poderes" próprios: as chamadas funções nativas ou métodos, que facilitam tarefas como busca, corte e transformação de textos. 

// Tipos primitivos: sem métodos
int x = 10;
// x.toString(); // ERRO! int não tem métodos

// String: é um objeto, possui métodos
String texto = "Java";
System.out.println(texto.length()); // 4 (método funcionando)

4. Operações e Funções Nativas

Para manipular Strings de forma eficiente, utilizamos as funções integradas da classe String em Java:

Operação Método Java Descrição
Comprimento .length() Retorna o total de caracteres do texto.
Acesso .charAt(i) Retorna o caractere na posição i (começando do 0).
Comparação .equals(s2) Verifica se o conteúdo de duas strings é idêntico.
Corte .substring(n, m) Extrai uma parte do texto entre as posições n e m−1.
Busca .indexOf(s2) Retorna a posição onde um texto começa dentro de outro.
Transformação .toUpperCase() Converte todo o texto para letras maiúsculas.

5. Detalhamento dos Principais Métodos

5.1. .length() — Comprimento

Retorna a quantidade total de caracteres da string. Note que é um método (com parênteses), diferente do atributo .length dos vetores (sem parênteses). 

String nome = "Programação";
System.out.println(nome.length()); // 11

5.2. .charAt(i) — Acesso por Índice

Retorna o caractere que está na posição i. Assim como vetores, o primeiro índice é 0. 

String palavra = "Java";
char primeira = palavra.charAt(0); // 'J'
char ultima = palavra.charAt(3);   // 'a'

System.out.println(primeira); // J
System.out.println(ultima);   // a

5.3. .equals(s2) — Comparação

Compara o conteúdo de duas strings. Nunca use == para comparar Strings, pois ele verifica se ambas apontam para o mesmo objeto na memória, e não se o texto é igual. 

String a = "hello";
String b = "hello";
String c = new String("hello");

System.out.println(a == b);      // true (cache de strings)
System.out.println(a == c);      // false (objetos diferentes!)
System.out.println(a.equals(c)); // true (conteúdo igual)

5.4. .substring(n, m) — Corte

Extrai uma porção do texto. O parâmetro n é inclusivo (começa ali) e m é exclusivo (para antes de chegar ali). 

String texto = "Programação Java";

String parte1 = texto.substring(0, 11); // "Programação"
String parte2 = texto.substring(12);    // "Java" (até o fim)

System.out.println(parte1); // Programação
System.out.println(parte2); // Java

5.5. .indexOf(s2) — Busca

Retorna o índice da primeira ocorrência do trecho buscado. Se não encontrar, retorna -1. 

String frase = "Aprendendo Java é divertido";
int pos = frase.indexOf("Java");

System.out.println("Java começa na posição: " + pos); // 12

int nada = frase.indexOf("Python");
System.out.println(nada); // -1 (não encontrou)

5.6. .toUpperCase() e .toLowerCase() — Transformação

Converte toda a string para maiúsculas ou minúsculas. Como Strings são imutáveis em Java, esses métodos retornam uma nova string, sem alterar a original. 

String original = "Hello World";

String maiusculas = original.toUpperCase();
String minusculas = original.toLowerCase();

System.out.println(original);    // Hello World (não mudou!)
System.out.println(maiusculas);  // HELLO WORLD
System.out.println(minusculas);  // hello world

6. Concatenação de Strings

Unir textos (concatenação) é feito de forma simples com o operador +. Isso também funciona para misturar Strings com outros tipos — o Java converte automaticamente. 

String saudacao = "Olá";
String nome = "Mundo";
String mensagem = saudacao + " " + nome; // "Olá Mundo"

System.out.println(mensagem);              // Olá Mundo
System.out.println("Tamanho: " + mensagem.length()); // 9

// Concatenação com outros tipos
int idade = 25;
String descricao = "Idade: " + idade; // "Idade: 25"

7. Percorrendo uma String como Vetor

Podemos usar um laço for para analisar cada letra individualmente, tratando a string como uma sequência indexada. 

String palavra = "Java";

for (int i = 0; i < palavra.length(); i++) {
    System.out.println("Posição " + i + ": " + palavra.charAt(i));
}

// Saída:
// Posição 0: J
// Posição 1: a
// Posição 2: v
// Posição 3: a

8. Comparação Segura

Nunca use == para comparar o conteúdo de Strings em Java; use sempre o método .equals(). 

String senhaCorreta = "12345";
String tentativa = "12345";

if (tentativa.equals(senhaCorreta)) {
    System.out.println("Acesso Permitido");
} else {
    System.out.println("Senha incorreta");
}

Exemplo de Código

Exemplo 1: Concatenação e Comprimento

Unir textos e descobrir o tamanho da mensagem resultante.

public class Concatenacao {
    public static void main(String[] args) {
        String saudacao = "Olá";
        String nome = "Mundo";
        String mensagem = saudacao + " " + nome; // "Olá Mundo"

        System.out.println("Mensagem: " + mensagem);
        System.out.println("Tamanho do texto: " + mensagem.length()); // 9
    }
}

Exemplo 2: Percorrendo uma String como Vetor

Exibe cada letra da palavra com sua respectiva posição.

public class PercorreString {
    public static void main(String[] args) {
        String palavra = "Java";

        for (int i = 0; i < palavra.length(); i++) {
            System.out.println("Posição " + i + ": " + palavra.charAt(i));
        }
    }
}

Exemplo 3: Comparação Segura

Verifica se a senha digitada corresponde à senha correta.

public class VerificaSenha {
    public static void main(String[] args) {
        String senhaCorreta = "12345";
        String tentativa = "12345";

        if (tentativa.equals(senhaCorreta)) {
            System.out.println("Acesso Permitido");
        } else {
            System.out.println("Senha incorreta. Tente novamente.");
        }
    }
}

Exemplo 4: Validando um E-mail

Verifica se o e-mail digitado contém o símbolo @ usando .indexOf(). 

public class ValidaEmail {
    public static void main(String[] args) {
        String email = "usuario@email.com";

        if (email.indexOf("@") != -1) {
            System.out.println("E-mail válido!");
        } else {
            System.out.println("E-mail inválido: falta o @");
        }
    }
}

Exemplo 5: Extraindo Informações com substring

Extrai o domínio de um e-mail (tudo depois do @). 

public class ExtraiDominio {
    public static void main(String[] args) {
        String email = "aluno@etec.sp.gov.br";
        int posArroba = email.indexOf("@");

        String dominio = email.substring(posArroba + 1);
        System.out.println("Domínio: " + dominio); // etec.sp.gov.br
    }
}

Exemplo 6: Contando Vogais em uma Palavra

Usa charAt() e um laço para contar.

public class ContaVogais {
    public static void main(String[] args) {
        String palavra = "Programacao";
        int contador = 0;

        for (int i = 0; i < palavra.length(); i++) {
            char letra = palavra.charAt(i);
            if (letra == 'a' || letra == 'e' || letra == 'i'
                || letra == 'o' || letra == 'u') {
                contador++;
            }
        }

        System.out.println("Vogais: " + contador); // 5
    }
}

Dicas & Lembretes

  • Imutabilidade: em Java, Strings são imutáveis. Funções como .trim() ou .toUpperCase() não alteram a string original — elas retornam uma nova string transformada.
  • Índice Zero: assim como nos vetores, a primeira letra está sempre na posição 0. A última letra está na posição comprimento - 1.
  • Case Sensitive: Java diferencia maiúsculas de minúsculas. Se precisar ignorar essa diferença, use .equalsIgnoreCase().
  • Nunca use ==: para comparar conteúdo de Strings, sempre use .equals(). O == compara endereços de memória, não o texto.
  • length() vs .length: para Strings use .length() (com parênteses); para vetores use .length (sem parênteses).
  • substring é exclusivo no fim: substring(0, 3) pega os caracteres nas posições 0, 1 e 2 — não inclui a posição 3.

Como aplicar na Prática

  • Validação de Formulários: verificar se um e-mail contém o símbolo @ usando .indexOf().
  • Sistemas de Segurança: formatar senhas e realizar login comparando Strings com .equals().
  • Processamento de Dados: ler arquivos de texto e extrair informações específicas através de divisões e cortes (.substring()).
  • Interface de Usuário: formatar nomes para exibição em relatórios (ex: tudo em maiúsculas ou apenas as iniciais).
