1. Enunciado

Muitos sistemas de jogos exigem que os nomes dos personagens sigam um padrão (ex: tudo em maiúsculas) e não excedam um limite de caracteres. Crie um programa que receba o nome de um herói e realize uma série de tratamentos.

2. Preparação

  • Ambiente: utilize o VS Code (com extensão Java) ou um compilador Java online (ex: OnlineGDB).
  • Conhecimento Prévio: requer domínio de métodos de String (.trim(), .toUpperCase(), .length(), .charAt(), .substring()).
  • Documentação: consulte o conteúdo da aula 23 sobre Strings e suas funções nativas.
  • Crie a classe FormatadorRPG.

Este código lê o nome do herói pelo teclado. Sua missão é implementar todos os tratamentos solicitados.

4. O Desafio

Implemente as seguintes regras de tratamento do nome do herói:

  • Limpeza: remova espaços em branco extras no início e no fim do nome usando .trim().
  • Padronização: exiba o nome todo em MAIÚSCULAS usando .toUpperCase().
  • Contagem: informe quantos caracteres o nome possui (após a limpeza) usando .length().
  • Validação: verifique se o nome começa com a letra "A" usando .charAt(0). Se sim, exiba a mensagem: "Este herói pertence ao Clã dos Alfas!".
  • Corte: exiba apenas as 3 primeiras letras do nome (abreviação) usando .substring(0, 3).

5. Orientações Finais

  • Teste de Mesa: teste o programa com nomes como " Artur " para verificar se o .trim() e o .toUpperCase() funcionam juntos.
  • Cuidado com nomes curtos: se o nome tiver menos de 3 caracteres, .substring(0, 3) lançará um erro. Considere usar Math.min(3, nomeLimpo.length()) como segundo parâmetro.
