Enunciado

Você foi contratado(a) para desenvolver o painel de preferências de uma loja virtual. Como o protocolo HTTP não mantém memória entre requisições, toda a persistência do lado do cliente deverá ser feita com cookies, usando a função setcookie() e a superglobal $_COOKIE.

Execute e valide cada etapa no seu ambiente com PHP 8 antes de prosseguir para a próxima.

Preparação

  1. Ambiente: garanta PHP 8+ instalado e, no XAMPP/WampServer, valide a versão com php -v. Se usar o servidor embutido, suba a pasta com php -S localhost:8080.
  2. Organização: crie uma pasta cookies-aula31 com os arquivos preferencias.php, historico.php e limpar.php.
  3. Ferramenta de inspeção: abra o DevTools do navegador (F12) na aba Application → Storage → Cookies. Você inspecionar, editar e remover os cookies por lá durante toda a atividade.
  4. Validação: a cada bloco, atualize a página e confirme que o cookie aparece no DevTools com o path e a data de expiração corretos.

1. Estrutura de Arquivos Proposta

  • preferencias.php — grava e lê os cookies de tema e idioma (Exemplo 1 da aula).
  • historico.php — registra e exibe os últimos cursos acessados (Exemplo 2).
  • limpar.php — revoga todos os cookies gravados (Exemplo 3 da aula).

2. Desafios de Prática

Bloco 1: Gravando e Lendo a Preferência de Tema

  1. Crie preferencias.php com um formulário que envie tema (claro ou escuro) e um botão para salvar: 
    <?php
declare(strict_types=1);

if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['tema'])) {
    setcookie('preferencia_tema', $_POST['tema'], [
        'expires'  => time() + (86400 * 30), // 30 dias
        'path'     => '/',
        'secure'   => false,
        'httponly' => true,
        'samesite' => 'Lax'
    ]);

    header('Location: ' . $_SERVER['PHP_SELF']);
    exit;
}

$temaAtual = $_COOKIE['preferencia_tema'] ?? 'claro';
?>
<!DOCTYPE html>
<html lang="pt-BR">
<meta charset="UTF-8">
<h1>Preferências</h1>
<p>Tema atual: <?= htmlspecialchars($temaAtual, ENT_QUOTES, 'UTF-8') ?></p>
<form method="POST">
    <select name="tema">
        <option value="claro">Claro</option>
        <option value="escuro">Escuro</option>
    </select>
    <button type="submit">Salvar</button>
</form>
  2. Teste o código e responda: por que o valor selecionado só aparece na página depois do clique em Salvar, e não imediatamente? Qual função do PHP resolve esse atraso?
  3. No DevTools, edite manualmente o valor do cookie para qualquer-coisa e recarregue a página. O que a aplicação faz com esse valor? Por que isso é um problema de segurança?

Bloco 2: Validação com Lista Branca e Proteção contra XSS

  1. Adicione a validação por lista branca antes de gravar o cookie, aceitando apenas claro e escuro: 
    $temasValidos = ['claro', 'escuro'];

if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['tema'])) {
    if (in_array($_POST['tema'], $temasValidos, true)) {
        setcookie('preferencia_tema', $_POST['tema'], [
            'expires'  => time() + (86400 * 30),
            'path'     => '/',
            'httponly' => true,
            'samesite' => 'Lax'
        ]);
    }

    header('Location: ' . $_SERVER['PHP_SELF']);
    exit;
}
  2. Reproduza um XSS: no DevTools, altere o cookie para <script>alert('XSS')</script>. Explique por que a flag httponly não protege a sua página nesse cenário e qual função de escape resolve o problema na saída.
  3. Adicione um segundo cookie de idioma (pt-BR, en-US ou es-ES) com validade de 1 ano (time() + 60*60*24*365) e exiba-o na tela.

Bloco 3: Histórico de Navegação em JSON

  1. Crie historico.php que registre os últimos 5 cursos acessados: 
    <?php
declare(strict_types=1);

$cursosDisponiveis = ['PHP 8 Avançado', 'Laravel Framework', 'CSS Grid e Flexbox', 'JavaScript ES6'];

$historico = json_decode($_COOKIE['historico_cursos'] ?? '[]', true) ?: [];
$cursoAtual = $_GET['curso'] ?? null;

if ($cursoAtual !== null && in_array($cursoAtual, $cursosDisponiveis, true)) {
    $historico = array_values(array_unique(array_merge([$cursoAtual], $historico)));
    $historico = array_slice($historico, 0, 5);

    setcookie('historico_cursos', json_encode($historico), [
        'expires'  => time() + (86400 * 7),
        'path'     => '/',
        'httponly' => true,
        'samesite' => 'Lax'
    ]);
}
?>
  2. Navegue por todos os cursos e observe o cookie no DevTools. Ele é um texto único — explique como o json_encode() conseguiu "colocar um array dentro de uma string".
  3. O que acontece se você gravar o histórico com array_slice($historico, 0, 100) e preencher 100 cursos longos? Relacione a resposta com o limite de 4 KB do cookie.
  4. Troque o json_decode($x, true) por json_decode($x) (sem o segundo parâmetro) e explique a diferença no tipo de retorno com gettype().

Bloco 4: Revogando Cookies

  1. Crie limpar.php para remover todos os cookies da aplicação: 
    <?php
$cookiesParaRevogar = ['preferencia_tema', 'idioma', 'historico_cursos'];

foreach ($cookiesParaRevogar as $nome) {
    setcookie($nome, '', [
        'expires' => time() - 3600, // Data no passado = revogação
        'path'    => '/'            // Precisa ser IGUAL ao da criação
    ]);
}

header('Location: index.php');
exit;
  2. Incline o exercício: apague o parâmetro 'path' da revogação. O cookie continua sendo removido? Explique por que o navegador não reconheceu o cookie como o mesmo.
  3. Liste os cookies que NÃO devem ser revogados por esta tela (por exemplo, PHPSESSID) e justifique com base no que você aprendeu na aula.

Bloco 5: Refletindo sobre a Prática

  1. Explique, com suas palavras, a diferença entre um cookie de sessão e um cookie persistente, citando o papel do parâmetro expires.
  2. Complete a frase: "Um cookie nunca deve armazenar a senha do usuário porque...".
  3. Qual seria a alternativa correta para guardar o histórico de navegação em um site real com milhares de produtos? Justifique sua resposta com os limites de 4 KB e de quantidade de cookies por domínio.
  4. Qual a relação entre o uso de cookies para rastreamento e a Lei Geral de Proteção de Dados (LGPD)?

Orientações Finais

  • Nada de saída antes dos cabeçalhos: todo o bloco de setcookie() e header() deve ficar no topo do script, antes de qualquer ?> seguido de HTML — inclusive sem espaços em branco antes do <?php.
  • Sempre redirecione: use header('Location: ' . $_SERVER['PHP_SELF']); exit; após gravar o cookie, para aplicar a mudança e evitar o reenvio do formulário.
  • Valide antes de gravar: use lista branca com in_array() e escape a saída com htmlspecialchars().
  • LGPD: todo sistema que registra preferências ou histórico deve oferecer uma forma clara de revogá-las.
