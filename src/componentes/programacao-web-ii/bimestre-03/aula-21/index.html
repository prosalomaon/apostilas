Teoria & Conceitos

A linguagem SQL (Structured Query Language) é dividida em subconjuntos de acordo com a finalidade do comando no banco de dados. Para um desenvolvedor Web, entender essas divisões é crucial para organizar os scripts de criação do sistema e a lógica de manipulação de dados dentro do código PHP.

1. DDL – Linguagem de Definição de Dados (Data Definition Language)

A DDL é utilizada para definir a estrutura e a organização dos dados. Em um projeto Web, esses comandos são geralmente executados uma única vez na fase de implantação ou durante migrações de versão do sistema.

  • CREATE DATABASE: Cria o banco de dados que abrigará as tabelas.
  • CREATE TABLE: Define o nome da tabela, suas colunas e tipos de dados (int, varchar, date, etc.).
  • ALTER TABLE: Modifica a estrutura de uma tabela existente (adicionar ou remover colunas/restrições).
  • DROP TABLE: Exclui permanentemente uma tabela e seus dados.

Exemplo MySQL (criação da tabela de usuários):

CREATE TABLE usuarios (
    id INT NOT NULL AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE,
    senha VARCHAR(255) NOT NULL,
    PRIMARY KEY (id)
);

2. DML – Linguagem de Manipulação de Dados (Data Manipulation Language)

A DML permite incluir, remover ou atualizar os registros armazenados nas tabelas. No PHP, esses comandos formam a base das operações de escrita (Create, Update, Delete) do CRUD.

  • INSERT INTO: Adiciona novos registros.
  • UPDATE: Altera valores em registros já existentes.
  • DELETE: Remove registros específicos.

Exemplo MySQL (inserção de dados):

INSERT INTO usuarios (nome, email, senha) VALUES ('Ana Silva', 'ana@email.com', 'hash_senha');

3. DQL – Linguagem de Consulta de Dados (Data Query Language)

Focada exclusivamente na extração e recuperação de informações. É o componente mais utilizado em aplicações Web para exibir conteúdos dinâmicos aos usuários.

  • SELECT: Especifica as colunas desejadas.
  • FROM: Indica de qual(is) tabela(s) os dados vêm.
  • WHERE: Aplica filtros para selecionar apenas linhas específicas.
  • ORDER BY: Define a ordem de exibição dos resultados.

Exemplo MySQL (busca ordenada):

SELECT nome, email FROM usuarios WHERE email LIKE '%@gmail.com' ORDER BY nome ASC;

Integração com PHP (Contexto Web II)

Na programação Web, a interação entre o PHP e o MySQL é feita preferencialmente através da interface PDO (PHP Data Objects), que oferece uma camada de abstração segura.

A. Conexão via PDO

Para conectar-se ao banco, o PHP utiliza um DSN (Data Source Name) que contém o host e o nome do banco. 

$dsn = "mysql:host=localhost;dbname=meu_banco_web";
$conexao = new PDO($dsn, "usuario", "senha");

B. Execução de Comandos

  • Comandos que não retornam linhas (DDL/DML): usa-se o método exec(), que retorna o número de linhas afetadas.
  • Consultas (DQL): usa-se o método query() ou, para maior segurança, prepare() com placeholders. 
// Comando sem retorno de linhas (DML): exec() devolve o total de linhas afetadas
$linhas = $conexao->exec("DELETE FROM usuarios WHERE id = 10");
echo "Registros removidos: $linhas";

// Consulta (DQL): query() para comandos simples
$resultado = $conexao->query("SELECT nome, email FROM usuarios");
foreach ($resultado as $linha) {
    echo $linha['nome'] . ' - ' . $linha['email'] . PHP_EOL;
}

Segurança e Boas Práticas: SQL Injection

Ao construir sistemas Web, nunca insira variáveis vindas de formulários diretamente na string SQL. Isso abre brecha para ataques de SQL Injection, onde um invasor pode injetar comandos maliciosos para roubar ou apagar dados.

A Solução: Placeholders (?)

Em vez de concatenar valores, utilize o sinal de interrogação como marcador. O PDO se encarrega de sanitizar os dados automaticamente. 

$sql = "SELECT * FROM usuarios WHERE email = ?";
$stmt = $conexao->prepare($sql);
$stmt->execute([$email_vindo_do_form]); // O dado é tratado com segurança pelo PDO
$usuario = $stmt->fetch();

Dicas & Lembretes

  • Persistência: use o MySQL para garantir que os dados submetidos via formulário HTML permaneçam gravados após o navegador ser fechado.
  • Identificadores: no MySQL, utilize sempre AUTO_INCREMENT em chaves primárias numéricas para facilitar a gestão de novos registros pela aplicação Web.
  • Dicionário de Dados: documente as regras de cada coluna (tamanho do VARCHAR, se aceita NULL) para que seu código PHP faça validações condizentes com o banco.
  • Placeholders: prefira sempre prepare() com ? (ou :nome) a concatenar variáveis em strings SQL — nunca confie em dados vindos do usuário.
  • Execução única: comandos DDL (CREATE, ALTER) são executados na implantação; a aplicação Web usa DML e DQL no dia a dia.

Como aplicar na Prática

  • Cadastro de usuários: crie a tabela com DDL, insira os dados submetidos no formulário com INSERT via PDO e confirme o cadastro com um SELECT.
  • Login seguro: use prepare() com WHERE email = ? para buscar o usuário sem risco de SQL Injection.
  • Listagens dinâmicas: use ORDER BY para exibir conteúdos ordenados e WHERE + LIKE para filtros de busca.
  • Edição e remoção: combine UPDATE e DELETE (com WHERE!) com exec() ou prepare() para completar o CRUD.
