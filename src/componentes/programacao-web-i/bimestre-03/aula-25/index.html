Teoria & Conceitos do Document Object Model (DOM)

Quando o navegador carrega um documento HTML, ele processa o texto do arquivo e cria uma representação estruturada do documento em memória. Essa representação é uma API orientada a objetos chamada DOM (Document Object Model), que serve como a ponte de comunicação entre o código JavaScript e a estrutura da página. É o DOM que permite ao JavaScript inspecionar, alterar e reagir dinamicamente às estruturas, estilos e conteúdos de uma página em tempo real.

1. Estrutura em Árvore (DOM Tree)

O DOM organiza os elementos em uma hierarquia de nós (nodes) formando uma árvore. O elemento raiz dessa árvore é o nó document, que engloba todo o conteúdo da página. A partir dele derivam elementos filhos como <html> e <body>, que por sua vez contêm seus próprios nós filhos: títulos, parágrafos, botões, imagens etc.

  • Nó raiz: document — representa o documento HTML inteiro.
  • Nós pais e filhos: Um elemento que contém outros elementos é o pai (parent) dos elementos dentro dele.
  • Nós irmãos: Elementos que compartilham o mesmo nó pai são irmãos (siblings).

2. HTML Fonte vs. DOM em Memória

O arquivo .html é apenas a instrução textual inicial enviada ao navegador. O DOM, por sua vez, é a estrutura viva mantida em memória. Quando o JavaScript altera um título ou oculta um painel, ele está modificando a árvore do DOM em tempo real, provocando a re-renderização visual da página sem a necessidade de recarregá-la.

  • HTML Fonte: texto estático, interpretado uma única vez ao carregar a página.
  • DOM: objeto em memória, dinâmico, que reflete o estado atual da página (inclusive mudanças feitas por scripts).

Métodos de Seleção de Elementos HTML

Para manipular qualquer elemento na tela via JavaScript, o primeiro passo é localizá-lo e selecioná-lo na árvore do DOM. Existem dois grupos de métodos: os tradicionais e os modernos (baseados em seletores CSS).

1. Métodos de Seleção Tradicionais

Estes métodos pertencem às primeiras especificações da linguagem e buscam elementos por atributos específicos:

  • document.getElementById('id'): Retorna a referência do único elemento que possui o identificador id especificado. Se não encontrar, retorna null.
  • document.getElementsByClassName('classe'): Retorna uma coleção viva de todos os elementos que contêm a classe informada.
  • document.getElementsByTagName('tag'): Retorna uma coleção viva de todos os elementos correspondentes à tag especificada (ex.: 'p', 'button', 'a'). 
// Exemplo de seleção tradicional
const tituloPrincipal = document.getElementById('titulo-pagina');
const botoesAcao = document.getElementsByClassName('btn-acao');
const paragrafos = document.getElementsByTagName('p');

2. Métodos de Seleção Modernos (Seletores CSS)

Nas especificações modernas, utiliza-se a mesma sintaxe de seletores do CSS para buscar elementos:

  • document.querySelector('seletor'): Busca na árvore do DOM e retorna o primeiro elemento que atende ao seletor CSS informado. Caso nenhum elemento coincida, retorna null.
  • document.querySelectorAll('seletor'): Retorna uma NodeList (coleção de nós) contendo todos os elementos que coincidem com o seletor CSS informado. 
// Seleciona o primeiro botão dentro do formulário
const primeiroBotao = document.querySelector('form button');

// Seleciona todas as linhas de uma tabela com a classe .linha-item
const linhasTabela = document.querySelectorAll('table .linha-item');

3. Diferença Crítica: NodeList Estática vs. HTMLCollection Viva

Critério HTMLCollection (getElementsByClassName / TagName) NodeList (querySelectorAll)
Sintaxe de Busca Nome exato de classe ou tag. Qualquer seletor CSS válido (.classe, #id, div > p).
Comportamento de Atualização Viva (Live): Atualiza-se automaticamente se elementos forem inseridos ou removidos do DOM durante a execução. Estática (Static): É uma fotografia congelada no instante em que o método foi chamado.
Métodos de Iteração Não possui método .forEach() nativo; exige conversão com Array.from() ou laço for tradicional. Suporta iteração direta com o método .forEach(). 
// HTMLCollection: precisa converter para array para usar forEach
const itensMenu = document.getElementsByClassName('menu-item');
Array.from(itensMenu).forEach(item => console.log(item.textContent));

// NodeList: suporta forEach nativamente
const itensMenu2 = document.querySelectorAll('.menu-item');
itensMenu2.forEach(item => console.log(item.textContent));

4. Manipulação de Propriedades dos Elementos

Uma vez selecionado e armazenado em uma variável, podemos modificar as propriedades visuais e estruturais do elemento:

  • element.textContent: Lê ou altera o conteúdo de texto puro dentro do elemento. É a forma mais segura contra injeção de scripts (XSS), pois qualquer texto é exibido literalmente.
  • element.innerHTML: Lê ou altera a estrutura HTML interna de um elemento. Permite interpretar novas tags HTML passadas como string — use com cuidado e nunca com conteúdo vindo do usuário.
  • element.value: Utilizado para ler ou alterar o valor digitado/selecionado em campos de formulários (<input>, <textarea>, <select>).
  • element.style.propriedade: Aplica estilos inline diretamente via JavaScript (ex.: element.style.color = 'red').
  • element.classList.add / remove / toggle: Adiciona, remove ou alterna classes CSS no elemento, mantendo a estilização separada do comportamento. 
const titulo = document.getElementById('titulo-pagina');

// Alterando texto (forma segura)
titulo.textContent = 'Novo Título da Página';

// Alterando estrutura HTML (interpola tags)
titulo.innerHTML = '<span class="destaque">Novo</span> Título';

// Manipulando classes CSS
titulo.classList.add('visivel');
titulo.classList.remove('oculto');
titulo.classList.toggle('destaque');

Eventos: Comunicando com o Usuário

Eventos são notificações enviadas pelo navegador quando algo acontece na página: um clique do mouse, a pressão de uma tecla, o envio de um formulário, o carregamento da página etc. Para reagir a esses acontecimentos, registramos funções callback que serão executadas quando o evento ocorrer.

1. O Método addEventListener()

A forma moderna e recomendada de tratar eventos é o método addEventListener(tipoEvento, callback), que permite registrar múltiplos tratadores para o mesmo evento sem sobrescrever os anteriores. 

const botao = document.querySelector('#btn-salvar');

// Registrando um tratador de evento de clique
botao.addEventListener('click', function (evento) {
  console.log('Botão clicado!');
  console.log('Elemento alvo:', evento.target);
});

2. Tipos de Eventos Mais Utilizados

Categoria Eventos Descrição
Mouse click, dblclick, mouseover, mouseout Interações diretas com o ponteiro do mouse.
Teclado keydown, keyup Pressionamento e soltura de teclas.
Formulários submit, input, change, focus, blur Envio, digitação e mudança de foco em campos.
Documento load, DOMContentLoaded, scroll, resize Ciclo de vida da página e janela do navegador.

3. O Objeto Event

Quando um evento dispara, o navegador cria um objeto Event e o passa como parâmetro para a função callback. Esse objeto contém informações cruciais sobre o acontecimento:

  • evento.target: o elemento original que disparou o evento.
  • evento.currentTarget: o elemento ao qual o tratador está vinculado.
  • evento.preventDefault(): cancela a ação padrão do navegador (ex.: envio do formulário, navegação de um link).
  • evento.stopPropagation(): impede a propagação do evento para elementos pai/filhos.
  • evento.key: retorna o código da tecla pressionada (útil em eventos de teclado). 
const formulario = document.querySelector('#form-cadastro');

formulario.addEventListener('submit', function (evento) {
  // Impede o recarregamento da página padrão do <form>
  evento.preventDefault();
  console.log('Formulário enviado sem recarregar!');
});

4. Delegação de Eventos

Em vez de registrar um tratador em cada elemento filho (o que é custoso quando a lista muda dinamicamente), a delegação de eventos registra um único tratador no elemento pai e verifica qual filho disparou o evento através de evento.target. 

const lista = document.querySelector('#lista-tarefas');

// Um único ouvinte atende todos os itens atuais e futuros
lista.addEventListener('click', function (evento) {
  if (evento.target.tagName === 'LI') {
    evento.target.classList.toggle('concluida');
  }
});

Exemplo de Código

1. Nível Básico: Contador Interativo

Exemplo introdutório combinando seleção de elementos com o evento de clique para manipular o conteúdo exibido na tela. 

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Contador Interativo</title>
  <style>
    body { font-family: Arial, sans-serif; text-align: center; margin-top: 50px; }
    #valor { font-size: 3rem; margin: 10px; }
    button { font-size: 1.2rem; padding: 8px 20px; cursor: pointer; }
  </style>
</head>
<body>
  <h1>Contador</h1>
  <div id="valor">0</div>
  <button id="menos">-</button>
  <button id="mais">+</button>

  <script>
    // Seleção dos elementos
    const valorEl = document.getElementById('valor');
    const btnMais = document.getElementById('mais');
    const btnMenos = document.getElementById('menos');

    let contador = 0;

    btnMais.addEventListener('click', function () {
      contador++;
      valorEl.textContent = contador;
    });

    btnMenos.addEventListener('click', function () {
      contador--;
      valorEl.textContent = contador;
    });
  </script>
</body>
</html>

2. Nível Intermediário: Validação de Formulário com preventDefault

Formulário que intercepta o envio, valida os campos e exibe mensagens de erro sem recarregar a página. 

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Formulário Validado</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 400px; margin: 40px auto; }
    label { display: block; margin-top: 12px; font-weight: bold; }
    input { width: 100%; padding: 8px; margin-top: 4px; box-sizing: border-box; }
    .erro { color: #c0392b; font-size: 0.85rem; min-height: 1.2em; }
    .sucesso { color: #27ae60; }
  </style>
</head>
<body>
  <h1>Cadastro</h1>
  <form id="form-cadastro">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">
    <span class="erro" id="erro-nome"></span>

    <label for="email">E-mail:</label>
    <input type="email" id="email" name="email">
    <span class="erro" id="erro-email"></span>

    <button type="submit">Enviar</button>
    <p id="mensagem"></p>
  </form>

  <script>
    const form = document.getElementById('form-cadastro');
    const mensagem = document.getElementById('mensagem');

    form.addEventListener('submit', function (evento) {
      // 1. Impede o recarregamento padrão da página
      evento.preventDefault();

      const nome = document.getElementById('nome');
      const email = document.getElementById('email');
      const erroNome = document.getElementById('erro-nome');
      const erroEmail = document.getElementById('erro-email');

      let valido = true;

      // 2. Validação do nome
      if (nome.value.trim() === '') {
        erroNome.textContent = 'O nome não pode ficar vazio!';
        valido = false;
      } else {
        erroNome.textContent = '';
      }

      // 3. Validação do e-mail (verificação simples)
      if (!email.value.includes('@')) {
        erroEmail.textContent = 'Informe um e-mail válido!';
        valido = false;
      } else {
        erroEmail.textContent = '';
      }

      // 4. Feedback final
      if (valido) {
        mensagem.textContent = 'Cadastro enviado com sucesso!';
        mensagem.className = 'sucesso';
        form.reset();
      } else {
        mensagem.textContent = 'Corrija os erros acima.';
        mensagem.className = 'erro';
      }
    });
  </script>
</body>
</html>

3. Nível Avançado: Lista Interativa com Teclado e Delegação de Eventos

Demonstração da captura da tecla Enter via keydown, da adição dinâmica de elementos e da delegação de eventos no elemento pai. 

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Lista de Tarefas</title>
  <style>
    body { font-family: Arial, sans-serif; max-width: 400px; margin: 40px auto; }
    #entrada-tarefa { width: 100%; padding: 10px; box-sizing: border-box; margin-bottom: 10px; }
    li { padding: 8px; margin: 4px 0; background: #f0f0f0; cursor: pointer; display: flex; justify-content: space-between; }
    li.concluida { text-decoration: line-through; color: #888; }
    li button { border: none; background: #c0392b; color: white; cursor: pointer; border-radius: 4px; }
  </style>
</head>
<body>
  <h2>Minha Lista de Tarefas</h2>

  <input type="text" id="entrada-tarefa" placeholder="Digite uma tarefa e pressione Enter">
  <p id="contador">0 tarefa(s)</p>

  <ul id="lista-tarefas">
    <li>Estudar Seletores DOM</li>
    <li>Praticar EventListeners</li>
  </ul>

  <script>
    const entrada = document.getElementById('entrada-tarefa');
    const lista = document.getElementById('lista-tarefas');
    const contador = document.getElementById('contador');

    function atualizarContador() {
      const total = lista.getElementsByTagName('li').length;
      contador.textContent = total + ' tarefa(s)';
    }

    // 1. Adição via teclado (Enter)
    entrada.addEventListener('keydown', function (evento) {
      if (evento.key === 'Enter' && entrada.value.trim() !== '') {
        const novoItem = document.createElement('li');
        novoItem.textContent = entrada.value.trim();
        lista.appendChild(novoItem);
        entrada.value = '';
        atualizarContador();
      }
    });

    // 2. Delegação de eventos: um único ouvinte no elemento pai
    //    atende cliques em itens atuais e futuros
    lista.addEventListener('click', function (evento) {
      if (evento.target.tagName === 'LI') {
        // Alterna a marcação de concluída
        evento.target.classList.toggle('concluida');
      } else if (evento.target.tagName === 'BUTTON') {
        // Remove o item ao clicar no botão de exclusão
        evento.target.parentElement.remove();
        atualizarContador();
      }
    });

    atualizarContador();
  </script>
</body>
</html>

Dicas, Lembretes e Boas Práticas

  • Posicionamento do Script no HTML: O navegador lê o HTML sequencialmente de cima para baixo. Se o script tentar selecionar um elemento <script> ainda não lido, o retorno será null e ocorrerá erro. Por isso, coloque os scripts no final do <body> ou use o evento DOMContentLoaded.
  • Prefira textContent a innerHTML: Use textContent para inserir dados de texto, pois innerHTML interpreta qualquer marcação e pode abrir brechas de segurança (XSS) se receber conteúdo vindo do usuário.
  • Seletor Moderno é mais flexível: Prefira querySelector e querySelectorAll, pois aceitam qualquer seletor CSS e retornam resultados previsíveis (estáticos), facilitando o raciocínio.
  • Delegação de Eventos: Para listas dinâmicas (itens adicionados em tempo de execução), registre um único ouvinte no elemento pai e use evento.target para identificar o item clicado. Isso evita registrar ouvintes repetidamente.
  • Remova ouvintes quando necessário: Se registrar muitos ouvintes ao longo da vida da página, utilize removeEventListener ou { once: true } para evitar vazamentos de memória.

Como aplicar na Prática

  • Menus e Modais: Utilize querySelector para localizar botões de abertura/fechamento e classList.toggle para alternar a visibilidade de painéis.
  • Formulários Dinâmicos: Intercepte o submit com preventDefault() e realize a validação dos campos antes de enviar os dados, exibindo mensagens de erro em tempo real.
  • Listas e Tabelas Editáveis: Combine criação de elementos (createElement + appendChild) com delegação de eventos para construir listas de tarefas, carrinhos de compra e tabelas administrativas.
  • Feedback Visual: Reaja a eventos de input e keyup para mostrar contadores de caracteres, indicadores de força de senha e autocomplete simples.
