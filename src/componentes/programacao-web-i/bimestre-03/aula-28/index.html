1. Descrição do Projeto

Você foi contratado para desenvolver um site estático interativo à sua escolha, aplicando os conceitos de JavaScript e manipulação do DOM aprendidos no 3º Bimestre. O site deve oferecer componentes interativos, como galerias, menus retráteis ou calculadoras.

O objetivo é demonstrar que o conteúdo da página pode reagir às ações do usuário em tempo real, sem necessidade de recarregar a página.

2. Requisitos Técnicos (O que será avaliado)

  • Separação de Responsabilidades: HTML estrutural, CSS de estilo e um arquivo externo de JavaScript (script.js).
  • Seleção e Eventos: Uso de querySelector/ querySelectorAll e ao menos 3 tipos de eventos diferentes (clique, envio, teclado, etc.).
  • Manipulação do DOM: Alteração dinâmica de conteúdo, atributos e/ou classes (classList).
  • Funções e Estruturas: Código organizado em funções, com uso de condicionais e laços.
  • Validação: Pelo menos um formulário com validação via JavaScript e mensagens de erro claras.
  • Boas Práticas: Uso de addEventListener (sem atributos inline onclick) e nomes de funções significativos.

3. Estrutura de Arquivos Sugerida

/projeto-iii
  ├── index.html          (estrutura semântica do site)
  ├── css/
  │    └── style.css      (estilização responsiva)
  ├── js/
  │    └── script.js      (toda a lógica de interação)
  └── imagens/            (assets otimizados)

4. O Desafio Prático

Escolha pelo menos dois componentes interativos:

  1. Galeria de Imagens: Navegação entre imagens com botões anterior/próximo e miniaturas.
  2. Menu Retrátil: Menu hambúrguer que abre/fecha com classe de estado alternada.
  3. Calculadora: Calculadora simples com operações básicas e feedback imediato.
  4. Lista de Tarefas: Adicionar e remover itens com validação de entrada vazia.

5. Desafios Bônus Opcional

  • Modo Escuro: Toggle que alterna um tema claro/escuro via classList.
  • Persistência: Salvar o estado da lista de tarefas no localStorage.

Orientações de Entrega

  • Sem Erros no Console: O site deve rodar sem exceções no console do navegador.
  • Depuração: Use o DevTools para inspecionar o comportamento dos eventos.
  • Responsividade: Os componentes devem funcionar bem em mobile e desktop.
  • Prazo: A entrega ocorre na aula 30, com correção e feedback.
