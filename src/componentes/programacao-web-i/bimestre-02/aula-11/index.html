1. Teoria & Conceitos

Nesta aula, iniciamos o estudo das Folhas de Estilo em Cascata (CSS - Cascading Style Sheets), a linguagem fundamental para descrever a aparência e a formatação de documentos escritos em linguagens de marcação como o HTML.

O CSS surgiu para resolver um problema crítico do HTML antigo: a mistura de conteúdo com formatação visual, o que tornava a manutenção de sites impraticável. Enquanto o HTML cuida da estrutura e semântica, o CSS foca exclusivamente na estilização.

A Anatomia de uma Regra CSS

Uma "regra" CSS (ou ruleset) é composta por dois elementos principais:

  • Seletor: Identifica qual elemento HTML será estilizado.
  • Bloco de Declaração: O grupo de instruções entre chaves {} que define o estilo.

Cada declaração dentro do bloco consiste em uma propriedade (como color ou font-size) e um valor (como blue ou 16px), separados por dois pontos : e finalizados com ponto e vírgula ;.

Métodos de Inclusão

Existem três formas de aplicar CSS a um documento, seguindo uma hierarquia de precedência:

  • CSS Inline: Aplicado diretamente no elemento através do atributo style="". Possui a maior precedência, mas é considerado uma má prática por misturar conteúdo e estilo.
  • CSS Interno (ou Incorporado): Declarado dentro da tag <style> no <head> do documento. É útil para estilos específicos de uma única página.
  • CSS Externo: O estilo é escrito em um arquivo separado (ex: estilos.css) e vinculado via tag <link> no HTML. É o padrão de mercado, pois permite o reaproveitamento de código em múltiplas páginas e mantém o HTML limpo.

2. Seletores Básicos

Os seletores permitem buscar elementos na página de forma precisa:

  • Seletor de Tipo (ou Tag): Aplica o estilo a todas as ocorrências de uma tag específica (ex: p { ... } afeta todos os parágrafos).
  • Seletor de Classe: Identificado por um ponto . (ex: .destaque). Pode ser aplicado a vários elementos diferentes e é o preferido para estilização profissional.
  • Seletor de ID: Identificado por uma cerquilha # (ex: #cabecalho). Deve ser único na página. Embora poderoso, seu uso para CSS é desencorajado em favor das classes para manter a especificidade baixa.

2.1 Cascata e Especificidade

Quando múltiplas regras CSS tentam estilizar o mesmo elemento, o navegador precisa decidir qual regra "vence". Isso é resolvido através do sistema de Cascata e Especificidade.

O que é Cascata?

A "cascata" (do inglês cascade, como água descendo por cachoeiras) é o algoritmo que o navegador usa para resolver conflitos de estilos. A ordem de precedência, da menor para a maior, é:

  1. Estilos do Navegador (user-agent stylesheet)
  2. CSS Externo (via <link>)
  3. CSS Interno (via <style>)
  4. CSS Inline (via atributo style="")
  5. !important (evite usar - quebra a cascata natural)

O que é Especificidade?

Especificidade é um sistema de pontuação que determina qual seletor é mais "específico". Quanto mais específico o seletor, maior sua precedência.

/* Especificidade: 0-0-1 (1 seletor de tipo) */
p { color: blue; }

/* Especificidade: 0-1-0 (1 classe) */
.texto { color: red; }

/* Especificidade: 1-0-0 (1 ID) */
#destaque { color: green; }

/* Resultado: O parágrafo será verde, pois ID vence */

Pontuação de Especificidade

  • Seletor de Tipo (p, h1, div): 0-0-1
  • Seletor de Classe (.classe): 0-1-0
  • Seletor de ID (#id): 1-0-0
  • Inline: 1-0-0-0
  • !important: Quebra todas as regras (use com moderação)

Regra de Ouro

Quando duas regras têm a especificidade igual, a que aparecer por último no CSS vence. Isso é especialmente importante ao trabalhar com múltiplos arquivos CSS.

3. Unidades de Medida

O CSS suporta diversas unidades para definir tamanhos de fontes, margens e dimensões:

  • Absolutas: O Pixel (px) é a mais comum, baseada nos pontos da tela do monitor.
  • Relativas:
    • EM: Relativa ao tamanho da fonte do elemento pai.
    • REM: Relativa ao tamanho da fonte do elemento raiz (<html>).
    • Porcentagem (%): Relativa ao tamanho do container pai.

3.1 Tipos de Display

A propriedade display controla como um elemento é renderizado na página. Entender os principais tipos é essencial para criar layouts funcionais.

Display Block

Ocupa toda a largura disponível, forçando quebra de linha antes e depois. É o padrão de tags como <div>, <p> e <h1>.

.bloco {
  display: block;
  width: 200px;
  height: 100px;
  background-color: lightblue;
  margin-bottom: 10px; /* Empilha verticalmente */
}

Display Inline

Flui dentro do texto sem quebrar linha. Não respeita width e height definidos. É o padrão de <span>, <a> e <strong>.

.inline {
  display: inline;
  background-color: lightyellow;
  padding: 5px; /* Funciona */
  width: 200px; /* NÃO funciona em inline */
}

Display Inline-Block

Combina o melhor dos dois mundos: flui inline mas respeita dimensões. Ideal para botões e cards que ficam lado a lado.

.card {
  display: inline-block;
  width: 200px;
  height: 150px;
  background-color: lightcoral;
  margin: 10px;
  padding: 15px;
}

Display Flex

O Flexbox é o modelo de layout moderno para distribuir espaço entre itens. Ideal para layouts responsivos.

.container {
  display: flex;
  justify-content: space-between; /* Espaço igual entre itens */
  align-items: center;            /* Alinha verticalmente */
  gap: 20px;                      /* Espaço entre itens */
}

.item {
  flex: 1; /* Cada item ocupa espaço igual */
  padding: 20px;
  background-color: lightgreen;
}

Display Grid

O CSS Grid é um sistema de layout bidimensional que permite organizar elementos em linhas e colunas. Diferente do Flexbox (unidimensional), o Grid é ideal para layouts complexos como galerias e dashboards.

.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 colunas iguais */
  gap: 20px;                             /* Espaço entre itens */
}

.grid-item {
  padding: 20px;
  background-color: lightblue;
  border: 1px solid #ccc;
}

5. Exemplo de Código

HTML (index.html)

<head>
  <!-- Método Externo (Recomendado) -->
  <link rel="stylesheet" href="css/estilo.css">
</head>
<body>
  <h1 class="titulo-principal">Bem-vindo à MusicDot</h1>
  <p>Aprenda música de forma <strong id="destaque-unico">online</strong>.</p>
</body>

CSS (css/estilo.css)

/* Seletor de Tipo */
body {
  font-family: Arial, sans-serif; /* Fonte herdada por cascata */ [41]
}

/* Seletor de Classe */
.titulo-principal {
  color: #2D5377;
  font-size: 2rem; /* Unidade relativa */ [38]
}

/* Seletor de ID */
#destaque-unico {
  color: red;
  border-bottom: 1px solid black; /* Shorthand property */ [42, 43]
}

Dicas & Lembretes

  • Separação de Responsabilidades: HTML para conteúdo, CSS para visual e JavaScript para comportamento.
  • Problema N+1 de Performance: No contexto de CSS, evite o uso excessivo de @import dentro de arquivos CSS, pois eles podem retardar o carregamento da página; prefira tags <link> no HTML.
  • Ponto e Vírgula: Sempre finalize suas declarações com ;. Omitir o último ponto e vírgula de um bloco é permitido, mas gera erros difíceis de encontrar ao adicionar novas linhas.
  • Cores: Embora existam nomes de cores (como red), o padrão profissional é usar códigos Hexadecimais (ex: #FF0000) ou RGB.

6. Ferramentas de Desenvolvimento (DevTools)

Os navegadores modernos possuem ferramentas integradas que são indispensáveis para desenvolvedores CSS.

Como Acessar

  • Chrome/Edge: F12 ou Ctrl+Shift+I
  • Firefox: F12 ou Ctrl+Shift+I

Recursos Essenciais para CSS

  • Painel "Elements": Mostra a árvore DOM e permite inspecionar estilos aplicados a cada elemento em tempo real.
  • Caixa de Modelo: Clique em qualquer elemento para ver visualmente margin, border, padding e content.
  • Edição em Tempo Real: Clique diretamente no valor de uma propriedade CSS para editá-la instantaneamente.
  • Classes Adicionais: Clique em .cls para adicionar/remover classes e testar efeitos.
  • Media Queries: Ative o modo responsivo (Ctrl+Shift+M) para testar em diferentes tamanhos de tela.

Console CSS

Você pode aplicar estilos diretamente no console! Digite algo como:

document.body.style.backgroundColor = 'red';

Isso é útil para testes rápidos, mas lembre: sempre faça as alterações permanentes nos arquivos CSS.

7. Como aplicar na Prática

  • Identidade Visual: Definir as cores institucionais de uma empresa (como o azul da MusicDot) em um único arquivo CSS para que todo o site seja atualizado instantaneamente.
  • Acessibilidade: Usar unidades relativas (rem ou em) para permitir que o usuário aumente o tamanho da fonte no navegador sem quebrar o layout.
  • Organização Modular: Criar arquivos CSS separados para componentes como cabecalho.css e rodape.css, facilitando a manutenção em projetos grandes.
