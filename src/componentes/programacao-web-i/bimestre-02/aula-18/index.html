1. Descrição do Projeto

Você foi contratado para criar a Landing Page de um produto, serviço ou evento à sua escolha. O objetivo deste projeto é aplicar os conceitos de layout com Flexbox e Grid, responsividade mobile-first e o modelo de caixas (Box-Model) aprendidos no 2º Bimestre.

A página deve convencer o visitante a realizar uma ação (como assinar uma newsletter, comprar um produto ou se inscrever em um evento), apresentando o conteúdo de forma clara e organizada em qualquer dispositivo.

2. Requisitos Técnicos (O que será avaliado)

  • Flexbox: Uso de display: flex para barras de navegação, alinhamento de hero e distribuição de itens.
  • Grid: Uso de display: grid com grid-template-columns para seções como benefícios e depoimentos.
  • Responsividade: Estratégia mobile-first com @media (ao menos um breakpoint) adaptando o layout para desktop.
  • Box-Model: Controle consciente de margin, padding, border e box-sizing.
  • Custom Properties: Paleta de cores e espaçamentos definidos como --variaveis.
  • Formulário Estilizado: Pelo menos um formulário de captura (ex: e-mail) com campos estilizados, estados de foco e hover.
  • Efeitos Visuais: Transições, sombras (box-shadow) e/ou filtros em imagens.

3. Estrutura de Arquivos Sugerida

/projeto-ii
  ├── index.html          (estrutura semântica da Landing Page)
  ├── css/
  │    └── style.css      (estilos, variáveis e media queries)
  └── imagens/            (assets otimizados)

4. O Desafio Prático

Sua Landing Page deve conter:

  1. Um hero com chamada principal e botão de ação (CTA).
  2. Uma seção de benefícios organizada com Grid (3 colunas no desktop, 1 coluna no mobile).
  3. Uma seção de depoimentos ou planos alinhada com Flexbox.
  4. Um rodapé com links e informações de contato.
  5. Nenhuma barra de rolagem horizontal em qualquer largura de tela.

5. Desafios Bônus Opcional

  • Menu Responsivo: Converter a navegação em um menu hambúrguer no mobile (pode usar um checkbox ou JavaScript simples).
  • Animações: Adicionar animações de entrada com @keyframes.

Orientações de Entrega

  • Teste Real: Valide o layout nas larguras de 360px (mobile), 768px (tablet) e 1280px (desktop).
  • Consistência: Use somente as variáveis definidas para cores e espaçamentos.
  • Performance: Otimize as imagens e evite estilos repetidos.
  • Prazo: A entrega ocorre na aula 20, com correção e feedback.
