1. Descrição do Projeto

Este é o projeto final do 2º Bimestre. Você irá praticar a criação dos layouts mais populares da web, utilizando Flexbox e Grid para estruturar blocos de conteúdo. O objetivo é dominar a organização espacial dos elementos, sem se preocupar com o conteúdo real.

Escolha pelo menos 3 layouts da lista abaixo para implementar. Cada layout deve ser responsivo e funcionar bem em dispositivos móveis e desktop.

2. Layouts Disponíveis

MENU DE NAVEGAÇÃO

</main>

Layout clássico com barra de navegação fixa no topo, área de conteúdo e rodapé.

Dica de CSS: Use display: flex; flex-direction: column no container e flex: 1 no conteúdo para ocupar o espaço restante.

3. Requisitos Técnicos

  • Flexbox: Uso de display: flex para alinhamento e distribuição de itens dentro dos blocos.
  • Grid: Uso de display: grid com grid-template-columns para layouts de múltiplas colunas.
  • Responsividade: Estratégia mobile-first com @media adaptando o layout para desktop.
  • Box-Model: Controle de margin, padding e box-sizing.
  • Custom Properties: Paleta de cores e espaçamentos definidos como --variaveis.
  • Blocos Sem Conteúdo: Use apenas texto genérico (ex: "Bloco 1", "Imagem 1") para representar os elementos.

5. Orientações de Implementação

  1. Crie um arquivo HTML para cada layout escolhido.
  2. Use blocos genéricos (divs com texto simples) para representar os elementos.
  3. Implemente a responsividade com media queries.
  4. Use variáveis CSS para cores e espaçamentos.
  5. Teste em diferentes larguras: 360px (mobile), 768px (tablet) e 1280px (desktop).

6. Desafios Bônus Opcional

  • Menu Hambúrguer: Implemente um menu responsivo que se expande no mobile.
  • Animações: Adicione transições suaves nos elementos ao passar o mouse.
  • Hover Effects: Crie efeitos visuais nos cards e botões.
  • Dark Mode: Implemente um toggle para alternar entre modo claro e escuro.

Orientações de Entrega

  • Teste Real: Valide o layout nas larguras de 360px (mobile), 768px (tablet) e 1280px (desktop).
  • Consistência: Use somente as variáveis definidas para cores e espaçamentos.
  • Performance: Evite estilos repetidos e mantenha o CSS organizado.
  • Prazo: A entrega ocorre na aula 20, com correção e feedback.
