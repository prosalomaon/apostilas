Atividade Pratica: Sistema de Temas com Variaveis CSS

1. Enunciado

Nesta atividade, voce criara uma pagina HTML com dois componentes de cartao (card) estilizados exclusivamente com CSS. O objetivo e praticar a cascata, a heranca e o uso de variaveis CSS (Custom Properties) para alternar entre um tema claro e um tema escuro sem reescrever regras de propriedades.

2. Preparacao

  • Localizacao: Crie os arquivos dentro da pasta do exercicio.
  • Arquivos Necessarios:
    • index.html: Estrutura HTML da pagina.
    • estilos.css: Arquivo CSS externo com todos os estilos.
  • Conhecimento Previo: Seletores CSS, especificidade, heranca e sintaxe de variaveis CSS.

3. Codigo Base

Crie o arquivo index.html com a seguinte estrutura:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sistema de Temas - CSS Variables</title>
  <link rel="stylesheet" href="estilos.css">
</head>
<body>
  <header class="cabecalho">
    <h1 class="cabecalho-titulo">Sistema de Temas</h1>
    <p class="cabecalho-sub">Praticando Cascata, Heranca e Variaveis CSS</p>
  </header>

  <main class="conteudo">
    <section class="secao-tema">
      <h2>Tema Claro (Padrao)</h2>
      <div class="card">
        <h3 class="card-titulo">Card Padrão</h3>
        <p class="card-texto">Este card usa as variaveis definidas no :root. As cores sao herdadas
          normalmente pela cascata do CSS.</p>
        <a href="#" class="card-link">Saiba mais</a>
      </div>
    </section>

    <section class="secao-tema">
      <h2>Tema Escuro</h2>
      <div class="card card--escuro">
        <h3 class="card-titulo">Card Dark Mode</h3>
        <p class="card-texto">Este card redefinir as variaveis locais dentro da classe .card--escuro.
          O mesmo componente se adapta automaticamente.</p>
        <a href="#" class="card-link">Saiba mais</a>
      </div>
    </section>

    <section class="secao-tema">
      <h2>Tema de Atencao</h2>
      <div class="card card--atencao">
        <h3 class="card-titulo">Card de Atencao</h3>
        <p class="card-texto">Este card demonstra como uma terceira paleta de cores pode ser criada
          apenas redefinindo as mesmas variaveis CSS.</p>
        <a href="#" class="card-link">Saiba mais</a>
      </div>
    </section>
  </main>

  <footer class="rodape">
    <p>Exercicio 01 - Aula 12</p>
  </footer>
</body>
</html>

4. O Desafio

Crie o arquivo estilos.css implementando os seguintes requisitos:

Requisito 1: Variaveis Globais no :root

Declare as variaveis CSS no seletor :root com a paleta do tema claro:

  • --cor-fundo: cor de fundo do card
  • --cor-texto: cor do texto principal
  • --cor-titulo: cor do titulo do card
  • --cor-borda: cor da borda do card
  • --cor-link: cor dos links dentro do card

Requisito 2: Componente Card Generico

Estilize a classe .card utilizando exclusivamente as variaveis declaradas. Inclua padding, border-radius, borda solida e uma transicao suave.

Requisito 3: Redefinicao de Escopo para Temas

Crie as classes .card--escuro e .card--atencao redefinindo apenas o valor das variaveis CSS. Nao crie novas regras de propriedades para essas classes.

Requisito 4: Heranca de Tipografia

Defina font-family e line-height no body e verifique que todos os elementos herdam essas propriedades automaticamente.

Requisito 5: Resolucao de Conflito de Especificidade

Adicione a regra abaixo no final do CSS e explique (em comentario no codigo) por que o link dentro do .card--escuro fica com a cor indicada:

/* Adicione esta regra e comente o resultado esperado */
a {
    color: gray;
}

.card--escuro .card-link {
    color: cyan;
}

5. Desafios Extras

  • Fallback: Adicione um valor de fallback na funcao var() para o caso de uma variavel nao ser definida.
  • Heranca com inherit: Crie um bloco <blockquote> dentro de um card e force-o a herdar a cor de texto do card usando color: inherit.
  • Case Sensitivity: Crie uma segunda variavel --Cor-Principal (com maiusculas) e use-as em elementos diferentes. Documente a diferenca.
  • !important: Adicione color: red !important em um seletor de tipo e observe se ele sobrescreve as variaveis. Comente o resultado.

6. Resultado Esperado

Ao abrir o arquivo index.html no navegador, voce deve ver:

  • Um cabecalho com titulo e subtitulo herdando a tipografia do body
  • Tres cards lado a lado (ou empilhados em telas estreitas) cada um com uma paleta de cores diferente
  • O primeiro card com cores claras (tema padrao do :root)
  • O segundo card com cores escuras (tema escuro)
  • O terceiro card com cores de alerta/atencao
  • Todos os cards compartilhando a mesma estrutura de layout, diferenciando-se apenas pelas variaveis
