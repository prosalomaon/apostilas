A Cascata: Ordem de Prioridade

A Cascata e o algoritmo que resolve conflitos quando multiplas regras tentam definir a mesma propriedade no mesmo elemento. O navegador avalia tres criterios nesta ordem exata:

1
Origem da Folha de Estilo - De qual fonte a regra vem? (User Agent < Autor < Autor com !important)
2
Especificidade - Quao especifico e o seletor? (Tag < Classe < ID < Inline)
3
Ordem de Origem - Qual regra aparece por ultimo no CSS?

Heranca: Propagacao de Propriedades

A Heranca define como as propriedades de estilizacao se propagam dos elementos pais para seus descendentes na arvore do DOM. Nem todas as propriedades sao herdadas.

Escopo de Variaveis

Variaveis CSS seguem a mesma logica de heranca da cascata. Uma variavel declarada no :root esta disponivel em toda a pagina. Se redefinida dentro de uma classe, afeta apenas os descendentes daquele contenedor.

Exemplo de escopo:
/* Escopo Global - disponivel em toda a pagina */ :root { --cor-destaque: #1565c0; } /* Escopo Local - afeta apenas descendentes de .container-azul */ .container-azul { --cor-destaque: #c62828; /* Sobrescreve o global */ } /* Ambos usam a mesma variavel, mas com valores diferentes */ .botao { background: var(--cor-destaque); }

Valor de Fallback em var()

A funcao var() aceita um segundo argumento opcional que e usado quando a variavel nao e encontrada.

Resultado:
Este bloco usa var(--meu-espacamento, 10px) no padding.

Sintaxe de Declaracao e Uso

Declaracao

:root { /* Use -- (hifen duplo) para declarar */ --cor-primaria: #1565c0; --tamanho-fonte: 16px; --espacamento: 1.5rem; }

Uso

.botao { /* Use var() para invocar */ background: var(--cor-primaria); font-size: var(--tamanho-fonte); padding: var(--espacamento); /* Com fallback: var(--nao-existe, 10px) */ }

Case Sensitivity

Variaveis CSS diferenciam maiusculas de minusculas. --cor-principal e --Cor-Principal sao variaveis completamente isoladas.

Demonstracao:
--cor-principal
Valor: minusc.
--Cor-Principal
Valor: maiusc.
:root { --cor-principal: "valor com minusculas"; --Cor-Principal: "valor com maiusculas"; } /* Sao duas variaveis completamente diferentes! */

Resumo: Fluxo Completo de Decisao

/* O navegador segue esta ordem para decidir qual valor aplicar: */ PASSO 1 - Origem da Folha de Estilo User Agent < Autor (externo/interno) < Autor (inline) < Autor com !important Se as origens sao iguais, vai para o Passo 2. PASSO 2 - Especificidade do Seletor * (0) < tag (1) < classe (10) < ID (100) < inline (1000) Se a especificidade e igual, vai para o Passo 3. PASSO 3 - Ordem de Origem A regra declarada por ULTIMO no CSS vence. Este e o criterio de desempate final.
