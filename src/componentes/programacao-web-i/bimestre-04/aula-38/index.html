1. Descrição do Projeto

Chegou a hora de consolidar tudo o que foi aprendido ao longo do ano! Você deve desenvolver e publicar um website completo: responsivo, interativo e acessível, combinando HTML5 semântico, CSS moderno, JavaScript e as ferramentas de publicação do 4º Bimestre.

O site deve ser publicado em uma plataforma real (GitHub Pages, Vercel ou Firebase) e estar acessível ao público por meio de uma URL.

2. Requisitos Técnicos (O que será avaliado)

  • HTML Semântico e Acessível: Estrutura com elementos de seção, hierarquia de títulos e atributos ARIA quando necessário.
  • CSS Responsivo: Layout com Flexbox/Grid, media queries e uso de Custom Properties.
  • JavaScript Interativo: Pelo menos dois componentes interativos e uma validação de formulário.
  • Consumo de Dados: Uso de fetch + JSON ou persistência via localStorage.
  • Build e Publicação: Projeto empacotado com uma ferramenta de build (ex: Vite) e publicado em uma plataforma de hospedagem.
  • Sem Erros: A página deve rodar sem erros no console e sem quebras em mobile e desktop.

3. Estrutura de Arquivos Sugerida

/projeto-final
  ├── index.html          (página principal)
  ├── sobre.html          (página Sobre)
  ├── contato.html        (página de Contato com formulário)
  ├── css/
  │    └── style.css      (estilos responsivos)
  ├── js/
  │    └── main.js        (interações e consumo de dados)
  └── imagens/            (assets otimizados)

4. O Desafio Prático

Seu website final deve conter:

  1. Pelo menos 3 páginas navegáveis entre si (ex: Home, Sobre, Contato).
  2. Formulário de contato com validação e mensagens de feedback.
  3. Dados dinâmicos: carregar conteúdo via fetch (ex: uma API pública) ou persistir preferências do usuário com localStorage.
  4. Componentes interativos, como menu retrátil, galeria ou modo escuro.
  5. URL pública publicada e funcional ao final da apresentação.

5. Desafios Bônus Opcional

  • Meta Tags de SEO: Open Graph e Twitter Cards para compartilhamento nas redes sociais.
  • PWA: Manifest e service worker para instalação da aplicação.

Orientações de Entrega

  • Publicação: Envie o link público da aplicação junto com o código-fonte.
  • Teste Final: Verifique a responsividade, acessibilidade e ausência de erros antes de entregar.
  • Apresentação: Prepare-se para apresentar o projeto na aula 40.
  • Prazo: A entrega e a apresentação ocorrem no encerramento do curso.
