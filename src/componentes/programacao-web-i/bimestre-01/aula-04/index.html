1. Teoria & Conceitos

O HTML não é uma linguagem de programação, mas sim uma linguagem de marcação que descreve a estrutura de um site de forma semântica. Nesta aula, aprenderemos a codificar elementos de texto com foco no seu significado, e não apenas na sua aparência visual.

A semântica na web refere-se ao uso de tags HTML que descrevem o significado do conteúdo que elas envolvem. Enquanto o HTML cuida da estrutura, a estilização visual (como cores e negritos) é responsabilidade do CSS.

Importância da Estruturação Semântica

  • SEO (Search Engine Optimization): Motores de busca como Google e Bing usam a hierarquia das tags (como os títulos <h1>) para indexar e ranquear a relevância do seu conteúdo. O uso de microdados e tags corretas ajuda a promover páginas nos resultados de busca.
  • Acessibilidade: Pessoas com deficiência visual utilizam softwares leitores de tela que navegam pelo documento baseando-se nas tags semânticas. Uma marcação correta permite que o usuário salte diretamente para o conteúdo principal ou identifique o papel de cada imagem.
  • Manutenção: Páginas semânticas são mais fáceis de ler e atualizar por outros desenvolvedores.

Elementos Fundamentais de Texto

  • Cabeçalhos (<h1> a <h6>): Definem a hierarquia de importância, sendo o <h1> o título principal e os demais subtítulos.
  • Parágrafos (<p>): Utilizados para blocos de texto comum.
  • Ênfase (<strong> e <em>): O <strong> indica importância forte (exibido em negrito), enquanto o <em> indica uma ênfase acentuada no sentido do texto (exibido em itálico).
  • Endereço (<address>): Usado especificamente para informações de contato.

2. Exemplo de Código

Abaixo, um exemplo de documento semântico que agrupa conteúdos de forma lógica.

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <title>Aula de Semântica</title>
</head>
<body>
  <header>
    <h1 class="titulo">Sobre a Empresa</h1> <!-- Título principal [17] -->
  </header>

  <main>
    <p>A MusicDot é a maior escola de música online.</p> <!-- Parágrafo [14] -->

    <h2 id="historia">Nossa História</h2> <!-- Subtítulo hierárquico [13] -->
    <p>Fundada em <strong>1932</strong>, a empresa revolucionou o ensino.</p>

    <section id="contato">
      <h3 class="contato_subtitulo">Correspondência</h3>
      <address class="contato_info"> <!-- Tag específica para endereços [16] -->
        Rua Vergueiro, 3185, 8º andar<br>
        São Paulo - SP
      </address>
    </section>
  </main>
</body>
</html>

3. Representação Gráfica

A Árvore do DOM (Document Object Model)

O navegador interpreta o HTML como uma estrutura hierárquica de árvore.

graph TD html((html)) --> head(head - Metadados) html --> body(body - Visível) body --> header[header] body --> main[main] header --> h1[h1 - Título Principal] main --> h2[h2 - Subtítulo] main --> p[p - Parágrafo] p --> strong[strong - Destaque]

Dicas & Lembretes

  • Regra do H1: Utilize apenas um único <h1> por página, representando o conteúdo mais importante.
  • Semântica vs. Visual: Escolha as tags pelo que elas representam e não por como elas aparecem na tela; o negrito do <strong> é apenas um padrão que o CSS pode alterar.
  • Indentação: Mantenha elementos "filhos" recuados em relação aos "mães" para facilitar a leitura do código.
  • SEO: Use títulos relevantes e descrições meta descritivas para ajudar os robôs de busca.

4. Como aplicar na Prática

O domínio da semântica é essencial em projetos reais para:

  • Páginas Institucionais: Organizar a história e diferenciais de uma empresa em uma página "Sobre".
  • Blogs e Portais: Garantir que cada notícia tenha uma hierarquia de títulos que facilite o escaneamento visual e por motores de busca.
  • Formulários Acessíveis: Usar rótulos (<label>) vinculados corretamente aos campos de texto para que usuários de leitores de tela saibam o que digitar.
  • Localização: Marcar endereços de lojas físicas com a tag <address> para que sistemas GPS ou mapas identifiquem a informação de contato.
