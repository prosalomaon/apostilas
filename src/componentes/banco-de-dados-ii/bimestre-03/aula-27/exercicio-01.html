Enunciado

Você é responsável por implementar a camada de persistência de um sistema de gerenciamento de usuários. O sistema possui dois tipos de usuários: Aluno (com atributo exclusivo matricula) e Professor (com atributo exclusivo siape). Ambos herdam da classe Usuario (com atributos nome e email). Além disso, cada usuário pode possuir múltiplos Telefones (associação 1:N).

Implemente o mapeamento utilizando a abordagem de Tabela Única (Single Table) para a herança, primeiro com um ORM (Hibernate ou Drizzle), depois compare com o equivalente via driver de abstração (JDBC ou PDO).

Parte 2 — Mapeamento com Hibernate (ORM)

Anote as classes com as anotações JPA/Hibernate para implementar a herança por Tabela Única (Single Table) e a associação 1:N com @OneToMany: 

// Complete as anotações nas classes
@Entity
@Table(name = "usuario")
@Inheritance(strategy = InheritanceType.SINGLE_TABLE)
@DiscriminatorColumn(name = "tipo")
public class Usuario {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)
    private String nome;

    @Column(nullable = false, unique = true)
    private String email;

    @OneToMany(mappedBy = "usuario", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<Telefone> telefones = new ArrayList<>();
}

@Entity
@DiscriminatorValue("A")
public class Aluno extends Usuario {
    @Column(length = 20)
    private String matricula;
}

@Entity
@DiscriminatorValue("P")
public class Professor extends Usuario {
    @Column(length = 20)
    private String siape;
}

@Entity
@Table(name = "telefone")
public class Telefone {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 20)
    private String numero;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "id_usuario", nullable = false)
    private Usuario usuario;
}

Parte 3 — Mapeamento com Drizzle ORM (TypeScript)

Defina o schema equivalente em Drizzle utilizando pgTable e a abordagem de Tabela Única com coluna discriminadora: 

import { pgTable, serial, varchar, char } from "drizzle-orm/pg-core";

// Tabela única para herança
export const usuario = pgTable("usuario", {
    id: serial("id_usuario").primaryKey(),
    nome: varchar("nome", { length: 100 }).notNull(),
    email: varchar("email", { length: 100 }).notNull().unique(),
    tipo: char("tipo", { length: 1 }).notNull(), // 'A' ou 'P'
    matricula: varchar("matricula", { length: 20 }),
    siape: varchar("siape", { length: 20 }),
});

export const telefone = pgTable("telefone", {
    id: serial("id_telefone").primaryKey(),
    numero: varchar("numero", { length: 20 }).notNull(),
    idUsuario: serial("id_usuario").notNull().references(() => usuario.id),
});

Parte 4 — Inserção com ORM vs. Driver de Abstração

Compare a inserção via Hibernate (ORM) com JDBC (driver):

// Hibernate (ORM) — sem SQL manual
Session session = sessionFactory.openSession();
Transaction tx = session.beginTransaction();

Aluno aluno = new Aluno();
aluno.setNome("Ana Souza");
aluno.setEmail("ana.souza@etec.sp.gov.br");
aluno.setMatricula("2025001234");
session.save(aluno); // INSERT gerado automaticamente

Telefone tel1 = new Telefone();
tel1.setNumero("(11) 99876-5432");
tel1.setUsuario(aluno);
session.save(tel1);

tx.commit();
// JDBC (Driver) — SQL explícito, sem mapeamento
Connection conn = DriverManager.getConnection(url, user, pass);
conn.setAutoCommit(false);

PreparedStatement stmt = conn.prepareStatement(
    "INSERT INTO usuario (nome, email, tipo, matricula) VALUES (?, ?, 'A', ?)",
    Statement.RETURN_GENERATED_KEYS
);
stmt.setString(1, "Ana Souza");
stmt.setString(2, "ana.souza@etec.sp.gov.br");
stmt.setString(3, "2025001234");
stmt.executeUpdate();

ResultSet rs = stmt.getGeneratedKeys();
rs.next();
long idUsuario = rs.getLong(1);

PreparedStatement telStmt = conn.prepareStatement(
    "INSERT INTO telefone (numero, id_usuario) VALUES (?, ?)"
);
telStmt.setString(1, "(11) 99876-5432");
telStmt.setLong(2, idUsuario);
telStmt.executeUpdate();

conn.commit();
