Objetivo

Entregar a Parte 1 do Projeto 3: todas as Stored Procedures e Stored Functions do StreamFlow, encapsulando as regras de negócio no servidor. Siga o roteiro abaixo e use o checklist final antes de submeter.

O que implementar

  1. Procedure realizar_cobranca_mensal (RN01):
    • Parâmetros: IN id_assinante INT, IN valor_mensalidade DECIMAL(10,2) e OUT novo_saldo DECIMAL(10,2).
    • Leitura do saldo em variável local com SELECT ... INTO.
    • Erro customizado quando o saldo for insuficiente, sem alterar o banco.
    • Débito e retorno do novo saldo no parâmetro OUT.
  2. Procedure registrar_reproducao (RF02):
    • Parâmetros de entrada: perfil, vídeo, IP e dispositivo.
    • Transação com COMMIT/ROLLBACK e manipulador de exceção.
    • Retorno do id do registro criado.
  3. Procedure gerar_faturamento_mensal (RF04):
    • Cursor sobre as produtoras (DECLARE, OPEN, FETCH, CLOSE).
    • Soma dos minutos consumidos no mês por produtora.
    • Fim do cursor detectado com CONTINUE HANDLER FOR NOT FOUND.
  4. Function minutos_assistidos_por_produtora:
    • Recebe id_produtora e competência, retorna os minutos totais.
    • Classificada quanto a determinismo/volatilidade e justificada.
  5. Function calcular_idade:
    • Recebe a data de nascimento e retorna a idade, usada pela visão LGPD.

Validações obrigatórias

  1. Execute CALL realizar_cobranca_mensal(...) para um assinante com saldo suficiente e confirme o débito e o novo saldo no OUT.
  2. Repita a chamada para um assinante sem saldo e confirme que o erro customizado é exibido e que nenhum dado foi alterado.
  3. Chame CALL registrar_reproducao(...) e confirme a nova linha em reproducoes com IP, dispositivo e timestamps corretos.
  4. Execute CALL gerar_faturamento_mensal('2026-07-01') com dados de teste e confira os valores em faturamento_produtoras.
  5. Use SELECT minutos_assistidos_por_produtora(1, '2026-07-01'); e confira se o resultado bate com uma consulta manual equivalente.
  6. Atualize a visão LGPD para usar calcular_idade e confirme que a data de nascimento não aparece mais.

Checklist de submissão

  • [ ] Script com todas as procedures e functions, comentado e com DELIMITER correto.
  • [ ] Comandos CALL/SELECT de teste documentados com seus resultados esperados.
  • [ ] Parágrafo de justificativa para cada objeto (parâmetros IN/OUT/INOUT, cursor, volatilidade, exceções).
  • [ ] Prova de que a RN01 (saldo não negativo) é garantida pela procedure.
  • [ ] Declaração do SGBD utilizado e adaptações de sintaxe aplicadas.

Orientações Finais

  • Utilize a estrutura do projeto anterior, adaptando os nomes das tabelas se necessário.
  • Confirme os efeitos de cada procedure com um SELECT após a execução.
  • Se usar MySQL, lembre-se do DELIMITER $$; se usar PostgreSQL, das variáveis declaradas AS $$ e de LANGUAGE plpgsql.
  • Tente resolver sem consultar as aulas; volte a elas apenas se travar em algum conceito.
