Orientações

  • Revise o conteúdo da aula antes de começar, especialmente procedures, functions, triggers e exceções.
  • Use DELIMITER $$ antes de criar stored programs no MySQL.
  • Sempre inclua ROLLBACK no EXIT HANDLER quando trabalhar com transações.
  • Coloque o DECLARE HANDLER no topo do bloco: depois das variáveis e antes do START TRANSACTION — uma posição errada gera erro de sintaxe na criação da procedure.
  • Em procedures com cursor, declare primeiro as variáveis, depois o cursor e então o CONTINUE HANDLER FOR NOT FOUND — nesta ordem específica.
  • Para o SIGNAL, use '22000' (dados) ou '23000' (integridade).
  • Teste cada objeto individualmente antes de seguir para o próximo.
  • Entregue a atividade no prazo estipulado pelo professor.
