Enunciado

Você está desenvolvendo o sistema de gestão de estoque de uma empresa. Algumas operações são críticas e precisam de tratamento adequado de erros para evitar dados inconsistentes. Resolva os problemas abaixo utilizando os conceitos de tratamento de exceções vistos na aula.

Considere as seguintes tabelas já criadas no banco estoque_db: 

CREATE TABLE produtos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    quantidade INT NOT NULL DEFAULT 0,
    preco_unitario DECIMAL(10,2) NOT NULL
);

CREATE TABLE movimentacoes (
    id INT PRIMARY KEY AUTO_INCREMENT,
    produto_id INT NOT NULL,
    tipo ENUM('ENTRADA', 'SAIDA') NOT NULL,
    quantidade INT NOT NULL,
    data_movimento DATETIME DEFAULT NOW(),
    FOREIGN KEY (produto_id) REFERENCES produtos(id)
);

Crie uma procedure CadastraProduto que insira um produto na tabela. Se já existir um produto com o mesmo nome (violação de UNIQUE), a procedure deve simplesmente ignorar o erro e retornar sem mensagem de erro.

  • Use DECLARE CONTINUE HANDLER FOR 1062 (erro de duplicata no MySQL).
  • Adicione uma constraint de nome único na tabela antes de criar a procedure: ALTER TABLE produtos ADD UNIQUE (nome);
